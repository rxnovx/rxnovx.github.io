<h2 id="3-nextjs-프로젝트-생성" tabindex="-1" data-src-line="52">3. Next.js 프로젝트 생성 <a class="header-anchor" href="#3-nextjs-프로젝트-생성" aria-hidden="true">#</a></h2>

<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">프로젝트 이름은 무엇인가요? → my-app

<h2 id="4-nextjs-개발-서버-실행-문제-해결-포함" tabindex="-1" data-src-line="83">4. Next.js 개발 서버 실행 (문제 해결 포함) <a class="header-anchor" href="#4-nextjs-개발-서버-실행-문제-해결-포함" aria-hidden="true">#</a></h2>
<p>생성된 프로젝트 디렉토리로 이동한 뒤 개발 서버를 실행합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">cd</span> ~/workspace/my-app

</code></pre></div></code></pre>
<p>일반적인 PC 환경이라면 개발 서버가 바로 실행되지만, <strong>안드로이드 태블릿 환경에서는 아래와 같은 오류가 발생할 수 있습니다</strong>.</p>
<p><img src="/images/_posts/termux/run-nextjs-on-android/1766729302449-Screenshot_20251226_150752_ChromeDev.jpg" alt="Screenshot20251226150752Chrome Dev.jpg"></p>
<h3 id="오류-원인" tabindex="-1" data-src-line="96">오류 원인 <a class="header-anchor" href="#오류-원인" aria-hidden="true">#</a></h3>
<p>Next.js 최신 버전은 기본적으로 <strong>Turbopack</strong>을 사용합니다.</p>
<p>그러나 Turbopack은 현재 <strong>안드로이드(ARM) 기반 Termux 환경을 완전히 지원하지 않기 때문에</strong> 개발 서버 실행 시 오류가 발생합니다.</p>
<hr>
<h3 id="해결-방법-webpack-사용하도록-설정-변경" tabindex="-1" data-src-line="104">해결 방법: Webpack 사용하도록 설정 변경 <a class="header-anchor" href="#해결-방법-webpack-사용하도록-설정-변경" aria-hidden="true">#</a></h3>
<p><code>package.json</code> 파일을 열어 <code>scripts</code> 항목을 아래와 같이 수정합니다.</p>
<pre><code class="language-json"><div class="code-block"><div class="code-header"><span class="code-title">json</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-json"><code class="hljs language-json"><span class="hljs-punctuation">{</span>
  <span class="hljs-attr">&quot;scripts&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-punctuation">{</span>
    <span class="hljs-attr">&quot;dev&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;next dev --webpack&quot;</span><span class="hljs-punctuation">,</span>
    <span class="hljs-attr">&quot;build&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;next build --webpack&quot;</span><span class="hljs-punctuation">,</span>
    <span class="hljs-attr">&quot;start&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;next start --webpack&quot;</span><span class="hljs-punctuation">,</span>
    <span class="hljs-attr">&quot;lint&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;eslint&quot;</span>
  <span class="hljs-punctuation">}</span>
<span class="hljs-punctuation">}</span>
</code></pre></div></code></pre>
<p><code>--webpack</code> 옵션을 명시적으로 지정하면, Turbopack 대신 <strong>Webpack을 사용하여 빌드 및 실행</strong>하게 됩니다.</p>
<p>수정 후 다시 개발 서버를 실행합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">npm run dev
</code></pre></div></code></pre>
