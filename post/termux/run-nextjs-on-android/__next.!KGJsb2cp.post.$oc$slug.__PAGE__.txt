<h3 id="오류-원인" tabindex="-1" data-src-line="96">오류 원인 <a class="header-anchor" href="#오류-원인" aria-hidden="true">#</a></h3>
<p>Next.js 최신 버전은 기본적으로 <strong>Turbopack</strong>을 사용합니다.</p>
<p>그러나 Turbopack은 현재 <strong>안드로이드(ARM) 기반 Termux 환경을 완전히 지원하지 않기 때문에</strong> 개발 서버 실행 시 오류가 발생합니다.</p>

<pre><code class="language-json"><div class="code-block"><div class="code-header"><span class="code-title">json</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-json"><code class="hljs language-json"><span class="hljs-punctuation">{</span>

    <span class="hljs-attr">&quot;build&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;next build --webpack&quot;</span><span class="hljs-punctuation">,</span>
    <span class="hljs-attr">&quot;start&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;next start --webpack&quot;</span><span class="hljs-punctuation">,</span>
    <span class="hljs-attr">&quot;lint&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;eslint&quot;</span>

<p><code>--webpack</code> 옵션을 명시적으로 지정하면, Turbopack 대신 <strong>Webpack을 사용하여 빌드 및 실행</strong>하게 됩니다.</p>
<p>수정 후 다시 개발 서버를 실행합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">npm run dev
</code></pre></div></code></pre>
