<p>이 문서는 안드로이드 태블릿에서 만든 Next.js 프로젝트를 Github에 배포하는 방법에 대해 설명하는 문서입니다.<br>
태블릿에 Node.js가 설치되어있고 Next.js 프로젝트를 구성하여 프로젝트를 실행해본 상태에서 진행합니다.<br>
Github 계정은 <a href="https://github.com" target="_blank" rel="noopener noreferrer" class="md-ext-link">깃허브 공식 홈페이지</a>에서 만드실 수 있습니다.</p>
<h2 id="github-저장소-생성" tabindex="-1">github 저장소 생성 <a class="header-anchor" href="#github-저장소-생성" aria-hidden="true">#</a></h2>
<h3 id="githubio-란" tabindex="-1">github.io 란? <a class="header-anchor" href="#githubio-란" aria-hidden="true">#</a></h3>
<p>GitHub Pages는 **GitHub 저장소의 파일(HTML/CSS/JS 등)**을 그대로 웹사이트로 배포해주는 기능입니다.<br>
그중에서도 <code>github.io</code>는 GitHub Pages로 만들어지는 기본 도메인이고, 보통 아래 두 종류가 있어요.</p>
<ul>
<li><strong>User/Organization 사이트</strong>: <code>https://[계정명].github.io/</code><br>
→ 저장소 이름이 <strong>반드시</strong> <code>[계정명].github.io</code> 여야 함</li>
<li><strong>Project 사이트</strong>: <code>https://[계정명].github.io/[repo]/</code><br>
→ 일반 저장소에서도 가능</li>
</ul>
<p>즉, 블로그나 포트폴리오를 “루트 도메인”으로 깔끔하게 쓰려면 <strong>User 사이트 방식</strong>이 가장 깔끔합니다.</p>
<hr>
<h3 id="계정명githubio를-만들어보자" tabindex="-1">[계정명].github.io를 만들어보자 <a class="header-anchor" href="#계정명githubio를-만들어보자" aria-hidden="true">#</a></h3>
<p>아래 순서대로 하면 됩니다.</p>
<h4 id="1-github에서-새-저장소-만들기" tabindex="-1">1) GitHub에서 새 저장소 만들기 <a class="header-anchor" href="#1-github에서-새-저장소-만들기" aria-hidden="true">#</a></h4>

<p>GitHub 로그인</p>
</li>
<li>
<p>우측 상단 <strong>+</strong> 버튼 → <strong>New repository</strong> 클릭</p>
</li>
<li>
<p>Repository name에 아래처럼 입력</p>
<ul>
<li><strong><code>[계정명].github.io</code></strong> (계정명과 정확히 일치해야 함)</li>
</ul>
</li>
<li>
<p>공개 설정은 보통 <strong>Public</strong> 추천</p>

<p>여기서는 **Next.js 프로젝트를 정적 사이트(export 모드)**로 설정한 뒤, GitHub Pages에서 제공하는<br>

<h4 id="4-gh-pages를-사용해서-배포하기" tabindex="-1">4) gh-pages를 사용해서 배포하기 <a class="header-anchor" href="#4-gh-pages를-사용해서-배포하기" aria-hidden="true">#</a></h4>
<p><code>gh-pages</code>는 <strong>빌드 결과물(<code>out/</code>)만 별도 브랜치(<code>gh-pages</code>)로 배포</strong>해주는 도구입니다.<br>
소스 코드와 배포 결과를 분리할 수 있어 <strong>유지보수에 가장 깔끔한 방식</strong>입니다.</p>
<hr>
<h5 id="4-1-gh-pages-설치" tabindex="-1">4-1) gh-pages 설치 <a class="header-anchor" href="#4-1-gh-pages-설치" aria-hidden="true">#</a></h5>
<p>프로젝트 루트에서 아래 명령을 실행합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code>npm install --<span class="hljs-built_in">save</span>-<span class="hljs-built_in">dev</span> gh-pages
</code></pre></div></code></pre>
<hr>
<h5 id="4-2-packagejson-스크립트-추가" tabindex="-1">4-2) package.json 스크립트 추가 <a class="header-anchor" href="#4-2-packagejson-스크립트-추가" aria-hidden="true">#</a></h5>
<p><code>package.json</code>에 아래 스크립트를 추가합니다.</p>
<pre><code class="language-json"><div class="code-block"><div class="code-header"><span class="code-title">json</span><button class="copy-button">Copy</button></div><pre class="language-json"><code><span class="hljs-punctuation">{</span>
  <span class="hljs-attr">&quot;scripts&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-punctuation">{</span>
    <span class="hljs-attr">&quot;build&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;next build&quot;</span><span class="hljs-punctuation">,</span>
    <span class="hljs-attr">&quot;deploy&quot;</span><span class="hljs-punctuation">:</span> <span class="hljs-string">&quot;gh-pages -d out&quot;</span>
  <span class="hljs-punctuation">}</span>
<span class="hljs-punctuation">}</span>
</code></pre></div></code></pre>
<div class="callout callout-note">
<p>노트<br>
<code>-d out</code> : Next.js export 결과물 디렉터리</p>
</div>
<hr>
<h5 id="4-4-빌드--배포-실행" tabindex="-1">4-4) 빌드 &amp; 배포 실행 <a class="header-anchor" href="#4-4-빌드--배포-실행" aria-hidden="true">#</a></h5>
<p>아래 명령 한 줄로 <strong>빌드 + gh-pages 브랜치 배포</strong>가 완료됩니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code>npm <span class="hljs-built_in">run</span> build
npm <span class="hljs-built_in">run</span> deploy
</code></pre></div></code></pre>
<p>정상 동작 시:</p>
<ul>
<li><code>gh-pages</code> 브랜치가 자동 생성됨</li>
<li><code>out/</code> 폴더의 내용만 <code>gh-pages</code> 브랜치에 커밋됨</li>
</ul>
<p><img src="/images/_posts/termux/deploy-nextjs-project-on-android/1767356830636-image.webp" alt="image.png"></p>
