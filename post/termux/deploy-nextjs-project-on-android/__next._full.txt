<h3 id="githubio-란" tabindex="-1" data-src-line="12">github.io 란? <a class="header-anchor" href="#githubio-란" aria-hidden="true">#</a></h3>
<p>GitHub Pages는 **GitHub 저장소의 파일(HTML/CSS/JS 등)**을 그대로 웹사이트로 배포해주는 기능입니다.<br>
그중에서도 <code>github.io</code>는 GitHub Pages로 만들어지는 기본 도메인이고, 보통 아래 두 종류가 있어요.</p>
<ul>
<li><strong>User/Organization 사이트</strong>: <code>https://[계정명].github.io/</code><br>
→ 저장소 이름이 <strong>반드시</strong> <code>[계정명].github.io</code> 여야 함</li>
<li><strong>Project 사이트</strong>: <code>https://[계정명].github.io/[repo]/</code><br>
→ 일반 저장소에서도 가능</li>
</ul>
<p>즉, 블로그나 포트폴리오를 “루트 도메인”으로 깔끔하게 쓰려면 <strong>User 사이트 방식</strong>이 가장 깔끔합니다.</p>

<h4 id="2-nextjs-프로젝트를-export-모드로-설정-하고-git-remote-추가" tabindex="-1" data-src-line="47">2) Next.js 프로젝트를 export 모드로 설정 하고 git remote 추가 <a class="header-anchor" href="#2-nextjs-프로젝트를-export-모드로-설정-하고-git-remote-추가" aria-hidden="true">#</a></h4>
<p>여기서는 **Next.js 프로젝트를 정적 사이트(export 모드)**로 설정한 뒤, GitHub Pages에서 제공하는<br>

<h5 id="2-1-nextjs를-export-모드로-설정하기" tabindex="-1" data-src-line="54">2-1) Next.js를 export 모드로 설정하기 <a class="header-anchor" href="#2-1-nextjs를-export-모드로-설정하기" aria-hidden="true">#</a></h5>
<p>GitHub Pages는 서버가 없는 <strong>정적 호스팅</strong>이기 때문에 Next.js를 반드시 export 모드로 설정해야 합니다.</p>
<p>프로젝트 루트에 있는 <code>next.config.js</code> 또는 <code>next.config.mjs</code> 파일을 아래처럼 수정합니다.</p>
<pre><code class="language-js"><div class="code-block"><div class="code-header"><span class="code-title">js</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-js"><code class="hljs language-js"><span class="hljs-comment">/** <span class="hljs-doctag">@type</span> {<span class="hljs-type">import(&#x27;next&#x27;).NextConfig</span>} */</span>
<span class="hljs-keyword">const</span> nextConfig = {
  <span class="hljs-attr">output</span>: <span class="hljs-string">&quot;export&quot;</span>, <span class="hljs-comment">// ✅ 정적 사이트로 빌드</span>
  <span class="hljs-attr">images</span>: {
    <span class="hljs-attr">unoptimized</span>: <span class="hljs-literal">true</span>, <span class="hljs-comment">// ✅ next/image 서버 최적화 비활성화 (필수)</span>
  },
};

<span class="hljs-variable language_">module</span>.<span class="hljs-property">exports</span> = nextConfig;
</code></pre></div></code></pre>
<div class="callout callout-warning">
