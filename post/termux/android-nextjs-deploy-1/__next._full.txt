10:T15a4,<h1>안드로이드 태블릿으로 Next.js 구성 및 github 배포하기 #1</h1>
<nav class="md-toc"><ul><li><a href="#들어가기-앞서">들어가기 앞서 </a></li><li><a href="#1-태블릿-준비">1. 태블릿 준비 </a></li><li><a href="#2-termux-설치">2. Termux 설치 </a></li><li><a href="#3-termux-repository-업데이트">3. Termux repository 업데이트 </a></li><li><a href="#4-code-server-패키지-설치-및-실행">4. code-server 패키지 설치 및 실행 </a></li><li><a href="#5-code-server-실행">5. code-server 실행 </a></li><li><a href="#6-실행-확인">6. 실행 확인 </a></li><li><a href="#마치며">마치며 </a></li></ul></nav><h2 id="들어가기-앞서" tabindex="-1">들어가기 앞서 <a class="header-anchor" href="#들어가기-앞서" aria-hidden="true">#</a></h2>
<p>이 문서는 안드로이드의 Termux 앱을 이용하여 code-server(vscode) 환경을 구성하고 구성한 환경 내에서 Next.js를 사용하여 웹 서비스를 구축하는 방법에 중 code-server를 설치하는 방법에 대해서 설명합니다.</p>
<h2 id="1-태블릿-준비" tabindex="-1">1. 태블릿 준비 <a class="header-anchor" href="#1-태블릿-준비" aria-hidden="true">#</a></h2>
<p>태블릿은 안드로이드 태블릿이면 아무 종류나 다 가능합니다. 다만 너무 느린 태블릿이라면 Next.js 빌드 시에 시간이 조금 걸린다는 단점이 있지만, 웹 서비스를 개발하는 데에는 크게 문제가 되지 않습니다.</p>
<blockquote>
<p>추천하는 최소 사양 : 갤럭시탭 S7+</p>
</blockquote>
<h2 id="2-termux-설치" tabindex="-1">2. Termux 설치 <a class="header-anchor" href="#2-termux-설치" aria-hidden="true">#</a></h2>
<p>예전에는 ‘구글 플레이스토어’ 에서 다운 받을 수 있는 Termux의 경우, apt 패키지 관리자가 오류를 일으킨다는 문제가 있었다고 합니다. 하지만 지금은 그 문제가 정책적으로 해결이 되었는지 문제 없이 잘 돌아가니 간편하게 플레이스토어에서 다운을 받도록 합니다.</p>
<h2 id="3-termux-repository-업데이트" tabindex="-1">3. Termux repository 업데이트 <a class="header-anchor" href="#3-termux-repository-업데이트" aria-hidden="true">#</a></h2>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-comment"># 저장소 업데이트</span>
pkg update

<span class="hljs-comment"># turmux repository 추가</span>
pkg <span class="hljs-keyword">install</span> tur-repo
</code></pre></div></code></pre>
<p>code-server는 용량이나 빌드 등의 부담 이유로 공식 저장소에 등록이 되어 있지 않은 패키지입니다. 따라서 <code>pkg instrall tur-repo</code> 명령어를 통해서 확장 저장소를 추가해주어야 code-server 패키지를 설치할 수 있습니다.</p>
<h2 id="4-code-server-패키지-설치-및-실행" tabindex="-1">4. code-server 패키지 설치 및 실행 <a class="header-anchor" href="#4-code-server-패키지-설치-및-실행" aria-hidden="true">#</a></h2>
<p>아래의 명령어로 code-server 패키지를 설치합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-symbol">pkg</span> install <span class="hljs-meta">code</span>-server
</code></pre></div></code></pre>
<h2 id="5-code-server-실행" tabindex="-1">5. code-server 실행 <a class="header-anchor" href="#5-code-server-실행" aria-hidden="true">#</a></h2>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-selector-tag">code</span>-server <span class="hljs-attr">--auth</span> <span class="hljs-attribute">none</span> <span class="hljs-attr">--host</span> <span class="hljs-number">0.0</span>.<span class="hljs-number">0.0</span> <span class="hljs-attr">--port</span> <span class="hljs-number">8080</span>
</code></pre></div></code></pre>
<p>코드 서버를 실행합니다.<br>
인증이 필요하다면 <code>--auth password</code> 를 입력하면 됩니다.<br>
네트워크는 0.0.0.0으로 모든 네트워크에서 접속이 가능하도록 (로컬에서만 접속가능하게 하려면 127.0.0.1 지정)<br>
포트는 8080 이외의 다른 것으로 지정을 해주셔도 됩니다.</p>
