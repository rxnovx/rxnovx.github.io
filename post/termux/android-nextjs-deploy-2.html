Termux 설치 완료 #

이전 시간에 Termux를 안드로이드 태블릿에 설치하였습니다.
이번에는 설치된 Termux에 Node.js를 설치하여 새로운 Next.js 프로젝트를 시작해보고자 합니다.

1. code-server 실행하여 터미널 열기 #

bash
code-server --auth none --host 0.0.0.0 --port 8080

code-server를 실행하여 터미널을 열어줍니다.
터미널을 여는 단축키는 (ctrl + )` 입니다.

단축키를 입력하면 위와 같이 아래에 터미널이 하단에 열릴것입니다.

2. Node.js 설치하기 #

bash
pkg install nodejs-lts

Node.js를 LTS 버전으로 설치해줍니다.

오늘 기준으로 설치하면 아래와 같이 24.11.1 버전이 설치가 됩니다.

3. Next.js 프로젝트 생성 #

Next.js 공식사이트에 접속하면 간편하게 설치할 수 있는 링크가 대문에 나와있습니다.

bash
npx create-next-app@latest

위 명령어를 치면 프로젝트에 대해 추천 설정으로 할 것인지 커스터마이징 할 것인지 물어보는데 저는 커스터마이징을 선택했습니다. 상세한 내용은 아래 캡쳐와 같습니다.

프로젝트 이름은 무엇인가요? → my-app
Next.js 권장 설정을 사용할까요? → 아니오
TypeScript를 사용할까요? → 예
React Compiler(실험적 기능)를 사용할까요? → 아니오
Tailwind CSS를 사용할까요? → 예
소스 코드를 src/ 디렉토리 안에 둘까요? → 예
App Router를 사용할까요? → 예
import 경로 별칭을 커스터마이즈할까요? (기본: @/) → 아니오

4. Next.js 프로젝트 개발모드로 시작 #

bash
cd ~/workspace/my-app
npm run dev

프로젝트 설정이 완료되었다면 Success*** 라는 문구가 뜨고, 위의 명령어를 입력하면 포트가 열리면서 개발 서버가 실행이 됩니다만, 태블릿 환경에서는 아래 캡쳐와 같이 실패를 하게됩니다.

실패 원인은 TurboPack을 태블릿 플랫폼에서는 사용할 수 없어 에러가 발생한건데요
이를 해결하기 위해서 package.json 파일을 열어 파일 내부를 수정해줍니다.

json
{
  ...
  "scripts": {
    "dev": "next dev --webpack",
    "build": "next build --webpack",
    "start": "next start --webpack",
    "lint": "eslint"
  },
  ...
}

–webpack 옵션을 주어서 빌드시 turbopack이 아닌 webpack을 사용하여 빌드를 하도록 하면 프로젝트가 정상적으로 실행이 됩니다.

아래와 같이 화면이 뜨면 성공적으로 프로젝트가 실행 된 것입니다.
