안드로이드 태블릿 + Termux 환경에서 <strong>정적 블로그 또는 CMS 형태의 Next.js 프로젝트</strong>를 운영한다는 전제에 맞춰 설명합니다.</p>

<h2 id="1-포스트가-저장될-폴더-src_post" tabindex="-1"><strong>1. 포스트가 저장될 폴더 (<code>src/_post</code>)</strong> <a class="header-anchor" href="#1-포스트가-저장될-폴더-src_post" aria-hidden="true">#</a></h2>
<p>이 폴더는 <strong>실제 콘텐츠가 저장되는 원본 데이터 영역</strong>입니다.<br>
Next.js 라우팅과는 직접적으로 연결되지 않으며, Markdown(<code>.md</code>) <strong>콘텐츠 저장소</strong> 역할을 합니다.</p>
<ul>
<li>정적 블로그의 글 원본 보관</li>
<li>GitHub에 커밋되는 실제 글 데이터</li>
<li>빌드 시 파일 시스템을 읽어 페이지를 생성하는 용도</li>
</ul>
<p>👉 일반적으로 <code>fs</code> 모듈과 markdown 라이브러리를 통해 이 폴더를 읽어옵니다.</p>
<hr>
<h2 id="2-카테고리폴더별-포스트-분류-_postcategory1" tabindex="-1"><strong>2. 카테고리(폴더)별 포스트 분류 (<code>_post/category1</code>)</strong> <a class="header-anchor" href="#2-카테고리폴더별-포스트-분류-_postcategory1" aria-hidden="true">#</a></h2>
<p>카테고리는 <strong>폴더 단위로 글을 분류</strong>하기 위한 구조입니다.</p>
<ul>
<li>하나의 폴더 = 하나의 카테고리</li>
<li>URL 구조와 매핑하기 쉬움<br>
예) <code>/categories/category1</code></li>
</ul>
<p>장점:</p>
<ul>
<li>카테고리 관리가 직관적</li>
<li>글 이동 및 정리가 쉬움</li>
<li>GitHub에서도 변경 이력이 명확</li>
</ul>
<hr>
<h2 id="3-포스트-2025-12-30-how-to-startmd" tabindex="-1"><strong>3. 포스트 (<code>2025-12-30-how-to-start.md</code>)</strong> <a class="header-anchor" href="#3-포스트-2025-12-30-how-to-startmd" aria-hidden="true">#</a></h2>
<p>실제 <strong>게시글 하나에 해당하는 Markdown 파일</strong>입니다.</p>
<p>일반적인 구성 예시:</p>
<pre><code class="language-md"><div class="code-block"><div class="code-header"><span class="code-title">md</span><button class="copy-button">Copy</button></div><pre class="language-md"><code><span class="hljs-meta">---</span>

</span>

</code></pre></div></code></pre>

<li>파일명에 날짜를 포함하여 정렬 및 관리 용이</li>
<li>Front Matter를 활용해 메타데이터 관리</li>
<li>정적 페이지 생성(SSG)에 최적화</li>
</ul>

<li>SEO-friendly한 구조 제공</li>
</ul>

<h2 id="6-포스트-상세보기-postslugpagetsx" tabindex="-1"><strong>6. 포스트 상세보기 (<code>post/[[...slug]]/page.tsx</code>)</strong> <a class="header-anchor" href="#6-포스트-상세보기-postslugpagetsx" aria-hidden="true">#</a></h2>

<p>예시 URL:</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">unknown</span><button class="copy-button">Copy</button></div><pre class="language-plain"><code>/<span class="hljs-built_in">post</span>/<span class="hljs-number">2025</span><span class="hljs-number">-12</span><span class="hljs-number">-30</span>-how-<span class="hljs-built_in">to</span>-<span class="hljs-built_in">start</span>
</code></pre></div></code></pre>
<p>특징:</p>
<ul>
<li><code>[[...slug]]</code> → 다단계 경로 지원</li>

<li>SSG 또는 ISR 적용 가능</li>
</ul>
<p>주요 역할:</p>
<ul>
<li>본문 렌더링</li>
<li>메타 태그 설정</li>
<li>이전/다음 글 네비게이션</li>
</ul>
