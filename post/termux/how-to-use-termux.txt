10:T1bc7,<h2 id="들어가며" tabindex="-1">들어가며 <a class="header-anchor" href="#들어가며" aria-hidden="true">#</a></h2>
<p>Termux에서 **code-server(VSCode)**를 사용하다 보면<br>
의외로 사소한 부분에서 자주 막히게 됩니다.</p>
<p>설치는 되었는데 접속이 되지 않거나,<br>
비밀번호 설정 때문에 오히려 더 꼬이거나,<br>
같은 명령어를 실행했는데 결과가 다른 경우도 흔합니다.</p>
<p>이 글에서는 그런 지점들만 정리합니다.<br>
복잡한 설명은 최대한 줄이고,<br>
<strong>실제로 문제가 되는 부분과 해결 방법만</strong> 다룹니다.</p>
<p>원리는 전문가 관점에서 설명하되,<br>
지금 당장 필요한 내용 위주로 정리하는 것이 목적입니다.</p>
<hr>
<h2 id="왜-tur-repo를-사용하는가" tabindex="-1">왜 tur-repo를 사용하는가 <a class="header-anchor" href="#왜-tur-repo를-사용하는가" aria-hidden="true">#</a></h2>
<p>Termux는 안드로이드 환경 위에서 동작합니다.<br>
이 때문에 일반적인 리눅스와는 조금 다른 부분이 있습니다.<br>
권한 문제라던지 등의 예상치 못한 오류가 발생하는 경우가 많습니다.</p>
<p><code>tur-repo</code>에서 제공하는 code-server는<br>
이러한 Termux 환경을 고려해 빌드된 패키지입니다.</p>
<p>다른 경로로 설치했을 때 발생하는<br>
접속 실패나 확장 설치 오류를 피할 수 있습니다.</p>
<p><strong>Termux에서 code-server를 설치하는 방법중에 가장 안전한 방법이<br>
tur-repo 기반 설치입니다.</strong></p>
<hr>
<h2 id="1-tur-repo-설치" tabindex="-1">1. tur-repo 설치 <a class="header-anchor" href="#1-tur-repo-설치" aria-hidden="true">#</a></h2>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code>pkg <span class="hljs-keyword">install</span> tur-repo
</code></pre></div></code></pre>
<p>Termux에서 사용할 수 있는<br>
사용자 전용 패키지 저장소를 추가하는 과정입니다.</p>
<hr>
<h2 id="2-code-server-설치" tabindex="-1">2. code-server 설치 <a class="header-anchor" href="#2-code-server-설치" aria-hidden="true">#</a></h2>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-symbol">pkg</span> install <span class="hljs-meta">code</span>-server
</code></pre></div></code></pre>
<p>이 명령으로 설치되는 code-server는<br>
<strong>tur-repo에 포함된 버전</strong>입니다.</p>
<p>다른 방식으로 설치하면<br>
실행은 되지만 접속이 되지 않거나,<br>
확장 설치 과정에서 오류가 반복되는 경우가 많습니다.</p>
<hr>
<h2 id="3-code-server-실행-비밀번호-없이" tabindex="-1">3. code-server 실행 (비밀번호 없이) <a class="header-anchor" href="#3-code-server-실행-비밀번호-없이" aria-hidden="true">#</a></h2>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-selector-tag">code</span>-server <span class="hljs-attr">--auth</span> <span class="hljs-attribute">none</span> <span class="hljs-attr">--host</span> <span class="hljs-number">0.0</span>.<span class="hljs-number">0.0</span>
</code></pre></div></code></pre>
<h3 id="비밀번호를-사용하지-않는-이유" tabindex="-1">비밀번호를 사용하지 않는 이유 <a class="header-anchor" href="#비밀번호를-사용하지-않는-이유" aria-hidden="true">#</a></h3>
<p>비밀번호를 설정하면<br>
인증 정보가 <code>/data</code> 영역에 저장됩니다.</p>
<p>Termux 환경에서는 이 영역을 직접 다루기 어렵기 때문에,<br>
비밀번호 확인이나 수정이 번거로워집니다.</p>
<p>이로 인해 설정을 잘못했다가<br>
다시 초기화해야 하는 상황도 자주 발생합니다.</p>
<p>따라서 Termux에서는<br>
<strong>비밀번호 없이 실행하는 방식이 가장 단순하고 안정적입니다.</strong></p>
<p>보안이 필요한 환경이라면,<br>
인증 설정이 아니라 네트워크 단에서 해결하는 것이 적절합니다.</p>
<hr>
<h2 id="4-code-server-접속" tabindex="-1">4. code-server 접속 <a class="header-anchor" href="#4-code-server-접속" aria-hidden="true">#</a></h2>
<p>실행 후 터미널에<br>
<code>http://IP:PORT</code> 형태의 주소가 출력됩니다.</p>
<p>해당 주소를<br>
브라우저 주소창에 그대로 입력하면 됩니다.</p>
<p>VSCode 화면이 표시되면<br>
정상적으로 접속된 상태입니다.</p>
<hr>
<h2 id="5-접속이-되지-않을-경우-포트-변경" tabindex="-1">5. 접속이 되지 않을 경우 포트 변경 <a class="header-anchor" href="#5-접속이-되지-않을-경우-포트-변경" aria-hidden="true">#</a></h2>
<p>접속이 되지 않는 경우,<br>
가장 먼저 확인해야 할 항목은 포트 충돌입니다.</p>
<p>다른 설정을 변경하기 전에<br>
<strong>포트부터 변경하는 것이 가장 빠른 해결 방법</strong>입니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-selector-tag">code</span>-server <span class="hljs-attr">--auth</span> <span class="hljs-attribute">none</span> <span class="hljs-attr">--host</span> <span class="hljs-number">0.0</span>.<span class="hljs-number">0.0</span> <span class="hljs-attr">--port</span> <span class="hljs-number">8081</span>
</code></pre></div></code></pre>
<p><code>8081</code> 대신<br>
<code>9000</code>, <code>10000</code> 등 다른 포트를 사용해도 무방합니다.</p>
<p>다시 실행하면 접속 주소가 변경되며,<br>
해당 주소로 접속하면 대부분 문제가 해결됩니다.</p>
<hr>
<h2 id="핵심-정리" tabindex="-1">핵심 정리 <a class="header-anchor" href="#핵심-정리" aria-hidden="true">#</a></h2>
<ul>
<li>code-server는 <strong>tur-repo 버전 사용</strong></li>
<li>인증 문제를 피하려면 <strong><code>--auth none</code> 옵션 사용</strong></li>
<li>접속이 되지 않으면 <strong>포트 변경부터 시도</strong></li>
</ul>
<hr>
<h2 id="마무리" tabindex="-1">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>위 과정을 모두 진행했음에도 문제가 발생한다면,<br>
대부분은 포트 충돌이나 실행 옵션 설정 문제입니다.</p>
<p>다른 설정을 추가로 건드리기보다는,<br>
위 순서를 기준으로 다시 실행해보는 것이 가장 효율적입니다.</p>
<p>Termux와 code-server 조합은<br>
초기 설정만 제대로 잡아두면 비교적 안정적으로 사용할 수 있습니다.</p>
