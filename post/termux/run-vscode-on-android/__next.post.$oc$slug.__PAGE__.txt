<nav class="md-toc"><ul><li><a href="#안드로이드-태블릿으로-vs-code-visual-studio-code-실행하기">안드로이드 태블릿으로 VS-CODE (Visual Studio Code) 실행하기 </a><ul><li><a href="#들어가기-앞서">들어가기 앞서 </a></li><li><a href="#1-태블릿-준비">1. 태블릿 준비 </a></li><li><a href="#2-termux-설치">2. <p>이 문서는 안드로이드 태블릿에서 <strong>Termux + code-server(VS Code)</strong> 환경을 구성하고, 해당 환경에서 <strong>Next.js 기반 웹 서비스를 개발</strong>하기 위한 준비 과정 중 <strong>code-server 설치 및 실행</strong>에 대해 설명합니다.</p>
<p>PC가 아닌 태블릿 환경에서도 충분히 개발이 가능하다는 점을 직접 구성 과정을 통해 보여주는 것이 목적입니다.</p>
<hr>
<h2 id="1-태블릿-준비" tabindex="-1">1. 태블릿 준비 <a class="header-anchor" href="#1-태블릿-준비" aria-hidden="true">#</a></h2>
<p>안드로이드 태블릿이라면 기종에 관계없이 모두 사용 가능합니다.<br>
다만, 성능이 많이 낮은 기기에서는 Next.js 빌드나 의존성 설치 과정에서 시간이 다소 오래 걸릴 수 있습니다.</p>
<blockquote>
<p><strong>권장 최소 사양</strong></p>
<ul>
<li>Galaxy Tab S7+ 또는 동급 이상의 성능</li>
</ul>
</blockquote>
<p>실제 개발 및 테스트에는 큰 제약이 없으며, 빌드 시간이 늘어나는 정도의 차이만 발생합니다.</p>
<hr>
<h2 id="2-termux-설치" tabindex="-1">2. Termux 설치 <a class="header-anchor" href="#2-termux-설치" aria-hidden="true">#</a></h2>
<p>과거에는 <strong>Google Play Store에서 설치한 Termux</strong>에서 패키지 관리자(<code>apt</code>) 오류가 발생하는 문제가 있었습니다.<br>
하지만 현재는 해당 문제가 해결되어, <strong>Play Store 버전 Termux도 정상적으로 사용 가능</strong>합니다.</p>
<p>가장 간편한 방법으로 <strong>Google Play Store에서 Termux를 설치</strong>하면 됩니다.</p>
<hr>
<h2 id="3-termux-저장소repository-업데이트" tabindex="-1">3. Termux 저장소(repository) 업데이트 <a class="header-anchor" href="#3-termux-저장소repository-업데이트" aria-hidden="true">#</a></h2>
<p>Termux 설치 후 가장 먼저 저장소를 최신 상태로 업데이트합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-comment"># 저장소 업데이트</span>
pkg update

<span class="hljs-comment"># Termux 확장 저장소(tur-repo) 추가</span>
pkg <span class="hljs-keyword">install</span> tur-repo
</code></pre></div></code></pre>
<h3 id="tur-repo가-필요한-이유" tabindex="-1">tur-repo가 필요한 이유 <a class="header-anchor" href="#tur-repo가-필요한-이유" aria-hidden="true">#</a></h3>
<p><code>code-server</code>는 용량과 빌드 부담 등의 이유로 <strong>Termux 공식 기본 저장소에는 포함되어 있지 않습니다</strong>.</p>
<p>따라서 <code>tur-repo</code>라는 <strong>확장 저장소</strong>를 추가해야 <code>code-server</code> 패키지를 설치할 수 있습니다.</p>
<hr>
<h2 id="4-code-server-설치" tabindex="-1">4. code-server 설치 <a class="header-anchor" href="#4-code-server-설치" aria-hidden="true">#</a></h2>
<p>확장 저장소 추가가 완료되었다면, 아래 명령어로 <code>code-server</code>를 설치합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-symbol">pkg</span> install <span class="hljs-meta">code</span>-server
</code></pre></div></code></pre>
<p>설치 과정에서 별도의 추가 설정은 필요하지 않습니다.</p>
<hr>
<h2 id="5-code-server-실행" tabindex="-1">5. code-server 실행 <a class="header-anchor" href="#5-code-server-실행" aria-hidden="true">#</a></h2>
<p>설치가 완료되면 아래 명령어로 <code>code-server</code>를 실행합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-selector-tag">code</span>-server <span class="hljs-attr">--auth</span> <span class="hljs-attribute">none</span> <span class="hljs-attr">--host</span> <span class="hljs-number">0.0</span>.<span class="hljs-number">0.0</span> <span class="hljs-attr">--port</span> <span class="hljs-number">8080</span>
</code></pre></div></code></pre>
<h3 id="옵션-설명" tabindex="-1">옵션 설명 <a class="header-anchor" href="#옵션-설명" aria-hidden="true">#</a></h3>
<ul>
<li>
<p><code>--auth none</code></p>
<ul>
<li>인증을 비활성화합니다.</li>
<li>태블릿 단독 사용 환경에서는 편의상 비활성화를 권장합니다.</li>
</ul>
</li>
<li>
<p><code>--host 0.0.0.0</code></p>
<ul>
<li>모든 네트워크 인터페이스에서 접속을 허용합니다.</li>
<li>로컬 접속만 허용하려면 <code>127.0.0.1</code>로 지정할 수 있습니다.</li>
</ul>
</li>
<li>
<p><code>--port 8080</code></p>
<ul>
<li>접속 포트를 지정합니다.</li>
<li>필요에 따라 다른 포트 번호로 변경해도 무방합니다.</li>
</ul>
</li>
</ul>
<blockquote>
<p>인증이 필요한 경우 <code>--auth password</code> 옵션을 사용할 수 있습니다.</p>
</blockquote>
