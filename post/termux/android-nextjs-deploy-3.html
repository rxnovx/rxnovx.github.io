Next.js 프로젝트 구성 완료 #

이전 시간에 Termux에 Node.js를 설치하고 Next.js 프로젝트 구성을 완료하였습니다.
이번에는 어떤 방식으로 프로젝트를 구성할 것인지에 대해 알아가보고자 합니다.

Next.js 폴더 구성 #

bash
myapp
┗ src
  ┗ _post         -> 1. 포스트가 저장될 폴더
    ┗ category1   -> 2. 카테고리(폴더)별 포스트 분류
      ┗2025-12-30-how-to-start.md -> 3. 포스트
    ┗ category2
    ┗ ...
  ┗ categories    
    ┗ [category]
      ┗ page.tsx  -> 4. 특정 카테고리에 포함된 포스트 일람
    ┗ page.tsx    -> 5. 카테고리 일람
  ┗ post
    ┗ [[...slug]]
      ┗ page.tsx  -> 6. 포스트 상세보기
  ┗ posts
    ┗ page.tsx    -> 7. 모든 글 일람
  ┗ tags
    ┗ [tag]
      ┗ page.tsx  -> 8. 특정 태그를 가진 포스트 일람
    ┗ page.tsx    -> 9. 태그 일람
  ┗ write
    ┗ page.tsx    -> 10. 글쓰기 에디터

아래는 제시해주신 Next.js 폴더 구조를 기준으로, 각 항목의 역할과 사용 목적을 하나씩 정리한 내용입니다.
안드로이드 태블릿 + Termux 환경에서 정적 블로그 또는 CMS 형태의 Next.js 프로젝트를 운영한다는 전제에 맞춰 설명합니다.

1. 포스트가 저장될 폴더 (src/_post) #

이 폴더는 실제 콘텐츠가 저장되는 원본 데이터 영역입니다.
Next.js 라우팅과는 직접적으로 연결되지 않으며, Markdown(.md) 콘텐츠 저장소 역할을 합니다.

  • 정적 블로그의 글 원본 보관
  • GitHub에 커밋되는 실제 글 데이터
  • 빌드 시 파일 시스템을 읽어 페이지를 생성하는 용도

👉 일반적으로 fs 모듈과 markdown 라이브러리를 통해 이 폴더를 읽어옵니다.

2. 카테고리(폴더)별 포스트 분류 (_post/category1) #

카테고리는 폴더 단위로 글을 분류하기 위한 구조입니다.

  • 하나의 폴더 = 하나의 카테고리
  • URL 구조와 매핑하기 쉬움
    예) /categories/category1

장점:

  • 카테고리 관리가 직관적
  • 글 이동 및 정리가 쉬움
  • GitHub에서도 변경 이력이 명확

3. 포스트 (2025-12-30-how-to-start.md) #

실제 게시글 하나에 해당하는 Markdown 파일입니다.

일반적인 구성 예시:

md
---
title: "How to Start"
date: "2025-12-30"
tags: ["nextjs", "android"]
category: "category1"
---

본문 내용...
  • 파일명에 날짜를 포함하여 정렬 및 관리 용이
  • Front Matter를 활용해 메타데이터 관리
  • 정적 페이지 생성(SSG)에 최적화

4. 특정 카테고리에 포함된 포스트 일람 (categories/[category]/page.tsx) #

동적 라우팅 페이지로, 특정 카테고리에 속한 글 목록을 보여줍니다.

예시 URL:

unknown
/categories/category1

역할:

  • _post/category1 폴더의 글 목록을 읽어 출력
  • 카테고리별 글 리스트 페이지 생성
  • SEO-friendly한 구조 제공

5. 카테고리 일람 (categories/page.tsx) #

전체 카테고리를 한눈에 보여주는 카테고리 인덱스 페이지입니다.

예시 URL:

unknown
/categories

기능:

  • _post 하위 폴더 목록을 스캔
  • 각 카테고리별 글 개수 표시 가능
  • 블로그 전체 구조 파악에 도움

6. 포스트 상세보기 (post/[[...slug]]/page.tsx) #

개별 포스트를 보여주는 핵심 페이지입니다.

예시 URL:

unknown
/post/2025-12-30-how-to-start

특징:

  • [[...slug]] → 다단계 경로 지원
  • Markdown 파일을 HTML로 변환
  • SSG 또는 ISR 적용 가능

주요 역할:

  • 본문 렌더링
  • 메타 태그 설정
  • 이전/다음 글 네비게이션

7. 모든 글 일람 (posts/page.tsx) #

블로그에 존재하는 모든 포스트를 시간순으로 출력하는 페이지입니다.

예시 URL:

unknown
/posts

활용:

  • 최신 글 목록 페이지
  • 홈 페이지 대체 가능
  • 페이지네이션 구현에 적합

8. 특정 태그를 가진 포스트 일람 (tags/[tag]/page.tsx) #

태그 기반으로 글을 필터링하는 동적 페이지입니다.

예시 URL:

unknown
/tags/nextjs

기능:

  • Front Matter의 tags 필드 활용
  • 하나의 글이 여러 태그에 속할 수 있음
  • 카테고리보다 세분화된 분류 제공

9. 태그 일람 (tags/page.tsx) #

블로그에서 사용 중인 모든 태그 목록을 출력하는 페이지입니다.

예시 URL:

unknown
/tags

역할:

  • 전체 태그 목록 표시
  • 태그별 글 개수 표시 가능
  • 콘텐츠 탐색성 향상

10. 글쓰기 에디터 (write/page.tsx) #

브라우저에서 글을 작성하기 위한 웹 기반 에디터 페이지입니다.
해당 페이지는 개발환경에서만 빌드되도록 설정하고, 배포환경(또는 export)에서는 빌드되지 않게 만들어 둘 예정입니다.

  • Markdown 에디터
  • 로컬 파일 저장
