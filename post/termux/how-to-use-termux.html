Termux에서 code-server(VSCode) 제대로 설치하는 방법 (권한 문제 해결)

Termux에서 code-server 설치 시 발생하는 접근 권한 문제를 tur-repo 기반으로 해결하고, 비밀번호 없이 안정적으로 접속하는 방법을 정리합니다.

2025. 12. 18.
#termux#code-server#vscode#android#dev-environment

들어가며 #

Termux에서 **code-server(VSCode)**를 쓰다 보면,
생각보다 사소한 문제에서 많이 막히게 됩니다.

설치는 되는데 접속이 안 되거나,
비밀번호 설정 때문에 더 꼬이거나,
분명 똑같이 따라 했는데 왜 안 되는지 모르겠는 상황이 자주 생깁니다.

이 글에서는 그런 부분들을 최대한 단순하게 정리해볼게요.
원리와 이유는 전문가 관점으로 설명하되, 표현은 최대한 쉽게 풀어보는 게 목표입니다.

왜 tur-repo를 사용하는가 #

Termux는 안드로이드 환경 위에서 동작하기 때문에
일반적인 리눅스와는 파일 접근 방식이 조금 다릅니다.

특히 /data 영역은 접근 제한이 강해서,
패키지는 설치됐지만 실제로는 제대로 동작하지 않는 경우가 있습니다.

tur-repo에서 제공하는 code-server는
이런 Termux 환경을 고려해서 빌드된 패키지라,
권한 문제로 막힐 가능성이 훨씬 적습니다.

결론적으로, Termux에서 code-server를 쓸 거라면
tur-repo 기반 설치가 가장 안정적입니다.

1. tur-repo 설치 #

bash
pkg install tur-repo

Termux에서 사용할 수 있는
사용자 전용 패키지 저장소를 추가하는 과정입니다.

2. code-server 설치 #

bash
pkg install code-server

이 명령으로 설치되는 code-server는
tur-repo에 포함된 버전입니다.

다른 경로로 설치하면
실행은 되지만 접속이 안 되거나,
확장 설치 중 오류가 나는 경우가 많습니다.

3. code-server 실행 (비밀번호 없이) #

bash
code-server --auth none --host 0.0.0.0

왜 비밀번호를 사용하지 않는가 #

비밀번호를 설정하면
인증 정보가 /data 영역에 저장됩니다.

이 영역은 일반적인 방법으로 접근이 거의 불가능하기 때문에,
비밀번호를 확인하거나 수정하기가 어렵습니다.

그래서 Termux 환경에서는
비밀번호 없이 실행(--auth none)하는 방식이
가장 단순하고 문제도 적습니다.

4. code-server 접속 방법 #

실행 후 터미널에
http://IP:PORT 형태의 주소가 출력됩니다.

이 주소를 브라우저 주소창에 그대로 입력하면
VSCode 화면에 접속할 수 있습니다.

5. 접속이 안 되면 포트 변경 #

접속이 되지 않는 경우,
가장 먼저 확인해야 할 것은 포트 충돌입니다.

포트 변경 방법 #

bash
code-server --auth none --host 0.0.0.0 --port 8081

8081 대신
다른 숫자(예: 9000, 10000 등)를 사용해도 됩니다.

다시 실행하면
출력되는 접속 주소가 바뀌며,
해당 주소로 접속하면 대부분 문제가 해결됩니다.

핵심만 정리 #

  • code-server는 tur-repo 버전 사용
  • 인증 문제를 피하려면 --auth none
  • 접속이 안 되면 포트 변경부터 시도

마무리 #

Termux + code-server 조합은
한 번만 제대로 잡아두면 꽤 안정적으로 사용할 수 있습니다.

설치 과정에서 막혔다면,
위 순서를 기준으로 하나씩 다시 확인해보세요.

대부분은 이 범위 안에서 해결됩니다.
