<li>원치 않는 조언을 부드럽게 거절할 수 있습니다.</li>
</ul>
</blockquote>

<h2 id="1-조언의-강도--6단계" tabindex="-1" data-src-line="18">1. 조언의 강도 — 6단계 <a class="header-anchor" href="#1-조언의-강도--6단계" aria-hidden="true">#</a></h2>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">약함 ←————————————————————→ 강함

Have you thought about...?
You might want to...
You could always...
If I were you, I&#039;d...
You really should...
You must / You need to...
</code></pre></div></code></pre>
<h3 id="단계별-예문" tabindex="-1" data-src-line="31">단계별 예문 <a class="header-anchor" href="#단계별-예문" aria-hidden="true">#</a></h3>
<p><strong>Have you thought about ~? / Have you considered ~?</strong> — 가장 부드러운 제안</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">Have you thought about taking a break?
잠깐 쉬는 건 생각해봤어요?

Have you considered talking to someone about it?
그 부분에 대해 누군가와 이야기해보는 건 생각해봤어요?
</code></pre></div></code></pre>
<p><strong>You might want to ~</strong> — 부드러운 권유</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">You might want to double-check that before sending.
보내기 전에 다시 확인하는 게 좋을 수도 있어요.

You might want to get a second opinion.
두 번째 의견을 구해보는 게 좋을 수도 있어요.
</code></pre></div></code></pre>
<p><strong>You could always ~</strong> — 선택지를 제시하는 방식</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">You could always ask your manager directly.
매니저한테 직접 물어볼 수도 있어요.

You could always try a different approach.
다른 방법을 시도해볼 수도 있어요.
</code></pre></div></code></pre>
<p><strong>If I were you, I’d ~</strong> — 개인적 의견을 담은 조언</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">If I were you, I&#039;d wait before making a decision.
제가 당신이라면, 결정 전에 기다릴 것 같아요.

If I were in your position, I&#039;d reach out to them first.
제가 그 자리라면, 먼저 연락할 것 같아요.
</code></pre></div></code></pre>
<p><strong>You really should ~</strong> — 강한 권고</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">You really should see a doctor about that.
그 부분은 정말 의사한테 가봐야 해요.

You really should back up your files more often.
파일을 더 자주 백업해야 해요.
</code></pre></div></code></pre>
<p><strong>You must / You need to ~</strong> — 가장 강한 강조</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">You need to address this immediately.
이것을 즉시 처리해야 해요.

You must talk to HR about this.
HR에 이것을 반드시 얘기해야 해요.
</code></pre></div></code></pre>

이건 스스로 해결해야 할 것 같아요.

<h2 id="마무리" tabindex="-1" data-src-line="278">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>조언·충고의 핵심 세 가지:</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① 강도를 상황에 맞게:
  친한 친구 → &quot;If I were you, I&#039;d...&quot;
  가벼운 제안 → &quot;Have you thought about...?&quot;
  긴급 상황 → &quot;You really need to...&quot;

② 공감 먼저, 조언 나중:
  &quot;That sounds really tough. Have you considered...?&quot;
  → 감정을 인정받은 사람이 조언을 훨씬 잘 받아들입니다.

③ 제안으로 포장하기:
  &quot;You should do X&quot; (명령처럼 들림) ❌
  &quot;It might be worth trying X&quot; (선택권 제공) ✅
</code></pre></div></code></pre>
