<p>비즈니스 글쓰기는 말하기와 다릅니다.<br>
글은 남고, 읽히고, 판단받습니다.<br>
명확하고 설득력 있는 비즈니스 영어 글쓰기는 커리어를 바꿀 수 있습니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>설득형·분석형 이메일을 구조적으로 쓸 수 있습니다.</li>
<li>보고서의 핵심 섹션(Executive Summary, Findings, Recommendations)을 작성할 수 있습니다.</li>
<li>제안서 구조와 표현을 익힐 수 있습니다.</li>
<li>능동태·수동태를 전략적으로 선택할 수 있습니다.</li>
</ul>
</blockquote>

<h2 id="4-능동태-vs-수동태-전략" tabindex="-1" data-src-line="178">4. 능동태 vs 수동태 전략 <a class="header-anchor" href="#4-능동태-vs-수동태-전략" aria-hidden="true">#</a></h2>
<p>비즈니스 글쓰기에서 능동태와 수동태는 각각 다른 효과를 냅니다.</p>
<h3 id="능동태--명확하고-강력함" tabindex="-1" data-src-line="182">능동태 — 명확하고 강력함 <a class="header-anchor" href="#능동태--명확하고-강력함" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">✅ We analyzed the data and found three key issues.
   (저희가 데이터를 분석해 세 가지 핵심 문제를 발견했습니다.)

✅ The team delivered the project on time.
   (팀이 제때 프로젝트를 납품했습니다.)

→ 책임 소재가 명확, 직접적, 읽기 쉬움
</code></pre></div></code></pre>
<h3 id="수동태--객관적이고-격식체" tabindex="-1" data-src-line="194">수동태 — 객관적이고 격식체 <a class="header-anchor" href="#수동태--객관적이고-격식체" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">✅ The data was analyzed and three key issues were identified.
   (데이터가 분석됐고 세 가지 핵심 문제가 확인됐습니다.)

✅ It is recommended that the project be reviewed.
   (프로젝트 검토가 권고됩니다.)

→ 책임 소재를 흐리거나, 객관성 강조, 공식 보고서에 적합
</code></pre></div></code></pre>
<h3 id="언제-어떤-것을" tabindex="-1" data-src-line="206">언제 어떤 것을? <a class="header-anchor" href="#언제-어떤-것을" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">능동태 사용:
- 이메일 (특히 설득형)
- 행동 요청
- 명확한 의사 전달이 필요할 때

수동태 사용:
- 공식 보고서
- 나쁜 소식을 부드럽게 전달할 때
- 책임 소재보다 결과에 집중할 때
- &quot;Mistakes were made.&quot; (= 누가 실수했는지 안 말하고)
</code></pre></div></code></pre>

<h2 id="5-데이터-기반-글쓰기-언어" tabindex="-1" data-src-line="223">5. 데이터 기반 글쓰기 언어 <a class="header-anchor" href="#5-데이터-기반-글쓰기-언어" aria-hidden="true">#</a></h2>
<p>차트·그래프를 설명하거나 수치를 인용할 때:</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">【증가】
...increased by 20% / rose sharply / surged / climbed
...jumped from X to Y / grew significantly

【감소】
...decreased by 15% / fell / dropped / declined
...plummeted / dipped / contracted

【유지·안정】
...remained stable / held steady / plateaued
...leveled off / showed little change

【비교】
Compared to last year, ...
전년 대비, ...

X outperformed Y by a significant margin.
X가 Y를 상당히 앞질렀습니다.

The results were broadly in line with expectations.
결과는 대체로 기대에 부합했습니다.

<h2 id="마무리" tabindex="-1" data-src-line="303">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>

<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① 구조를 먼저:
