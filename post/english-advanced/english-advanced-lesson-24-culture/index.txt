<h2 id="1-직접적-문화-vs-간접적-문화" tabindex="-1" data-src-line="21">1. 직접적 문화 vs 간접적 문화 <a class="header-anchor" href="#1-직접적-문화-vs-간접적-문화" aria-hidden="true">#</a></h2>
<h3 id="직접적-소통-문화-low-context" tabindex="-1" data-src-line="23">직접적 소통 문화 (Low-context) <a class="header-anchor" href="#직접적-소통-문화-low-context" aria-hidden="true">#</a></h3>
<p>미국, 독일, 네덜란드, 북유럽</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">특징:
- 말하는 내용이 의미의 대부분
- &quot;No&quot;를 직접적으로 말하는 것이 정직함
- 모호한 표현을 피함
- 침묵 = 어색함

예:
&quot;I disagree with that approach.&quot;
&quot;I can&#039;t make it to the meeting.&quot;
&quot;That doesn&#039;t work for me.&quot;
</code></pre></div></code></pre>
<h3 id="간접적-소통-문화-high-context" tabindex="-1" data-src-line="40">간접적 소통 문화 (High-context) <a class="header-anchor" href="#간접적-소통-문화-high-context" aria-hidden="true">#</a></h3>
<p>일본, 한국, 중국, 중동, 라틴아메리카, (정도는 덜하지만) 영국</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">특징:
- 말 너머의 맥락·관계가 중요
- 직접적인 거절을 피함
- 분위기와 관계 유지가 우선
- 침묵도 소통의 일부

&quot;Maybe&quot; = 아마 No
&quot;That could be difficult&quot; = No
&quot;We&#039;ll see&quot; = 아마 No
&quot;I&#039;ll try&quot; = 확신 없음
</code></pre></div></code></pre>
<h3 id="영어권에서의-간접적-표현" tabindex="-1" data-src-line="57">영어권에서의 간접적 표현 <a class="header-anchor" href="#영어권에서의-간접적-표현" aria-hidden="true">#</a></h3>
<p>영국, 캐나다, 호주는 미국보다 훨씬 간접적입니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">영국인이 말하는 것 → 실제 의미:
&quot;That&#039;s quite interesting.&quot; → &quot;별로야.&quot;
&quot;I might be wrong, but...&quot; → &quot;내가 맞고 넌 틀렸어.&quot;
&quot;Not bad.&quot; → &quot;꽤 좋아.&quot;
&quot;Could be better.&quot; → &quot;나빠.&quot;
&quot;I hear what you&#039;re saying.&quot; → &quot;동의 안 해.&quot;
&quot;We should do this again sometime.&quot; → &quot;안 만날 거야.&quot;
</code></pre></div></code></pre>

<h2 id="5-칭찬거절사과의-문화적-차이" tabindex="-1" data-src-line="184">5. 칭찬·거절·사과의 문화적 차이 <a class="header-anchor" href="#5-칭찬거절사과의-문화적-차이" aria-hidden="true">#</a></h2>
<h3 id="칭찬" tabindex="-1" data-src-line="186">칭찬 <a class="header-anchor" href="#칭찬" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">미국: 자주, 구체적으로, 열정적으로
&quot;That was absolutely incredible work!&quot;

영국: 절제, 칭찬도 understatement
&quot;Not bad at all, actually.&quot; (= 정말 잘했어)

한국 문화 vs 영어권:
한국: 칭찬을 겸손하게 거부하는 것이 예의
영어권: 칭찬을 거부하면 상대방의 판단을 무시하는 것처럼 들릴 수 있음

✅ 영어로 칭찬받을 때:
&quot;Thank you! I really enjoyed working on it.&quot;
</code></pre></div></code></pre>
<h3 id="거절" tabindex="-1" data-src-line="203">거절 <a class="header-anchor" href="#거절" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">미국: 이유를 들어 직접적으로
&quot;I&#039;m sorry, I&#039;m not available that day.&quot;

영국: 간접적으로, 이유를 흐리게
&quot;That might be a bit difficult.&quot;

한국 문화 vs 영어권:
한국: &quot;No&quot;가 즉각적이지 않을 수 있음, 상황을 읽어야 함
영어권: 명확한 Yes/No를 선호

✅ 영어로 거절할 때:
명확하게, 하지만 부드럽게:
&quot;I appreciate you thinking of me, but I won&#039;t be able to.&quot;
</code></pre></div></code></pre>
<h3 id="사과" tabindex="-1" data-src-line="221">사과 <a class="header-anchor" href="#사과" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">캐나다: 가장 자주, 때로는 과하게 (&quot;Sorry!&quot;)
미국: 상황이 심각할 때 진지하게
영국: 자주 사용하지만 진심과 의례적 사과가 섞임
