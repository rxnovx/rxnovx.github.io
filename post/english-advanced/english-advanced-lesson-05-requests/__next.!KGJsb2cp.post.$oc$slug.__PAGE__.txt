<p>친한 친구에게 하는 부탁과 처음 만난 상사에게 하는 부탁은 완전히 달라야 합니다.<br>
영어는 이 차이를 <strong>요청의 형식</strong>으로 명확히 구분합니다.</p>
<p>같은 &quot;도와줄 수 있어?&quot;도 이렇게 다릅니다:</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">Help me.                           (명령, 매우 직접적)
Can you help me?                   (비격식)
Could you help me?                 (정중)
Would you mind helping me?         (더 정중)
I was wondering if you could help me.  (매우 정중)
Would it be possible for you to help me? (초격식)
</code></pre></div></code></pre>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>정중도 6단계를 상황에 맞게 완벽히 구사할 수 있습니다.</li>
<li>“Would you mind ~ing?” 패턴을 완전히 정복할 수 있습니다.</li>
<li>거절하기 어려운 부탁을 부드럽게 거절할 수 있습니다.</li>
<li>직장·일상의 다양한 상황에서 적절한 요청 표현을 선택할 수 있습니다.</li>
</ul>
</blockquote>

<h2 id="1-요청의-정중도-6단계" tabindex="-1" data-src-line="29">1. 요청의 정중도 6단계 <a class="header-anchor" href="#1-요청의-정중도-6단계" aria-hidden="true">#</a></h2>
<h3 id="단계-1--직접-명령-매우-비격식강압적" tabindex="-1" data-src-line="31">단계 1 — 직접 명령 (매우 비격식·강압적) <a class="header-anchor" href="#단계-1--직접-명령-매우-비격식강압적" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">Sit down.
Come here.
Help me with this.
Don&#039;t do that.
</code></pre></div></code></pre>
<p>친한 사이에서도 자칫 무례하게 들릴 수 있습니다.<br>
Please를 붙이면 약간 부드러워집니다: “Sit down, please.”</p>
<hr>
<h3 id="단계-2--can-you--will-you-비격식" tabindex="-1" data-src-line="45">단계 2 — Can you…? / Will you…? (비격식) <a class="header-anchor" href="#단계-2--can-you--will-you-비격식" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">Can you help me?
Can you send me the file?
Will you be there tonight?
Can you speak up a bit?
</code></pre></div></code></pre>
<p>친구, 가족, 가까운 동료에게 자연스럽습니다.<br>
낯선 사람에게 쓰면 약간 직접적으로 들릴 수 있습니다.</p>
<hr>
<h3 id="단계-3--could-you--would-you-정중" tabindex="-1" data-src-line="59">단계 3 — Could you…? / Would you…? (정중) <a class="header-anchor" href="#단계-3--could-you--would-you-정중" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">Could you help me with this?
Could you send the report by Friday?
Would you mind moving your bag?
Would you be able to join the call?
</code></pre></div></code></pre>
<p>대부분의 직장 상황에 적절합니다.<br>
<strong>Can → Could</strong>로만 바꿔도 훨씬 정중해집니다.</p>
<hr>
<h3 id="단계-4--would-you-mind-ing-더-정중" tabindex="-1" data-src-line="73">단계 4 — Would you mind ~ing? (더 정중) <a class="header-anchor" href="#단계-4--would-you-mind-ing-더-정중" aria-hidden="true">#</a></h3>
<p>상대방의 불편함을 배려하는 표현입니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">Would you mind closing the window?
창문 닫아주시겠어요?

Would you mind waiting for a moment?
잠시 기다려주시겠어요?

Would you mind if I opened the window?
창문을 열어도 될까요?
(Would you mind if + 주어 + 과거동사 = 내가 ~해도 될까?)
</code></pre></div></code></pre>
<p>⚠️ <strong>중요</strong>: Would you mind ~?의 대답</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">질문: Would you mind helping me?
→ 도와줘도 괜찮겠어요? (= 도와줄 의향이 있으세요?)

대답:
✅ 괜찮다 (도와줄게요):
   &quot;Not at all.&quot; / &quot;Of course not.&quot; / &quot;No problem.&quot;

❌ 틀린 대답:
   &quot;Yes, I will.&quot; → &quot;Yes, I mind.&quot; (= 싫어요)가 되어버림!
</code></pre></div></code></pre>

<h3 id="단계-5--i-was-wondering-if-you-could-매우-정중" tabindex="-1" data-src-line="105">단계 5 — I was wondering if you could… (매우 정중) <a class="header-anchor" href="#단계-5--i-was-wondering-if-you-could-매우-정중" aria-hidden="true">#</a></h3>

<h2 id="3-간접-요청-전략" tabindex="-1" data-src-line="159">3. 간접 요청 전략 <a class="header-anchor" href="#3-간접-요청-전략" aria-hidden="true">#</a></h2>
<p>직접 요청하지 않고 상황을 설명하여 상대방이 자연스럽게 도와주게 만드는 기술입니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">직접 요청: Can you open the window?
간접 표현: It&#039;s really warm in here, isn&#039;t it?
           (여기 정말 따뜻하죠? → 창문 열어줄 것 같은 암시)

직접 요청: Can you help me with this?
간접 표현: I&#039;m really struggling with this part.
           (이 부분 정말 힘드네요 → 도움을 자연스럽게 유도)

직접 요청: Turn down the music, please.
간접 표현: I&#039;m having a bit of trouble concentrating.
           (집중하기가 좀 어렵네요 → 소음을 줄여달라는 암시)
</code></pre></div></code></pre>
<p>⚠️ 이런 간접 표현은 문화에 따라 통하는 정도가 다릅니다.<br>
직접적인 문화(미국, 독일 등)에서는 명확한 요청이 더 효율적일 수 있습니다.</p>

<h3 id="대답-정리" tabindex="-1" data-src-line="350">대답 정리 <a class="header-anchor" href="#대답-정리" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">부탁을 들어줄 때 (거리낌 없어요):

&quot;Of course not.&quot; ✅
&quot;Go ahead.&quot; ✅
&quot;Sure, no problem.&quot; ✅

부탁을 거절할 때 (좀 불편해요):
&quot;Actually, I&#039;m afraid that&#039;s not possible.&quot;
&quot;I&#039;m sorry, but I do mind, actually.&quot;
&quot;Unfortunately, that doesn&#039;t work for me.&quot;
</code></pre></div></code></pre>

<h2 id="8-실수하면-어색해지는-top-5" tabindex="-1" data-src-line="367">8. 실수하면 어색해지는 TOP 5 <a class="header-anchor" href="#8-실수하면-어색해지는-top-5" aria-hidden="true">#</a></h2>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ Can you please to help me?
✅ Can you please help me?
   (please to 불가 — please + 동사원형)

❌ Would you mind to close the window?
✅ Would you mind closing the window?
   (Would you mind + 동사ing)

❌ I was wondering if you can help.
✅ I was wondering if you could help.
   (간접 요청에는 could가 더 자연스러움)

❌ Yes, I don&#039;t mind. (Would you mind...?에 대한 답으로 틀린 경우)
→ 문맥에 따라 맞을 수도 있지만,
✅ Not at all. / Of course not. (더 명확한 수락 표현)

❌ Could you possibly maybe help me?
✅ Could you possibly help me?
   (possibly / maybe 중 하나만 사용)
</code></pre></div></code></pre>

<h2 id="9-실전-회화--직장일상에서의-정중한-요청" tabindex="-1" data-src-line="393">9. 실전 회화 — 직장·일상에서의 정중한 요청 <a class="header-anchor" href="#9-실전-회화--직장일상에서의-정중한-요청" aria-hidden="true">#</a></h2>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">【상황 1: 상사에게 마감 연장 요청】

          for a moment about the deadline.

          extend the deadline by two days.
          마감을 이틀 연장해주신다면 정말 감사하겠어요.
          
          I want to make sure the quality is up to standard,
          and I&#039;m currently working through a few final issues.
          품질 기준을 맞추고 싶은데,
          지금 마지막 몇 가지 문제를 처리하고 있어서요.

Manager:  That should be fine. Could you send me
          an update by end of day tomorrow, though?
          괜찮아요. 하지만 내일 업무 종료 전에
          업데이트 보내줄 수 있어요?

Employee: Absolutely. I&#039;ll make sure to do that.
