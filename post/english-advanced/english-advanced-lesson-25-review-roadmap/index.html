들어가기 앞서 #

25강까지 왔습니다. 정말 대단합니다.

이 강에서는 전체 시리즈의 핵심 포인트를 빠르게 복습하고,
B2를 넘어 C1으로 가기 위한 실질적인 로드맵을 제시합니다.

영어는 목적지가 아닙니다. 계속 성장하는 여정입니다.

Part 1 복습 — 뉘앙스와 어감 #

핵심 정리 #

plain
【1강: 말하기 동사】
say + 내용 / tell + 사람 + 내용
speak (격식, 언어능력) / talk (비격식, 쌍방향)
mention (가볍게) / discuss (깊이)
❌ discussed about / ❌ mentioned about

【2강: 감정 표현】
기쁨: content → pleased → happy → delighted → thrilled → ecstatic
슬픔: down → sad → upset → heartbroken → devastated
분노: annoyed → frustrated → angry → furious → livid
-ing = 감정 유발 / -ed = 감정을 느끼는 사람

【3강: 동의·반론】
완전 동의: "I couldn't agree more."
부분 동의: "I see your point, but..."
부드러운 반론: "I'd push back a little on that."
강한 반론: "I strongly disagree."

【4강: 확실성】
must(~임이 틀림없다) → should(예상) → may(가능) → might(불확실) → can't(불가능)
definitely → probably → possibly → maybe → unlikely

【5강: 요청】
Can you? → Could you? → Would you mind ~ing?
→ I was wondering if you could...
→ Would it be possible to...?

Part 2 복습 — 슬랭과 구어체 #

핵심 정리 #

plain
【6강: 미국 슬랭】
fire / lit / slay / bussin / GOAT (긍정)
bet / no cap / facts / fr (동의·확인)
sus / cringe / L / canceled (부정)
lowkey / highkey / vibe / ghosting (감정·관계)

【7강: 영국 슬랭】
brilliant / gutted / knackered / chuffed (감정)
dodgy / fit / proper / well (묘사)
cheers / sorted / spot on / mate (일상)
영국식 understatement: "Quite good" = 아주 좋아

【8강: 구동사】
직장: pull off / follow up / come up with / wrap up
관계: fall for / drift apart / open up / get over
문제 해결: sort out / figure out / narrow down / break down

【9강: 관용어】
시작: get the ball rolling
비즈니스: on the same page / bite the bullet / cut corners
갈등: bury the hatchet / clear the air / meet halfway
성공·실패: go the extra mile / miss the boat / back to square one

【10강: 유머】
Pun 구조: Setup → Punchline (반전)
아이러니 = 상황 반전 / 사르카즘 = 의도적 비꼬기
자기 비하 유머 (영국식), 건조한 유머 (dry humor)

Part 3 복습 — 비즈니스 영어 #

핵심 정리 #

plain
【11강: 회의】
시작: "Let's kick things off." / "Shall we get started?"
발언권: "Can I just add..." / "I'd like to build on that."
확인: "Just to clarify..." / "If I understand correctly..."
마무리: "Let's wrap up." / "Action items: ..."

【12강: 프레젠테이션】
Hook → 본론 → 결론 구조
전환: "Moving on to..." / "Turning now to..."
데이터: spike / plateau / steady decline
Q&A: "That's a great question." / "Let me come back to that."

【13강: 협상】
입장 제시: "Our starting point is..."
양보: "We'd be willing to..." / "We could consider..."
타협: "Could we meet halfway?" / "What if we split the difference?"
결렬: "I'd like to leave the door open."

【14강: 전화·영상통화】
전화 걸기: "This is [이름] calling from [회사]."
영상통화: "You're on mute." / "You're breaking up."
메시지: "Could I take your name and number?"
마무리: "I'll follow up by email."

【15강: 비즈니스 글쓰기】
구조: 목적 → 근거 → 요청 → 행동
능동태 = 직접적 / 수동태 = 격식·객관적
데이터 언어: surge / plateau / decline / outperform

Part 4 복습 — 일상 심화 #

핵심 정리 #

plain
【16강: 스토리텔링】
시작: "You're not going to believe this..."
긴장감: "And then, out of nowhere..."
극적 현재: 과거 이야기를 현재 시제로 → 생동감
클라이맥스: "Turns out..." / "That's when I realized..."

【17강: 사과·감사·칭찬】
사과 깊이: Oops → Sorry → I apologize → I sincerely apologize
감사 + 이유: "Thank you for believing in me."
칭찬 수락: "That's so kind of you to say. Thank you!"

【18강: 조언】
강도: Have you thought about? → You might want to → You really should → You must
공감 먼저: "That sounds really tough. Have you considered...?"
거절: "I'm not looking for advice right now — I just needed to vent."

【19강: 컴플레인】
정중: "I'm afraid there seems to be a problem with..."
강하게: "This is completely unacceptable."
받는 입장: "I completely understand your frustration. Let me look into this."

【20강: 소셜 영어】
시작: "How do you know [host]?" / FORD (Family, Occupation, Recreation, Dreams)
이어가기: "How did you get into that?" / "What do you enjoy most?"
마무리: "I don't want to monopolize your evening..."

Part 5 복습 — 미디어·문화 #

핵심 정리 #

plain
【21강: 뉴스·미디어】
헤드라인: 현재형=과거, to부정사=미래, 관사 생략
편향 신호: "claims" vs "says", "regime" vs "government"
BBC(격식·절제) / CNN(드라마틱) / NPR(스토리·분석)

【22강: 드라마·영화】
섀도잉 5단계: 듣기 → 스크립트 → 소리 내어 읽기 → 오버랩 → 스크립트 없이
연음: gonna / wanna / gotta / lemme / dunno
자막 없이 4단계 접근법

【23강: 소셜미디어】
마침표 = 차갑게 들릴 수 있음 / ALL CAPS = 소리 지르기
플랫폼: Twitter(짧고 위트) / Instagram(감성) / LinkedIn(전문)
약어: TBH / NGL / IMO / FYI / ICYMI / TL;DR

【24강: 문화 차이】
직접적: 미국, 호주 / 간접적: 영국, 캐나다
영국 understatement: "That's quite interesting" = "별로야"
금기: 수입·나이·정치·종교 (처음 만날 때)
칭찬: 영어권에서는 거부하지 않고 받아들이기

나만의 영어 스타일 만들기 #

B2 레벨에 도달했다면, 이제 단순히 "맞는 영어"가 아닌
나다운 영어를 만들 차례입니다.

스타일 체크리스트 #

plain
□ 나는 격식체와 비격식체를 상황에 맞게 전환할 수 있다.
□ 나는 감정을 정확한 강도로 표현할 수 있다.
□ 나는 유머를 한두 개씩 자연스럽게 넣을 수 있다.
□ 나는 조언을 강요하지 않고 제안으로 표현할 수 있다.
□ 나는 반론을 상대방을 존중하며 표현할 수 있다.
□ 나는 침묵이 불편하지 않게 대화를 이어갈 수 있다.

나만의 스타일 찾기 #

plain
내가 자주 쓰고 싶은 표현 3가지를 정하세요:
예: "That said..." / "I'd push back on that." / "Turns out..."

이 표현들을 일주일 동안 의식적으로 써보세요.
→ 한 달 후에 자연스럽게 나오기 시작합니다.

C1 레벨을 향한 로드맵 #

B2와 C1의 차이 #

plain
B2 (중상급):
- 복잡한 주제를 이해하고 논의할 수 있다.
- 유창하게 소통하지만 가끔 찾아야 하는 표현이 있다.
- 뉘앙스와 함축적 의미를 어느 정도 파악한다.

C1 (고급):
- 즉흥적으로, 유창하게, 자연스럽게 표현한다.
- 사회적·직업적·학문적 상황에서 효과적으로 활용한다.
- 미묘한 뉘앙스, 아이러니, 유머를 완전히 이해한다.
- 복잡한 아이디어를 명확하고 구조적으로 표현한다.

C1을 향한 3가지 집중 영역 #

plain
1. 어휘의 정밀도 높이기
   "happy" → "content / pleased / delighted / elated / ecstatic"
   정확한 단어를 고르는 연습을 매일 하세요.

2. 말하기 유창성
   섀도잉 매일 15분 → 사고와 발화 사이의 딜레이 줄이기
   말하는 속도보다 자연스러운 흐름이 중요합니다.

3. 읽기의 깊이
   영어 원서 · 영어 기사 매일 읽기
   모르는 단어를 찾지 말고 맥락으로 추론하는 연습

추천 학습 자료 #

읽기 #

plain
뉴스:
- The Guardian (영국식 영어, 다양한 주제)
- NPR (미국식, 이야기체)
- BBC News (격식체, 국제적 시각)

원서 (B2 → C1 수준):
- "The Hitchhiker's Guide to the Galaxy" (가볍고 위트 있음)
- "Educated" by Tara Westover (회고록, 아름다운 문체)
- "Atomic Habits" (비즈니스·자기계발)

듣기·말하기 #

plain
팟캐스트:
- This American Life (스토리텔링 영어)
- TED Talks (다양한 주제, 명확한 발음)
- The Daily (뉴스 영어)
- Conan O'Brien Needs a Friend (유머·구어체)

유튜브:
- Kurzgesagt (복잡한 개념을 쉬운 영어로)
- TED-Ed (교육적, 명확한 발음)

앱 #

plain
- Anki: 나만의 단어장 플래시카드
- HelloTalk: 원어민과 언어 교환
- Speechling: 발음 교정
- Elsa Speak: AI 발음 코치

마지막 메시지 #

plain
이 시리즈를 통해 여러분은:

✅ 뉘앙스를 구분하는 눈을 얻었습니다.
✅ 슬랭과 구어체로 생동감 있게 말할 수 있게 됐습니다.
✅ 비즈니스 영어로 전문적으로 소통할 수 있습니다.
✅ 일상에서 더 자연스럽고 풍부하게 표현할 수 있습니다.
✅ 미디어와 문화 차이를 이해하는 시각을 가졌습니다.

B2는 끝이 아닙니다.
이제 영어가 도구가 됐습니다.
그 도구로 무엇을 만들지는 여러분의 몫입니다.

Keep going. You've got this.
계속 하세요. 할 수 있어요.
