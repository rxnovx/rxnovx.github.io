<p>영어를 배울 때 감정 표현은 보통 이렇게 시작합니다.</p>
<ul>
<li>기쁘다 → happy</li>
<li>슬프다 → sad</li>
<li>화났다 → angry</li>
</ul>
<p>하지만 원어민은 이 세 단어만으로는 감정을 제대로 전달하지 않습니다.<br>
같은 &quot;기쁨&quot;이어도 <strong>조용한 만족감</strong>인지, <strong>뛸 듯한 흥분</strong>인지에 따라 완전히 다른 단어를 씁니다.</p>
<p>감정 표현을 정밀하게 쓸수록 여러분의 영어는 훨씬 <strong>입체적이고 자연스럽게</strong> 들립니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>긍정 감정의 강도 스펙트럼을 완벽히 구분할 수 있습니다.</li>
<li>부정 감정(슬픔·분노·두려움·놀라움)을 세밀하게 표현할 수 있습니다.</li>
<li>과장 표현과 절제 표현을 상황에 맞게 선택할 수 있습니다.</li>
<li>감정을 자연스럽게 전달하는 문장 패턴을 익힐 수 있습니다.</li>
</ul>
</blockquote>

<p>기쁨을 나타내는 단어들은 <strong>강도</strong> 순서로 배열됩니다.<br>
단어가 강할수록 더 강렬하고 표현적인 감정입니다.</p>
<h3 id="기쁨-스펙트럼-약--강" tabindex="-1" data-src-line="31">기쁨 스펙트럼 (약 → 강) <a class="header-anchor" href="#기쁨-스펙트럼-약--강" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">content → pleased → glad → happy → delighted → thrilled → ecstatic
(만족)    (흡족)   (다행) (행복) (아주 기쁜)  (설레는)   (황홀한)
</code></pre></div></code></pre>
<h3 id="각-단어별-뉘앙스" tabindex="-1" data-src-line="38">각 단어별 뉘앙스 <a class="header-anchor" href="#각-단어별-뉘앙스" aria-hidden="true">#</a></h3>
<p><strong>content</strong> — 조용한 만족감. 흥분보다는 평온한 충족감.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m content with my life right now.
나는 지금 내 삶에 만족하고 있습니다.

She seemed perfectly content just reading by the window.
그녀는 창가에서 책을 읽는 것만으로 완전히 만족스러워 보였습니다.
</code></pre></div></code></pre>
<p><strong>pleased</strong> — 흡족함. 기대가 충족됐을 때의 긍정적 반응.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m pleased to meet you.
만나서 반갑습니다. (격식체)

She was pleased with the results.
그녀는 결과에 만족했습니다.

We&#039;re pleased to announce...
~을 발표하게 되어 기쁩니다. (공식 발표에 자주 쓰임)
</code></pre></div></code></pre>
<p><strong>glad</strong> — 안도감이 섞인 기쁨. &quot;다행이다&quot;에 가까운 뉘앙스.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m glad you could make it.
오실 수 있어서 다행이에요.

I&#039;m glad to hear you&#039;re feeling better.
몸이 좋아졌다니 다행이에요.

I&#039;m so glad that&#039;s over.
그게 끝나서 정말 다행이에요.
</code></pre></div></code></pre>
<p><strong>happy</strong> — 가장 일반적인 행복감. 중간 강도.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m really happy for you!
정말 잘 됐다!

Are you happy with your decision?
당신의 결정에 만족하나요?
</code></pre></div></code></pre>
<p><strong>delighted</strong> — 즐거움이 넘치는 상태. 격식체에서도 자주 쓰임.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m absolutely delighted!
정말 너무 기쁩니다!

She was delighted to receive the award.
그녀는 상을 받아 매우 기뻐했습니다.

We&#039;d be delighted to join you.
함께하게 되어 정말 기쁠 것 같아요. (초대 수락 시 격식체)
</code></pre></div></code></pre>
<p><strong>thrilled</strong> — 흥분과 기대감이 섞인 강렬한 기쁨.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m thrilled about the new project!
새 프로젝트 생각에 너무 설레요!

She was thrilled to get the job offer.
그녀는 입사 제안을 받고 너무 기뻐했습니다.

The kids were absolutely thrilled.
아이들은 정말 신이 났습니다.
</code></pre></div></code></pre>
<p><strong>ecstatic</strong> — 최고조의 기쁨. 거의 황홀할 정도.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">We were ecstatic when we heard the news.
그 소식을 들었을 때 우리는 너무너무 기뻤습니다.

She was ecstatic about getting into her dream school.
그녀는 꿈에 그리던 학교에 합격해서 황홀해했습니다.
</code></pre></div></code></pre>

<h2 id="3-부정-감정의-스펙트럼--슬픔" tabindex="-1" data-src-line="187">3. 부정 감정의 스펙트럼 — 슬픔 <a class="header-anchor" href="#3-부정-감정의-스펙트럼--슬픔" aria-hidden="true">#</a></h2>

<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;ve been feeling a bit down lately.

</code></pre></div></code></pre>
<p><strong>sad</strong> — 일반적인 슬픔.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m sad to see you go.

</code></pre></div></code></pre>
<p><strong>unhappy</strong> — 불만족스럽거나 불행한 상태. 지속적인 슬픔.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">She was deeply unhappy in her job.
그녀는 자신의 일에 깊이 불행해했습니다.
</code></pre></div></code></pre>
<p><strong>upset</strong> — 정서적으로 동요된 상태. 슬픔+불쾌함 복합.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">Don&#039;t be upset — it wasn&#039;t your fault.

그 소식을 들었을 때 정말 속상했어요.
</code></pre></div></code></pre>
<p><strong>heartbroken</strong> — 마음이 깊이 상한 상태. 사랑이나 가까운 관계의 상실.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">She was heartbroken after the breakup.

</code></pre></div></code></pre>
<p><strong>devastated</strong> — 완전히 무너진 상태. 감당하기 어려운 충격.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">We were devastated by the loss.

그 역할을 맡지 못했을 때 그녀는 정말 망연자실했습니다.
</code></pre></div></code></pre>

<h2 id="4-부정-감정의-스펙트럼--분노" tabindex="-1" data-src-line="257">4. 부정 감정의 스펙트럼 — 분노 <a class="header-anchor" href="#4-부정-감정의-스펙트럼--분노" aria-hidden="true">#</a></h2>
<h3 id="분노-스펙트럼-약--강" tabindex="-1" data-src-line="259">분노 스펙트럼 (약 → 강) <a class="header-anchor" href="#분노-스펙트럼-약--강" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">a bit annoyed → irritated → frustrated → angry → furious → livid / enraged
(약간 짜증)    (짜증난)    (답답한)     (화난)   (격분한)   (극도로 분노한)
</code></pre></div></code></pre>
<p><strong>annoyed</strong> — 작은 일에 짜증이 난 상태.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I was a bit annoyed by the noise.

</code></pre></div></code></pre>
<p><strong>irritated</strong> — annoyed보다 약간 더 강한 짜증.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">She was clearly irritated by his comments.
그녀는 그의 발언에 분명히 짜증을 냈습니다.
</code></pre></div></code></pre>
<p><strong>frustrated</strong> — 원하는 대로 되지 않아 답답하고 화가 난 상태.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m so frustrated — nothing is working.
너무 답답해요 — 아무것도 안 되네요.

He was frustrated with the lack of progress.
그는 진전이 없는 것에 답답해했습니다.
</code></pre></div></code></pre>
<p><strong>angry</strong> — 일반적인 화남.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m not angry, I&#039;m disappointed.
화난 게 아니라 실망한 거예요.

She&#039;s angry about what happened.
그녀는 일어난 일에 화가 났어요.
</code></pre></div></code></pre>
<p><strong>furious</strong> — 강렬하게 화난 상태.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">He was absolutely furious.
그는 정말 화가 났습니다.

I was furious when I found out.
알게 됐을 때 나는 분노가 치밀었습니다.
</code></pre></div></code></pre>
<p><strong>livid / enraged</strong> — 극도의 분노. 통제가 어려울 정도.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">She was absolutely livid.
그녀는 완전히 노발대발했습니다.

The crowd became enraged.
군중은 격분했습니다.
</code></pre></div></code></pre>

<h2 id="5-부정-감정의-스펙트럼--두려움불안" tabindex="-1" data-src-line="319">5. 부정 감정의 스펙트럼 — 두려움·불안 <a class="header-anchor" href="#5-부정-감정의-스펙트럼--두려움불안" aria-hidden="true">#</a></h2>
<h3 id="두려움-스펙트럼-약--강" tabindex="-1" data-src-line="321">두려움 스펙트럼 (약 → 강) <a class="header-anchor" href="#두려움-스펙트럼-약--강" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">uneasy → nervous → worried → anxious → scared → terrified → petrified
(불편한) (긴장된)  (걱정되는) (불안한)   (무서운)  (겁에 질린) (완전 굳어버린)
</code></pre></div></code></pre>
<p><strong>uneasy</strong> — 뭔가 찜찜하고 불편한 느낌.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I have an uneasy feeling about this.
이것에 대해 왠지 불편한 느낌이 들어요.
</code></pre></div></code></pre>
<p><strong>nervous</strong> — 앞으로의 일에 대한 긴장감.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m nervous about the interview.
인터뷰가 긴장돼요.

She always gets nervous before a performance.
그녀는 공연 전에 항상 긴장합니다.
</code></pre></div></code></pre>
<p><strong>worried</strong> — 걱정하는 상태. 지속적인 불안.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m worried about you.
당신이 걱정돼요.

Don&#039;t worry — everything will be fine.
걱정하지 마요 — 다 잘 될 거예요.
</code></pre></div></code></pre>
<p><strong>anxious</strong> — 걱정+긴장이 복합된 상태. 심리적으로 불안한.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">She felt anxious about moving to a new city.
새로운 도시로 이사하는 것에 불안함을 느꼈습니다.

I&#039;ve been feeling really anxious lately.
요즘 많이 불안하더라고요.
</code></pre></div></code></pre>
<p><strong>scared</strong> — 무섭다. 직접적인 두려움.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I was scared of failing.
실패하는 게 무서웠어요.

Don&#039;t be scared — I&#039;m right here.
무서워하지 마요 — 내가 바로 여기 있어요.
</code></pre></div></code></pre>
<p><strong>terrified</strong> — 매우 강한 공포.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">She was terrified of spiders.
그녀는 거미를 너무나 무서워했습니다.

I&#039;m terrified of public speaking.
대중 앞에서 말하는 게 정말 무서워요.
</code></pre></div></code></pre>
<p><strong>petrified</strong> — 너무 무서워서 몸이 굳어버린 상태.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I was absolutely petrified.
너무 무서워서 몸이 완전히 굳었어요.
</code></pre></div></code></pre>

<h2 id="6-부정-감정의-스펙트럼--놀라움충격" tabindex="-1" data-src-line="387">6. 부정 감정의 스펙트럼 — 놀라움·충격 <a class="header-anchor" href="#6-부정-감정의-스펙트럼--놀라움충격" aria-hidden="true">#</a></h2>
<h3 id="놀라움-스펙트럼-긍정부정-공통" tabindex="-1" data-src-line="389">놀라움 스펙트럼 (긍정·부정 공통) <a class="header-anchor" href="#놀라움-스펙트럼-긍정부정-공통" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">surprised → shocked → stunned → astounded → flabbergasted
(놀란)      (충격받은)  (경악한)   (깜짝 놀란)   (너무 놀라 말이 안 나오는)
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I was surprised to see you here.

We were stunned by the announcement.
우리는 그 발표에 경악했습니다.

그녀의 연기에 완전히 감탄했습니다.

(비격식체, 유머스러운 뉘앙스 가능)
</code></pre></div></code></pre>

<h2 id="7-과장-표현-vs-절제-표현" tabindex="-1" data-src-line="416">7. 과장 표현 vs 절제 표현 <a class="header-anchor" href="#7-과장-표현-vs-절제-표현" aria-hidden="true">#</a></h2>
<p>영어에서는 감정을 <strong>과장</strong>하거나 <strong>절제</strong>하는 방식이 문화와 상황에 따라 크게 다릅니다.</p>
<h3 id="과장-표현-intensifiers" tabindex="-1" data-src-line="420">과장 표현 (Intensifiers) <a class="header-anchor" href="#과장-표현-intensifiers" aria-hidden="true">#</a></h3>
<p>감정 앞에 강조 부사를 붙여 강도를 높입니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">absolutely / totally / completely / utterly / incredibly / ridiculously
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m absolutely thrilled!
I&#039;m completely devastated.
That&#039;s utterly ridiculous!
I was totally shocked.
She was incredibly excited.
That was ridiculously funny.
</code></pre></div></code></pre>
<p><strong>감탄사 표현:</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m over the moon! (너무 기뻐서 달 위에 있는 것 같아요!)
I&#039;m on cloud nine! (너무 행복해요!)
I&#039;m losing my mind with excitement!
I could cry, I&#039;m so happy!
This is literally the best day of my life!
</code></pre></div></code></pre>
<h3 id="절제-표현-understatement--영국식에-특히-많음" tabindex="-1" data-src-line="446">절제 표현 (Understatement — 영국식에 특히 많음) <a class="header-anchor" href="#절제-표현-understatement--영국식에-특히-많음" aria-hidden="true">#</a></h3>
<p>실제 감정보다 훨씬 약하게 표현하는 방식. 특히 영국 영어에서 흔합니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m not exactly thrilled. (별로 안 기뻐요 — 실제로는 꽤 화가 남)
That&#039;s not ideal. (별로 안 좋네요 — 실제로는 매우 실망함)
I&#039;m a bit concerned. (좀 걱정돼요 — 실제로는 매우 걱정함)
It&#039;s not my favorite. (제 취향은 아니에요 — 실제로는 싫어함)
I was slightly surprised. (약간 놀랐어요 — 실제로는 충격받음)
</code></pre></div></code></pre>
<p><strong>절제 표현 예문:</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">British colleague: &quot;The presentation was... interesting.&quot;
(실제 의미: 별로였어요.)

British friend: &quot;I&#039;m not entirely sure that was the best idea.&quot;
(실제 의미: 그건 정말 나쁜 생각이었어요.)

Boss: &quot;That&#039;s a little disappointing.&quot;
(실제 의미: 매우 실망스럽습니다.)
</code></pre></div></code></pre>

<p>실제 감정은 하나가 아닌 경우가 많습니다. 복합 감정을 자연스럽게 표현하는 방법입니다.</p>

<h3 id="감정을-숨기거나-조절할-때" tabindex="-1" data-src-line="595">감정을 숨기거나 조절할 때 <a class="header-anchor" href="#감정을-숨기거나-조절할-때" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I&#039;m trying to stay calm. (침착함을 유지하려고 해요)

<h2 id="12--ing-vs--ed-형용사--자주-하는-실수" tabindex="-1" data-src-line="657">12. -ing vs -ed 형용사 — 자주 하는 실수 <a class="header-anchor" href="#12--ing-vs--ed-형용사--자주-하는-실수" aria-hidden="true">#</a></h2>
<p>영어 감정 형용사에서 가장 많이 하는 실수입니다.</p>
<p><strong>-ing</strong> = 그 감정을 <strong>유발하는</strong> 것/사람<br>
<strong>-ed</strong> = 그 감정을 <strong>느끼는</strong> 사람</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">boring vs bored
exciting vs excited
interesting vs interested
surprising vs surprised
shocking vs shocked
terrifying vs terrified
exhausting vs exhausted
frustrating vs frustrated
overwhelming vs overwhelmed
confusing vs confused
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The movie was boring. (영화가 지루했다 — 지루함을 유발)
I was bored during the movie. (나는 지루했다 — 지루함을 느낌)

The news was shocking. (뉴스가 충격적이었다)
I was shocked by the news. (나는 충격을 받았다)

It was an exhausting day. (힘든 하루였다)
I&#039;m exhausted. (나는 지쳤다)

The instructions were confusing. (설명이 헷갈렸다)
I was confused by the instructions. (나는 헷갈렸다)
</code></pre></div></code></pre>

<h2 id="마무리" tabindex="-1" data-src-line="761">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>감정 표현의 핵심 세 가지를 기억하세요.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① 강도를 선택하세요:
  기쁨: content → pleased → glad → happy → delighted → thrilled → ecstatic
  슬픔: down → sad → upset → heartbroken → devastated
  분노: annoyed → irritated → frustrated → angry → furious → livid

② -ing와 -ed를 구분하세요:
  -ing = 감정을 유발하는 것 (The news was shocking.)
  -ed  = 감정을 느끼는 사람 (I was shocked.)

③ 강도에 맞는 강조어를 쓰세요:
  약한 감정: a bit, slightly, rather, somewhat
  강한 감정: absolutely, completely, utterly, totally
  very는 되도록 피하고 더 생생한 단어를 선택하세요.
</code></pre></div></code></pre>
<p>다음 강에서는 <strong>동의와 반론의 뉘앙스</strong> — &quot;agree&quot;부터 &quot;strongly disagree&quot;까지,<br>
상대방을 존중하면서도 내 의견을 명확히 전달하는 기술을 완전히 파고듭니다!</p>
