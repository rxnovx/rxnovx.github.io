<p>“만약 내가 더 열심히 공부했다면 시험을 통과했을 텐데”,<br>
“만약 복권에 당첨된다면 뭘 할 것 같아요?”,<br>
“비가 오면 나는 우산을 가져가요” —</p>
<p>이 세 문장은 모두 if(만약)를 쓰지만 <strong>시제와 의미가 전혀 다릅니다.</strong></p>
<p>영어 가정법은 <strong>얼마나 현실적인 상황인지</strong>에 따라 시제가 달라집니다.<br>
이 원리를 이해하면 모든 가정법이 자연스럽게 연결됩니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>0형·1형·2형·3형 조건문의 구조와 의미를 정확히 구분할 수 있습니다.</li>
<li>현실적 가정과 비현실적 가정을 영어로 자연스럽게 표현할 수 있습니다.</li>
<li>I wish / If only / As if 표현을 익힐 수 있습니다.</li>
<li>unless / as long as / provided that 등 조건 표현을 익힐 수 있습니다.</li>

<h2 id="6-가정법-4가지-완전-비교" tabindex="-1" data-src-line="222">6. 가정법 4가지 완전 비교 <a class="header-anchor" href="#6-가정법-4가지-완전-비교" aria-hidden="true">#</a></h2>

【1형 — 실현 가능한 미래】
If it rains tomorrow, I&#039;ll take an umbrella.

(실제로는 매일 비가 오지 않음)

If it had rained yesterday, I would have taken an umbrella.
어제 비가 왔다면, 우산을 가져갔을 텐데.

<p>현실과 반대되는 현재 상황을 바랄 때 씁니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I wish I had more time.

프랑스어를 할 수 있으면 좋겠어요.
(실제로는 못 함)

날씨가 더 좋으면 좋겠어요.
