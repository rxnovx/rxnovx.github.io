들어가기 앞서 #

“만약 내가 더 열심히 공부했다면 시험을 통과했을 텐데”,
“만약 복권에 당첨된다면 뭘 할 것 같아요?”,
“비가 오면 나는 우산을 가져가요” —

이 세 문장은 모두 if(만약)를 쓰지만 시제와 의미가 전혀 다릅니다.

영어 가정법은 얼마나 현실적인 상황인지에 따라 시제가 달라집니다.
이 원리를 이해하면 모든 가정법이 자연스럽게 연결됩니다.

이 글을 읽고 나면:

  • 0형·1형·2형·3형 조건문의 구조와 의미를 정확히 구분할 수 있습니다.
  • 현실적 가정과 비현실적 가정을 영어로 자연스럽게 표현할 수 있습니다.
  • I wish / If only / As if 표현을 익힐 수 있습니다.
  • unless / as long as / provided that 등 조건 표현을 익힐 수 있습니다.
  • 혼합 가정법을 이해할 수 있습니다.

1. 가정법 개요 — 현실성에 따른 4가지 유형 #

유형 이름 현실성 if절 시제 주절 시제
0형 Zero Conditional 항상 사실 현재시제 현재시제
1형 First Conditional 실현 가능 현재시제 will + 동사원형
2형 Second Conditional 비현실적·가상 과거시제 would + 동사원형
3형 Third Conditional 과거의 비현실 had + p.p. would have + p.p.

2. 0형 가정법 — 항상 사실인 조건 #

구조 #

plain
If + 현재시제, 현재시제.

과학적 사실, 일반적 진리, 자동적 결과를 나타냅니다.
"만약 ~하면 항상 ~하다"의 의미로, if 대신 when으로 바꿔도 됩니다.

plain
If you heat water to 100°C, it boils.
물을 100도로 가열하면 끓습니다. (과학적 사실)

If it rains, the streets get wet.
비가 오면 거리가 젖어요. (자동적 결과)

If I don't eat breakfast, I feel tired.
아침을 먹지 않으면 피곤함을 느껴요. (습관적 사실)

If you mix red and blue, you get purple.
빨강과 파랑을 섞으면 보라색이 나와요.

3. 1형 가정법 — 실현 가능한 미래 조건 #

구조 #

plain
If + 현재시제, will + 동사원형.

실제로 일어날 가능성이 있는 미래 상황을 나타냅니다.

plain
If it rains tomorrow, I'll take an umbrella.
내일 비가 오면, 우산을 가져갈 거예요.

If you study hard, you will pass the exam.
열심히 공부하면, 시험에 합격할 거예요.

If she calls, tell her I'll be home by 7.
그녀가 전화하면, 7시까지 집에 있을 거라고 말해줘요.

If we leave now, we won't be late.
지금 떠나면, 늦지 않을 거예요.

If I get the job, I'll celebrate with you.
직장을 얻으면, 같이 축하할게요.

1형에서 will 외 다른 조동사 사용 #

plain
If you're tired, you can rest.
피곤하면, 쉬어도 돼요. (can — 허가)

If you have any questions, you should ask.
질문이 있으면, 물어봐야 해요. (should — 충고)

If it doesn't rain, we might go hiking.
비가 안 오면, 등산을 갈 수도 있어요. (might — 가능성)

If you finish early, you could come with us.
일찍 끝나면, 우리와 함께 올 수도 있어요. (could — 제안)

unless — if ~ not (~하지 않는다면) #

plain
Unless you study, you won't pass.
= If you don't study, you won't pass.
공부하지 않으면, 합격하지 못할 거예요.

I'll go unless it rains.
= I'll go if it doesn't rain.
비가 오지 않으면 갈 거예요.

Unless you apologize, she won't forgive you.
사과하지 않으면, 그녀는 용서하지 않을 거예요.

4. 2형 가정법 — 비현실적 현재·미래 가정 #

구조 #

plain
If + 과거시제, would + 동사원형.

현실과 반대되거나 실현 가능성이 낮은 현재/미래 상황을 가정합니다.

plain
If I had more money, I would travel the world.
돈이 더 있다면, 세계여행을 할 텐데.
(실제로는 돈이 없음)

If I were you, I wouldn't do that.
내가 당신이라면, 그렇게 하지 않을 텐데.
(실제로는 내가 당신이 아님)

If she lived closer, we would see each other more often.
그녀가 더 가까이 살았다면, 더 자주 만났을 텐데.
(실제로는 멀리 삼)

What would you do if you won the lottery?
복권에 당첨된다면 뭘 하시겠어요?
(당첨될 가능성이 낮음)

If I could fly, I would visit every country.
날 수 있다면, 모든 나라를 방문할 텐데.
(불가능한 가정)

were — be동사의 특별한 2형 가정법 #

2형 가정법에서 be동사는 주어에 상관없이 were를 씁니다.
(현대 영어에서 was도 사용되지만, 격식체에서는 were가 정확합니다.)

plain
If I were rich, I would buy a big house.
내가 부자라면, 큰 집을 살 텐데.
(❌ If I was rich — 비격식체에서만 허용)

If she were here, she would know what to do.
그녀가 여기 있다면, 어떻게 해야 할지 알 텐데.

If he were in my position, what would he do?
그가 내 상황이라면, 어떻게 하겠어?

If I were you, I'd talk to him directly.
내가 당신이라면, 그에게 직접 말할 텐데.

5. 3형 가정법 — 과거의 비현실적 가정 #

구조 #

plain
If + had + p.p., would have + p.p.

과거에 일어나지 않은 일을 가정합니다. 이미 지나간 일이므로 되돌릴 수 없습니다.
주로 후회나 안도를 표현할 때 씁니다.

plain
If I had studied harder, I would have passed the exam.
더 열심히 공부했다면, 시험에 합격했을 텐데.
(실제로는 공부를 덜 해서 떨어짐)

If she had arrived earlier, she wouldn't have missed the train.
더 일찍 도착했다면, 기차를 놓치지 않았을 텐데.
(실제로는 늦게 도착해서 놓침)

If you had told me, I would have helped you.
말해줬다면, 도와줬을 텐데.
(실제로는 말하지 않음)

If we hadn't taken that shortcut, we would have been late.
그 지름길을 택하지 않았다면, 늦었을 거예요.
(실제로는 지름길을 택해서 제시간에 도착)

What would you have done if you had been there?
거기 있었다면 어떻게 했을 것 같아요?

3형에서 다른 조동사 사용 #

plain
If I had known, I might have done things differently.
알았다면, 다르게 했을 수도 있어요. (might have)

If she had asked for help, I could have assisted her.
도움을 요청했다면, 도와줄 수 있었을 텐데. (could have)

If they had prepared more, they should have done better.
더 준비했다면, 더 잘 했어야 했는데. (should have)

6. 가정법 4가지 완전 비교 #

같은 상황을 4가지 가정법으로 표현합니다.

주제: 비가 오는 상황과 우산

plain
【0형 — 항상 사실】
If it rains, I take an umbrella.
비가 오면 (항상) 우산을 가져가요.

【1형 — 실현 가능한 미래】
If it rains tomorrow, I'll take an umbrella.
내일 비가 오면, 우산을 가져갈 거예요.

【2형 — 비현실적 현재 가정】
If it rained every day, I would buy a better umbrella.
매일 비가 온다면, 더 좋은 우산을 살 텐데.
(실제로는 매일 비가 오지 않음)

【3형 — 과거의 비현실】
If it had rained yesterday, I would have taken an umbrella.
어제 비가 왔다면, 우산을 가져갔을 텐데.
(실제로는 어제 비가 오지 않았음)

7. 혼합 가정법 (Mixed Conditionals) #

과거의 조건과 현재의 결과를 섞거나 그 반대를 조합합니다.

유형 ① 과거 조건 + 현재 결과 #

plain
If + had + p.p., would + 동사원형 (현재).

plain
If I had studied medicine, I would be a doctor now.
의학을 공부했다면, 지금 의사일 텐데.
(과거에 의학을 공부하지 않음 → 현재 의사가 아님)

If she had taken the job in Seoul, she would live here now.
서울에서 일자리를 받아들였다면, 지금 여기 살고 있을 텐데.

If he hadn't spent all his money, he wouldn't be in debt now.
돈을 다 쓰지 않았다면, 지금 빚이 없을 텐데.

유형 ② 현재 조건 + 과거 결과 #

plain
If + 과거시제, would have + p.p.

plain
If I were more organized, I would have finished the project on time.
내가 더 체계적이었다면, 프로젝트를 제시간에 끝냈을 텐데.
(현재 체계적이지 않음 → 과거에 제시간에 못 끝냄)

If she were braver, she would have spoken up at the meeting.
그녀가 더 용감했다면, 회의에서 말했을 텐데.

8. I wish / If only — 소원·후회 표현 #

I wish + 과거시제 — 현재 상황에 대한 소원 #

현실과 반대되는 현재 상황을 바랄 때 씁니다.

plain
I wish I had more time.
시간이 더 있었으면 좋겠어요.
(실제로는 시간이 없음)

I wish I could speak French.
프랑스어를 할 수 있으면 좋겠어요.
(실제로는 못 함)

I wish the weather were better.
날씨가 더 좋으면 좋겠어요.

I wish I lived closer to work.
직장에서 더 가까이 살면 좋겠어요.

She wishes she had a better job.
그녀는 더 좋은 직업이 있으면 좋겠다고 생각해요.

I wish + had + p.p. — 과거에 대한 후회 #

과거에 하지 않은(또는 한) 것을 아쉬워할 때 씁니다.

plain
I wish I had studied harder.
더 열심히 공부했으면 좋았을 텐데. (후회)

I wish I hadn't said that.
그말을 하지 않았으면 좋았을 텐데. (후회)

I wish I had taken that opportunity.
그 기회를 잡았으면 좋았을 텐데.

She wishes she had listened to the advice.
그녀는 그 조언을 들었으면 좋았을 텐데라고 생각해요.

I wish + would — 다른 사람의 행동 변화를 바랄 때 #

plain
I wish you would stop interrupting me.
당신이 내 말을 끊지 않았으면 좋겠어요.

I wish it would stop raining.
비가 그쳤으면 좋겠어요.

I wish she would reply to my messages.
그녀가 내 메시지에 답장해줬으면 좋겠어요.

If only — I wish보다 강한 감정 #

If only는 I wish와 같은 구조지만 더 강한 후회나 소망을 나타냅니다.

plain
If only I had more money!
돈이 더 있다면 얼마나 좋을까!

If only I hadn't made that mistake.
그 실수를 하지 않았다면 얼마나 좋았을까.

If only she were here with us now.
그녀가 지금 우리와 함께 있다면 얼마나 좋을까.

9. as if / as though — ~인 것처럼 #

현실과 다른 방식으로 행동하거나 말할 때 씁니다.

plain
He talks as if he knows everything.
그는 모든 것을 아는 것처럼 말해요. (실제로는 모름)

She acts as if she were the boss.
그녀는 자신이 상사인 것처럼 행동해요. (상사가 아님)

He looked as if he had seen a ghost.
그는 귀신을 본 것처럼 보였어요. (귀신을 본 것은 아님)

She spoke as though she had been there herself.
그녀는 자신이 직접 거기 있었던 것처럼 말했어요.

10. 다양한 조건 접속사 #

if 외에도 다양한 조건 접속사가 있습니다.

unless (~하지 않으면) #

plain
Unless you leave now, you'll miss the bus.
지금 떠나지 않으면, 버스를 놓칠 거예요.

I won't go unless you come with me.
당신이 함께 오지 않으면, 나도 가지 않을 거예요.

as long as / provided (that) / providing (that) (~하는 한) #

plain
You can borrow my car as long as you drive carefully.
조심해서 운전하는 한 내 차를 빌릴 수 있어요.

I'll help you provided (that) you help me in return.
대신 나를 도와주는 한 도와드릴게요.

You can stay here as long as you need.
필요한 한 여기 있어도 돼요.

even if (~이라도) #

plain
Even if I had the money, I wouldn't buy it.
돈이 있다 해도, 사지 않을 거예요.

She'll come even if it rains.
비가 와도 올 거예요.

Even if you apologize, she might not forgive you.
사과해도, 그녀가 용서하지 않을 수도 있어요.

suppose / supposing (만약 ~라면) #

plain
Suppose you won the lottery, what would you do?
복권에 당첨된다면, 뭘 하겠어요?

Supposing it doesn't work, what's your backup plan?
그것이 안 된다면, 대안은 뭔가요?

in case (혹시 ~에 대비하여) #

plain
Take an umbrella in case it rains.
혹시 비가 올 경우를 대비해서 우산을 가져가요.

I'll write it down in case I forget.
혹시 잊을 경우를 대비해서 적어둘게요.

She keeps a spare key in case she loses hers.
혹시 잃어버릴 경우를 대비해서 여분 열쇠를 갖고 있어요.

11. 도치 가정법 — 격식체·문어체 #

if를 생략하고 조동사를 앞으로 보내는 도치 구문입니다. 격식체·글쓰기에서 자주 쓰입니다.

plain
【1형 도치】
If you should need any help → Should you need any help
If you should have any questions → Should you have any questions

Should you need any assistance, please contact us.
도움이 필요하시면, 연락해 주세요.

【2형 도치】
If I were you → Were I you
If it were possible → Were it possible

Were I in your position, I would do the same.
내가 당신 입장이라면, 똑같이 할 거예요.

【3형 도치】
If I had known → Had I known
If she had been there → Had she been there

Had I known earlier, I would have helped.
더 일찍 알았다면, 도와줬을 텐데.

12. 가정법 총정리표 #

유형 if절 주절 의미 예문
0형 현재시제 현재시제 항상 사실 If it rains, I take an umbrella.
1형 현재시제 will + 동사원형 실현 가능 미래 If it rains, I’ll take an umbrella.
2형 과거시제 would + 동사원형 비현실적 현재 If it rained, I would take an umbrella.
3형 had + p.p. would have + p.p. 과거의 비현실 If it had rained, I would have taken it.
혼합 had + p.p. would + 동사원형 과거조건+현재결과 If I had studied, I would be a doctor now.
I wish + 과거 현재 소원 I wish I had more time.
I wish + had pp 과거 후회 I wish I had studied harder.

13. 실전 회화 — 가정법 총동원 #

상황 ① 진로 상담 #

plain
A: If you could do anything for work,
   what would you choose?
   직업으로 무엇이든 할 수 있다면,
   무엇을 선택하겠어요?

B: Honestly, if money weren't an issue,
   I'd be a musician. I've always loved music.
   솔직히, 돈이 문제가 아니라면,
   음악가가 될 거예요. 항상 음악을 좋아했어요.

A: Why didn't you pursue it?
   왜 그 길을 걷지 않았나요?

B: If I had taken music seriously earlier,
   I might have had a chance.
   But I focused on getting a stable job.
   더 일찍 음악을 진지하게 받아들였다면,
   기회가 있었을 수도 있어요.
   하지만 안정적인 직업을 구하는 데 집중했어요.

A: Do you regret it?
   후회하나요?

B: Sometimes. I wish I had been braver
   when I was younger.
   But if I hadn't taken this path,
   I wouldn't have met such great colleagues.
   가끔요. 더 어릴 때 더 용감했으면 좋았을 텐데.
   하지만 이 길을 걷지 않았다면,
   이런 훌륭한 동료들을 만나지 못했겠죠.

상황 ② 사고를 돌이켜보며 #

plain
A: If you hadn't caught that early,
   what do you think would have happened?
   그것을 일찍 발견하지 못했다면,
   어떻게 됐을 것 같아요?

B: If we hadn't spotted the error,
   the whole project would have failed.
   실수를 발견하지 못했다면,
   프로젝트 전체가 실패했을 거예요.

A: That was lucky. What would you do
   differently if this happened again?
   운이 좋았네요. 다시 이런 일이 생긴다면
   어떻게 다르게 하겠어요?

B: If something like this happened again,
   I would implement a double-checking system.
   이런 일이 다시 생긴다면,
   이중 확인 시스템을 도입할 거예요.

   And if I had had that system in place,
   we wouldn't have had the problem
   in the first place.
   그리고 그 시스템이 있었다면,
   애초에 문제가 없었을 거예요.

상황 ③ 일상 대화 #

plain
A: I wish this meeting were shorter.
   이 회의가 더 짧으면 좋겠어요.

B: Ha! If only we could skip it entirely.
   하하! 아예 건너뛸 수 있다면 얼마나 좋을까요.

A: If the agenda were clearer,
   it probably would have been done
   in half the time.
   회의 안건이 더 명확했다면,
   아마 절반의 시간에 끝났을 거예요.

B: Agreed. Unless we change how we
   run these meetings, they'll always
   take forever.
   맞아요. 회의 진행 방식을 바꾸지 않는 한,
   항상 영원히 걸릴 거예요.

A: I'll suggest a new format provided
   the manager agrees.
   매니저가 동의하는 한 새로운 형식을
   제안할게요.

B: Good idea. And if the new format works,
   everyone will be happier.
   좋은 생각이에요. 그리고 새로운 형식이
   효과가 있다면, 모두가 더 행복할 거예요.

14. 자주 틀리는 실수 정리 #

실수 ① if절에 will 사용 #

plain
❌ If it will rain tomorrow, I'll take an umbrella.
✅ If it rains tomorrow, I'll take an umbrella.
→ if절 안에서는 will을 쓰지 않음 (현재시제로 미래 표현)

실수 ② 2형에서 was 사용 (격식체에서) #

plain
❌ If I was you, I wouldn't do that. (비격식체)
✅ If I were you, I wouldn't do that.
→ 격식체·시험에서는 were 사용

실수 ③ 3형에서 would have를 if절에 사용 #

plain
❌ If I would have known, I would have helped.
✅ If I had known, I would have helped.
→ if절 안에서 would have 사용 불가 → had + p.p.

실수 ④ I wish + 현재시제 #

plain
❌ I wish I have more money.
✅ I wish I had more money.
→ 현재 소원 → I wish + 과거시제

❌ I wish I studied harder yesterday.
✅ I wish I had studied harder yesterday.
→ 과거 후회 → I wish + had + p.p.

실수 ⑤ unless와 if ~ not 혼용 오류 #

plain
❌ Unless you don't come, we'll cancel.
✅ Unless you come, we'll cancel.
= If you don't come, we'll cancel.
→ unless = if ~ not 이므로 not 중복 불가

15. 문형 정리 #

문형 if절 주절 예문
0형 현재시제 현재시제 If I’m late, I call.
1형 현재시제 will/can/should + 동사원형 If it rains, I’ll stay.
2형 과거시제 (were) would/could + 동사원형 If I were rich, I would travel.
3형 had + p.p. would/could have + p.p. If I had known, I would have come.
혼합 had + p.p. would + 동사원형 If I had studied, I’d be a doctor now.
I wish (현재) I wish + 과거시제 I wish I had more time.
I wish (과거) I wish + had + p.p. I wish I had gone.
I wish (will) I wish + would + 동사원형 I wish you would stop.
as if as if + 과거/had pp He acts as if he were the boss.
unless unless + 현재시제 will/won’t + 동사원형 Unless you hurry, we’ll be late.
in case 주절, in case + 현재시제 Take an umbrella in case it rains.

마무리 #

가정법의 핵심 원칙을 기억하세요.

plain

그리고 자주 틀리는 포인트:

③ I wish + 과거시제 (현재 소원)
