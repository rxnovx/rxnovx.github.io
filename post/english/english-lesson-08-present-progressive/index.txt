<p>4강에서 현재시제를 배웠다면, 이번 강에서는 <strong>지금 이 순간 일어나고 있는 동작</strong>을 표현하는 <strong>현재진행형</strong>을 완전히 익힙니다.</p>
<p>“나는 공부하고 있어요”, “그녀는 전화 중이에요”, “우리는 내일 만날 예정이에요” —<br>
이 모든 표현이 현재진행형으로 가능합니다.<br>
단순해 보이지만, 진행형을 쓸 수 없는 동사가 따로 있고 미래 표현으로도 쓰인다는 점에서 꼼꼼히 익혀야 합니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>-ing형(동명사)을 모든 동사에서 정확하게 만들 수 있습니다.</li>
<li>현재진행형의 3가지 용법(진행·변화·가까운 미래)을 구분할 수 있습니다.</li>
<li>현재시제와 현재진행형의 차이를 명확히 이해할 수 있습니다.</li>
<li>진행형을 쓸 수 없는 상태동사를 완전히 익힐 수 있습니다.</li>
<li>부정문·의문문·의문사 의문문을 자유롭게 만들 수 있습니다.</li>
</ul>
</blockquote>

We&#039;re leaving at 6 AM. (우리는 오전 6시에 출발할 예정이에요.)

</code></pre></div></code></pre>

<h3 id="실수---ing-형태-오류" tabindex="-1" data-src-line="616">실수 ① -ing 형태 오류 <a class="header-anchor" href="#실수---ing-형태-오류" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ I am makeing dinner.
✅ I am making dinner.
→ make → e 삭제 + ing

❌ She is runing.
✅ She is running.
→ run → 자음 중복 + ing

❌ He is dieing.
✅ He is dying.
→ die → ie를 y로 + ing
</code></pre></div></code></pre>
<h3 id="실수--상태동사에-진행형-사용" tabindex="-1" data-src-line="632">실수 ② 상태동사에 진행형 사용 <a class="header-anchor" href="#실수--상태동사에-진행형-사용" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ I am knowing the answer.
✅ I know the answer.

❌ She is loving this song.
✅ She loves this song.

❌ He is having a car.
✅ He has a car.
</code></pre></div></code></pre>

<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ I am drinking coffee every morning.

</code></pre></div></code></pre>

<h2 id="마무리" tabindex="-1" data-src-line="683">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>현재진행형의 핵심을 세 줄로 정리합니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① 지금 이 순간 → I&#039;m eating / She&#039;s working

③ 확정된 가까운 미래 → We&#039;re meeting tomorrow
</code></pre></div></code></pre>

<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">상태동사(know / want / love / have / see 등)는
현재진행형 ❌ → 항상 현재시제 ✅
</code></pre></div></code></pre>
