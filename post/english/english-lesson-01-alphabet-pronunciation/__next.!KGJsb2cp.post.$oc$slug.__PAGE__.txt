<h2 id="2-모음-vs-자음" tabindex="-1" data-src-line="46">2. 모음 vs 자음 <a class="header-anchor" href="#2-모음-vs-자음" aria-hidden="true">#</a></h2>
<p>알파벳 26자는 <strong>모음(Vowel) 5자</strong>와 <strong>자음(Consonant) 21자</strong>로 나뉩니다.</p>
<h3 id="모음-vowel--5자" tabindex="-1" data-src-line="50">모음 (Vowel) — 5자 <a class="header-anchor" href="#모음-vowel--5자" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">A, E, I, O, U
</code></pre></div></code></pre>
<p>모음은 공기가 막힘 없이 자유롭게 흘러나오며 소리를 만듭니다.<br>
영어의 모든 음절에는 반드시 모음이 하나 이상 포함됩니다.</p>
<h3 id="자음-consonant--21자" tabindex="-1" data-src-line="59">자음 (Consonant) — 21자 <a class="header-anchor" href="#자음-consonant--21자" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">B, C, D, F, G, H, J, K, L, M, N, P, Q, R, S, T, V, W, X, Y, Z
</code></pre></div></code></pre>
<p>자음은 입술·혀·이·목구멍 등을 이용해 공기 흐름을 막거나 좁혀서 소리를 만듭니다.</p>
<blockquote>
<p>💡 <strong>관사 a vs an 선택 기준</strong><br>
모음 소리로 시작하는 단어 앞에는 <code>an</code>, 자음 소리로 시작하는 단어 앞에는 <code>a</code>를 씁니다.<br>
철자가 아닌 <strong>소리</strong> 기준임을 주의하세요.</p>
<ul>
<li>an apple (a로 시작 → 모음 소리 → an)</li>
<li>an hour (h로 시작하지만 h 무음 → 모음 소리 → an)</li>
<li>a university (u로 시작하지만 “유” 소리 → 자음 소리 → a)</li>
</ul>
</blockquote>

<h2 id="3-영어-발음-기호-ipa-기초" tabindex="-1" data-src-line="76">3. 영어 발음 기호 (IPA) 기초 <a class="header-anchor" href="#3-영어-발음-기호-ipa-기초" aria-hidden="true">#</a></h2>
<p>영어 발음 기호는 <strong>IPA(International Phonetic Alphabet)</strong> 를 기반으로 합니다.<br>

<h2 id="마무리" tabindex="-1" data-src-line="347">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>알파벳과 발음은 영어의 가장 기본적인 토대입니다.<br>
처음에는 생소하게 느껴지는 발음들도 꾸준히 소리 내어 연습하면 반드시 교정됩니다.</p>
<p>특히 <strong>r vs l, f vs p, v vs b, th 발음</strong> 이 네 가지는 한국인 학습자가 가장 많이 틀리는 부분이므로 의식적으로 반복 연습하는 것을 추천합니다.</p>
<p>다음 강에서는 드디어 영어로 <strong>자기소개</strong>를 해봅니다. <code>My name is ~</code>, <code>I'm from ~</code> 패턴으로 첫 영어 문장을 만들어봅시다!</p>
