<p>“나는 어제 그 여자를 만났다” + “그 여자는 의사다” → “나는 어제 만난 <strong>의사인 그 여자</strong>를 만났다”</p>
<p>이렇게 <strong>두 문장을 하나로 연결</strong>할 때 관계대명사를 사용합니다.</p>
<p>관계대명사는 영어 표현을 훨씬 풍부하고 정교하게 만들어주는 도구입니다.<br>
원리를 이해하면 매우 체계적이고, 익히고 나면 영어 글쓰기와 독해 수준이 크게 올라갑니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>who/which/that/whose/whom을 상황에 맞게 정확히 쓸 수 있습니다.</li>
<li>두 문장을 관계대명사로 자연스럽게 연결할 수 있습니다.</li>
<li>제한적 용법과 비제한적 용법(콤마 유무)의 차이를 이해할 수 있습니다.</li>
<li>관계대명사를 생략할 수 있는 경우와 없는 경우를 구분할 수 있습니다.</li>
<li>관계부사(where/when/why/how)를 이해하고 사용할 수 있습니다.</li>
</ul>
</blockquote>

<h2 id="1-관계대명사란" tabindex="-1" data-src-line="21">1. 관계대명사란? <a class="header-anchor" href="#1-관계대명사란" aria-hidden="true">#</a></h2>
<p>관계대명사는 <strong>대명사 + 접속사</strong>의 역할을 동시에 합니다.<br>
앞에 오는 명사(선행사)를 수식하는 절(관계절)을 이끕니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I know a woman.
She is a doctor.

→ I know a woman who is a doctor.
   나는 의사인 여성을 알아요.
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">선행사 → 관계대명사 → 관계절

</code></pre></div></code></pre>

<h2 id="3-who--사람을-수식하는-관계대명사" tabindex="-1" data-src-line="51">3. who — 사람을 수식하는 관계대명사 <a class="header-anchor" href="#3-who--사람을-수식하는-관계대명사" aria-hidden="true">#</a></h2>
<h3 id="주격-who-관계절에서-주어-역할" tabindex="-1" data-src-line="53">주격 who (관계절에서 주어 역할) <a class="header-anchor" href="#주격-who-관계절에서-주어-역할" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I know a man who speaks five languages.

She&#039;s the teacher who changed my life.
그녀가 내 인생을 바꾼 선생님이에요.

</code></pre></div></code></pre>
<h3 id="두-문장--하나로-연결" tabindex="-1" data-src-line="69">두 문장 → 하나로 연결 <a class="header-anchor" href="#두-문장--하나로-연결" aria-hidden="true">#</a></h3>

② Her sister is a professional dancer.

→ She has a sister who is a professional dancer.
   그녀에게 프로 댄서인 언니/여동생이 있어요.
</code></pre></div></code></pre>

<h2 id="4-which--사물동물을-수식하는-관계대명사" tabindex="-1" data-src-line="89">4. which — 사물·동물을 수식하는 관계대명사 <a class="header-anchor" href="#4-which--사물동물을-수식하는-관계대명사" aria-hidden="true">#</a></h2>
<h3 id="주격-which-관계절에서-주어-역할" tabindex="-1" data-src-line="91">주격 which (관계절에서 주어 역할) <a class="header-anchor" href="#주격-which-관계절에서-주어-역할" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The book which is on the table is mine.
테이블 위에 있는 책이 내 것이에요.

She showed me a photo which was taken in Paris.
그녀는 파리에서 찍힌 사진을 보여줬어요.

I bought a laptop which has a great battery life.
나는 배터리가 오래가는 노트북을 샀어요.

The train which leaves at 9 AM is always on time.
오전 9시에 출발하는 기차는 항상 제시간이에요.
</code></pre></div></code></pre>
<h3 id="두-문장--하나로-연결-1" tabindex="-1" data-src-line="107">두 문장 → 하나로 연결 <a class="header-anchor" href="#두-문장--하나로-연결-1" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① I read a book.
② The book was written by Hemingway.

→ I read a book which was written by Hemingway.
   나는 헤밍웨이가 쓴 책을 읽었어요.
</code></pre></div></code></pre>
<hr>
<h2 id="5-that--사람사물-모두에-사용" tabindex="-1" data-src-line="119">5. that — 사람·사물 모두에 사용 <a class="header-anchor" href="#5-that--사람사물-모두에-사용" aria-hidden="true">#</a></h2>
<p><code>that</code>은 <code>who</code>와 <code>which</code>를 대신해 사람과 사물 모두에 쓸 수 있습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The woman that called you is my boss.
(= who)

The book that is on the table is mine.
(= which)

The best movie that I&#039;ve ever seen was directed by Bong Joon-ho.
내가 본 것 중 최고의 영화는 봉준호 감독이 연출했어요.
</code></pre></div></code></pre>
<h3 id="that을-반드시-사용해야-하는-경우" tabindex="-1" data-src-line="134">that을 반드시 사용해야 하는 경우 <a class="header-anchor" href="#that을-반드시-사용해야-하는-경우" aria-hidden="true">#</a></h3>
<p>다음 경우에는 who/which 대신 that을 씁니다.</p>
<p><strong>① 최상급이 선행사를 수식할 때</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">She&#039;s the best teacher that I&#039;ve ever had.
그녀는 내가 만나본 최고의 선생님이에요.

This is the most interesting book that I&#039;ve read.
이것은 내가 읽은 가장 흥미로운 책이에요.
</code></pre></div></code></pre>
<p><strong>② 서수(first/second 등)가 선행사를 수식할 때</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">He was the first person that arrived.
그는 가장 먼저 도착한 사람이었어요.
</code></pre></div></code></pre>
<p><strong>③ 선행사가 사람+사물 둘 다일 때</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I saw a man and his dog that were running in the park.
나는 공원에서 달리고 있는 한 남자와 그의 개를 봤어요.
</code></pre></div></code></pre>
<p><strong>④ all, every, any, no 등이 선행사를 수식할 때</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">Everything that she said was true.
그녀가 말한 모든 것이 사실이었어요.

I&#039;ll do anything that I can to help.
내가 도울 수 있는 모든 것을 하겠어요.
</code></pre></div></code></pre>
<h3 id="that을-쓸-수-없는-경우" tabindex="-1" data-src-line="172">that을 쓸 수 없는 경우 <a class="header-anchor" href="#that을-쓸-수-없는-경우" aria-hidden="true">#</a></h3>
<p><strong>콤마(,) 뒤 비제한적 용법</strong>에서는 that을 쓸 수 없습니다. (11번에서 자세히 다룸)</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ My sister, that lives in London, is a teacher.
✅ My sister, who lives in London, is a teacher.
</code></pre></div></code></pre>
<hr>
<h2 id="6-목적격-관계대명사" tabindex="-1" data-src-line="183">6. 목적격 관계대명사 <a class="header-anchor" href="#6-목적격-관계대명사" aria-hidden="true">#</a></h2>
<p>관계절에서 관계대명사가 <strong>목적어</strong> 역할을 할 때의 형태입니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">주격: The man who called me was friendly.
     (관계절에서 주어 → who가 주어 역할)

목적격: The man who(m) I called was friendly.
       (관계절에서 목적어 → who(m)이 목적어 역할)
</code></pre></div></code></pre>
<h3 id="사람-목적격--who--whom" tabindex="-1" data-src-line="195">사람 목적격 — who / whom <a class="header-anchor" href="#사람-목적격--who--whom" aria-hidden="true">#</a></h3>
<p>격식체에서는 <code>whom</code>, 일상 회화에서는 <code>who</code>를 씁니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The doctor who(m) I saw yesterday was very kind.
어제 만난 의사가 정말 친절했어요.

The friend who(m) I mentioned is coming tomorrow.
내가 언급한 친구가 내일 와요.

Is she the person who(m) you were talking about?
그녀가 당신이 이야기하던 사람인가요?
</code></pre></div></code></pre>
<h3 id="사물-목적격--which--that" tabindex="-1" data-src-line="210">사물 목적격 — which / that <a class="header-anchor" href="#사물-목적격--which--that" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The movie which/that I watched last night was amazing.
어젯밤에 본 영화가 정말 좋았어요.

The coffee which/that she made was delicious.
그녀가 만든 커피가 맛있었어요.

The report that I submitted had a mistake.
내가 제출한 보고서에 실수가 있었어요.
</code></pre></div></code></pre>
<hr>
<h2 id="7-whose--소유격-관계대명사" tabindex="-1" data-src-line="225">7. whose — 소유격 관계대명사 <a class="header-anchor" href="#7-whose--소유격-관계대명사" aria-hidden="true">#</a></h2>
<p>선행사와 관계절의 명사 사이에 <strong>소유 관계</strong>가 있을 때 씁니다.<br>
사람·사물 모두에 사용 가능합니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">I know a woman whose husband is a politician.
나는 남편이 정치인인 여성을 알아요.

The student whose essay won the prize is in my class.
에세이로 상을 받은 학생이 내 반에 있어요.

That&#039;s the company whose products I use every day.
그게 내가 매일 그 회사 제품을 사용하는 회사예요.

She lives in a house whose roof is red.
그녀는 지붕이 빨간 집에 살아요.
</code></pre></div></code></pre>
<h3 id="두-문장--whose로-연결" tabindex="-1" data-src-line="244">두 문장 → whose로 연결 <a class="header-anchor" href="#두-문장--whose로-연결" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① I met a man yesterday.
② His car was stolen.

→ I met a man yesterday whose car was stolen.
   나는 어제 차를 도난당한 남자를 만났어요.
</code></pre></div></code></pre>
<hr>
<h2 id="8-관계대명사-생략" tabindex="-1" data-src-line="256">8. 관계대명사 생략 <a class="header-anchor" href="#8-관계대명사-생략" aria-hidden="true">#</a></h2>
<p>목적격 관계대명사는 <strong>생략</strong>할 수 있습니다.<br>
주격 관계대명사는 생략할 수 없습니다.</p>
<h3 id="생략-가능--목적격" tabindex="-1" data-src-line="261">생략 가능 — 목적격 <a class="header-anchor" href="#생략-가능--목적격" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The movie (which/that) I watched was great.
→ The movie I watched was great. ✅ (생략 가능)

The man (who/whom) I met was kind.
→ The man I met was kind. ✅ (생략 가능)

The report (that) I submitted had an error.
→ The report I submitted had an error. ✅ (생략 가능)
</code></pre></div></code></pre>
<h3 id="생략-불가--주격" tabindex="-1" data-src-line="274">생략 불가 — 주격 <a class="header-anchor" href="#생략-불가--주격" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The man who called me was my boss.
→ ❌ The man called me was my boss. (주격 관계대명사 생략 불가)

The book which is on the table is mine.
→ ❌ The book is on the table is mine. (생략 불가)
</code></pre></div></code></pre>
<blockquote>
<p>💡 <strong>생략 가능 여부 확인법</strong><br>
관계대명사를 빼도 관계절이 완전한 문장이 되면 → 목적격 → 생략 가능</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The movie (that) I watched → I watched (뭔가가 없음 → 목적어 없음 → 목적격)
The movie that is popular → is popular (주어 없음 → 주격 → 생략 불가)
</code></pre></div></code></pre>
</blockquote>
<hr>
<h2 id="9-전치사--관계대명사" tabindex="-1" data-src-line="293">9. 전치사 + 관계대명사 <a class="header-anchor" href="#9-전치사--관계대명사" aria-hidden="true">#</a></h2>
<p>전치사가 관계대명사와 함께 쓰일 때 두 가지 방식이 있습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">방식 ①: 전치사를 문장 끝에 (회화체)
방식 ②: 전치사 + whom/which (격식체)
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">【방식 ① — 회화체, 자연스러움】
The person I was talking to is my manager.
내가 이야기하고 있던 사람이 내 매니저예요.

The company I work for is in Gangnam.
내가 일하는 회사는 강남에 있어요.

【방식 ② — 격식체, 문어체】
The person to whom I was talking is my manager.
The company for which I work is in Gangnam.
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The city I grew up in has changed a lot.
내가 자란 도시가 많이 변했어요.
(= The city in which I grew up has changed a lot.)

The friend I went on holiday with is very funny.

<h2 id="11-제한적-용법-vs-비제한적-용법" tabindex="-1" data-src-line="337">11. 제한적 용법 vs 비제한적 용법 <a class="header-anchor" href="#11-제한적-용법-vs-비제한적-용법" aria-hidden="true">#</a></h2>
<h3 id="제한적-용법-defining--콤마-없음" tabindex="-1" data-src-line="339">제한적 용법 (Defining) — 콤마 없음 <a class="header-anchor" href="#제한적-용법-defining--콤마-없음" aria-hidden="true">#</a></h3>
<p>선행사를 <strong>특정</strong>하는 데 필수적인 정보를 제공합니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">The students who study hard get good grades.
열심히 공부하는 학생들은 좋은 성적을 받아요.
(모든 학생이 아닌, 열심히 공부하는 학생들로 범위 제한)

I have a sister who lives in London.
나는 런던에 사는 언니/여동생이 있어요.
(여러 자매 중 런던에 사는 한 명 특정)
</code></pre></div></code></pre>
<h3 id="비제한적-용법-non-defining--콤마-있음" tabindex="-1" data-src-line="353">비제한적 용법 (Non-defining) — 콤마 있음 <a class="header-anchor" href="#비제한적-용법-non-defining--콤마-있음" aria-hidden="true">#</a></h3>
<p>선행사에 <strong>추가 정보</strong>를 더하지만, 없어도 의미 이해에 지장이 없습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">My sister, who lives in London, is a doctor.
내 언니/여동생은 런던에 사는데, 의사예요.
(자매가 한 명뿐 — 런던에 산다는 것은 추가 정보)

Seoul, which is the capital of Korea, has over 10 million people.
서울은 한국의 수도인데, 1000만 명 이상이 살아요.
(서울을 이미 알고 있음 — 수도라는 것은 추가 정보)
</code></pre></div></code></pre>
<h3 id="비제한적-용법의-핵심-규칙" tabindex="-1" data-src-line="367">비제한적 용법의 핵심 규칙 <a class="header-anchor" href="#비제한적-용법의-핵심-규칙" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① 반드시 콤마(,)를 사용
② that 사용 불가 (who/which만 가능)
③ 관계대명사 생략 불가
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">【비제한적 — 올바른 표현】
My car, which I bought last year, has broken down.
내 차가 고장났어요, 작년에 산 건데.

【비제한적 — 틀린 표현】
❌ My car, that I bought last year, has broken down.
→ 비제한적 용법에서 that 사용 불가

</code></pre></div></code></pre>

<h2 id="13-what--관계대명사-선행사-포함" tabindex="-1" data-src-line="454">13. what — 관계대명사 (선행사 포함) <a class="header-anchor" href="#13-what--관계대명사-선행사-포함" aria-hidden="true">#</a></h2>
<p><code>what</code>은 <strong>the thing(s) which</strong>의 의미로, 선행사를 포함한 관계대명사입니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">What she said surprised everyone.
그녀가 말한 것이 모든 사람을 놀라게 했어요.
(= The thing that she said)

I don&#039;t understand what you mean.
무슨 말인지 이해하지 못하겠어요.

Tell me what you need.
무엇이 필요한지 말해줘요.

That&#039;s exactly what I was looking for.
바로 내가 찾던 것이에요.

What surprised me most was his calmness.
나를 가장 놀라게 한 것은 그의 침착함이었어요.
</code></pre></div></code></pre>
<blockquote>
<p>⚠️ <strong>what vs that 혼동 주의</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">✅ What she said was true. (what = the thing that)
✅ The thing that she said was true.
❌ That she said was true. (that만으로는 주어 불가)
</code></pre></div></code></pre>
</blockquote>

<h2 id="15-관계대명사-vs-접속사-that" tabindex="-1" data-src-line="517">15. 관계대명사 vs 접속사 that <a class="header-anchor" href="#15-관계대명사-vs-접속사-that" aria-hidden="true">#</a></h2>
<p><code>that</code>은 관계대명사로도, 접속사(명사절)로도 쓰입니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">【관계대명사 that — 앞에 선행사 있음】

(that = which, 관계절이 book을 수식)

【접속사 that — 선행사 없음, 명사절 이끔】
I think that she is right.
나는 그녀가 옳다고 생각해요.
(that절이 think의 목적어)

She told me that she would come.
그녀는 오겠다고 내게 말했어요.
</code></pre></div></code></pre>

<h3 id="실수--what과-that-혼동" tabindex="-1" data-src-line="671">실수 ⑤ what과 that 혼동 <a class="header-anchor" href="#실수--what과-that-혼동" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ I don&#039;t understand what he said it.

<h2 id="마무리" tabindex="-1" data-src-line="718">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>관계대명사의 핵심 원칙 네 가지를 기억하세요.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① 사람 → who / whom / whose
  사물 → which / whose
  사람+사물 → that

② 목적격 관계대명사 → 생략 가능
  주격 관계대명사 → 생략 불가

③ 비제한적 용법(콤마) → that 불가, 생략 불가

④ 전치사 + 관계대명사:
  회화: The man I work with
  격식: The man with whom I work
</code></pre></div></code></pre>
<p>드디어 다음 강이 <strong>A2 레벨 마지막 — 18강 가정법</strong>입니다!<br>
