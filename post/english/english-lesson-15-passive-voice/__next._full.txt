<p>“이 책은 헤밍웨이가 썼습니다” vs “이 책은 헤밍웨이에 의해 쓰였습니다” —<br>
같은 의미지만 관점이 다릅니다. 전자는 능동태, 후자는 수동태입니다.</p>
<p>수동태는 뉴스, 공식 문서, 과학 글쓰기, 공지사항에서 매우 자주 등장합니다.<br>
“The road is being repaired”, “Mistakes were made” — 이런 표현이 모두 수동태입니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>능동태를 수동태로 정확히 변환할 수 있습니다.</li>
<li>현재·과거·미래·완료 시제의 수동태를 만들 수 있습니다.</li>
<li>by를 생략하는 규칙과 생략하지 않는 경우를 구분할 수 있습니다.</li>
<li>수동태를 써야 하는 상황과 쓰면 안 되는 상황을 이해할 수 있습니다.</li>
<li>조동사와 함께 쓰는 수동태를 익힐 수 있습니다.</li>
</ul>
</blockquote>

<h3 id="-이중-목적어-동사의-수동태" tabindex="-1" data-src-line="381">① 이중 목적어 동사의 수동태 <a class="header-anchor" href="#-이중-목적어-동사의-수동태" aria-hidden="true">#</a></h3>
<p><code>give, send, tell, show, teach, offer</code> 등 두 개의 목적어를 가지는 동사는<br>
두 가지 방식으로 수동태를 만들 수 있습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">【능동태】

【수동태 ①】
The students were given a book (by the teacher).
학생들은 (선생님에게) 책을 받았습니다.

【수동태 ②】

책이 (선생님에 의해) 학생들에게 주어졌습니다.
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">They told me the news.

→ The news was told to me.

She showed us the photos.
→ We were shown the photos.
→ The photos were shown to us.
</code></pre></div></code></pre>
<h3 id="-지각동사사역동사의-수동태" tabindex="-1" data-src-line="410">② 지각동사·사역동사의 수동태 <a class="header-anchor" href="#-지각동사사역동사의-수동태" aria-hidden="true">#</a></h3>
<p>능동태에서 목적보어로 동사원형을 쓰는 경우, 수동태에서는 <strong>to + 동사원형</strong>으로 바뀝니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">【능동태】

【수동태】
He was made to work overtime.
그는 야근하게 됐습니다.

They saw her leave the building.
→ She was seen to leave the building.

The police heard the suspect confess.
→ The suspect was heard to confess.
</code></pre></div></code></pre>

<h3 id="상황--관광지에서" tabindex="-1" data-src-line="579">상황 ③ 관광지에서 <a class="header-anchor" href="#상황--관광지에서" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">A: This palace is amazing.
   When was it built?
   이 궁궐 정말 멋지네요.
   언제 지어진 건가요?

B: Gyeongbokgung was built in 1395.
   It was destroyed several times throughout
   history and has been restored multiple times.
   경복궁은 1395년에 지어졌어요.
   역사 속에서 여러 번 파괴됐고,
   여러 번 복원됐어요.

A: Was it always used as a royal palace?
   항상 왕궁으로 사용됐나요?

B: Yes, it was used as the main royal palace
   of the Joseon Dynasty.
   The buildings are now being preserved
   as cultural heritage sites.
   네, 조선왕조의 주요 왕궁으로 사용됐어요.
   건물들은 현재 문화유산으로 보존되고 있어요.

A: I&#039;m so impressed. Who is it managed by now?
   정말 감동적이네요. 지금은 누가 관리하나요?

B: It&#039;s managed by the Cultural Heritage Administration.
   Several restoration projects are currently
   being carried out.
   문화재청에 의해 관리돼요.
   현재 여러 복원 사업이 진행 중이에요.
</code></pre></div></code></pre>

<h2 id="14-자주-틀리는-실수-정리" tabindex="-1" data-src-line="616">14. 자주 틀리는 실수 정리 <a class="header-anchor" href="#14-자주-틀리는-실수-정리" aria-hidden="true">#</a></h2>
<h3 id="실수--be동사-누락" tabindex="-1" data-src-line="618">실수 ① be동사 누락 <a class="header-anchor" href="#실수--be동사-누락" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ The report written by Tom.
✅ The report was written by Tom.
→ 수동태에는 반드시 be동사 필요
</code></pre></div></code></pre>
<h3 id="실수--과거형과-과거분사-혼동" tabindex="-1" data-src-line="626">실수 ② 과거형과 과거분사 혼동 <a class="header-anchor" href="#실수--과거형과-과거분사-혼동" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ The window was broke.
✅ The window was broken.
→ break의 과거분사는 broken (과거형 broke 아님)

❌ The email was wrote last night.
✅ The email was written last night.
→ write의 과거분사는 written
</code></pre></div></code></pre>
<h3 id="실수--by-없이-행위자-표현" tabindex="-1" data-src-line="638">실수 ③ by 없이 행위자 표현 <a class="header-anchor" href="#실수--by-없이-행위자-표현" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ The book was written Shakespeare.
✅ The book was written by Shakespeare.
→ 행위자 앞에 반드시 by
</code></pre></div></code></pre>
<h3 id="실수--수동태에서-시제-일치-오류" tabindex="-1" data-src-line="646">실수 ④ 수동태에서 시제 일치 오류 <a class="header-anchor" href="#실수--수동태에서-시제-일치-오류" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ The results are announced yesterday.
✅ The results were announced yesterday.
→ 과거 시제 → was/were + p.p.

❌ The problem will been solved.
✅ The problem will be solved.
→ will + be + p.p. (will + been 불가)
</code></pre></div></code></pre>
<h3 id="실수--자동사의-수동태" tabindex="-1" data-src-line="658">실수 ⑤ 자동사의 수동태 <a class="header-anchor" href="#실수--자동사의-수동태" aria-hidden="true">#</a></h3>
<p>목적어가 없는 자동사는 수동태를 만들 수 없습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">❌ The accident was happened.
✅ The accident happened.
→ happen은 자동사 → 수동태 불가

❌ She was arrived late.
✅ She arrived late.
→ arrive는 자동사 → 수동태 불가
</code></pre></div></code></pre>

<h2 id="마무리" tabindex="-1" data-src-line="691">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>수동태의 핵심 원칙 세 가지를 기억하세요.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① 구조: be동사(시제 변함) + p.p.(변하지 않음)
② by + 행위자: 행위자가 중요하면 씀, 불명확하면 생략
③ 자동사(happen, arrive, appear)는 수동태 불가
</code></pre></div></code></pre>
<p>그리고 시제별 핵심:</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">현재 → is/are + p.p.
과거 → was/were + p.p.
미래 → will be + p.p.
완료 → have/has been + p.p.
진행 → is/are being + p.p.
</code></pre></div></code></pre>
<p>다음 강에서는 <strong>to부정사와 동명사</strong> — <code>to do</code>와 <code>doing</code>의 차이와 각각의 용법을 완전히 정복합니다!</p>
