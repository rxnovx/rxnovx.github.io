SSH 접속 </a></li></ul></li><li><a href="#마치며">마치며 </a></li></ul></nav><h2 id="들어가기" tabindex="-1" data-src-line="2">들어가기 <a class="header-anchor" href="#들어가기" aria-hidden="true">#</a></h2>
<p>SSH를 처음부터 적극적으로 사용해온 편은 아니었습니다.<br>
예전에는 원격 접속과 파일 전송을 위해 서로 다른 프로토콜을 사용하던 시기가 있었습니다.</p>
<p>당시 대표적으로 사용되던 방식은 다음과 같습니다.</p>
<table>
<thead>
<tr>
<th>구분</th>
<th>System V</th>
<th>BSD</th>
</tr>
</thead>
<tbody>
<tr>
<td>파일 전송</td>
<td>ftp</td>
<td>rcp</td>
</tr>
<tr>
<td>원격 접속</td>
<td>telnet</td>
<td>rlogin</td>
</tr>
</tbody>
</table>
<p>문제는 이 방식들이 모두 <strong>평문 통신</strong>을 사용했다는 점입니다.<br>
네트워크 중간에서 패킷을 가로채면, 사용자 계정과 비밀번호, 명령어 내용까지 그대로 노출되는 구조였습니다.<br>
보안이라는 개념이 지금만큼 중요하게 다뤄지기 전의 이야기입니다.</p>
<p>이러한 문제를 해결하기 위해 등장한 것이 <strong>SSH(Secure Shell)</strong> 입니다.<br>
SSH는 원격 접속과 파일 전송을 암호화된 채널 위에서 처리합니다.</p>
<ul>
<li>ssh : 원격 접속</li>
<li>scp : 파일 복사</li>
<li>sftp : 파일 전송</li>
</ul>
<p>하나의 패키지를 설치하면 위 세 가지 도구를 함께 사용할 수 있습니다.<br>
이 글에서는 OpenSSH 서비스의 구성과 기본적인 보안 설정 방법을 정리해봅니다.</p>
<hr>
<h2 id="ssh와-암호화-방식" tabindex="-1" data-src-line="30">SSH와 암호화 방식 <a class="header-anchor" href="#ssh와-암호화-방식" aria-hidden="true">#</a></h2>
<p>SSH는 통신 내용을 암호화하기 위해 <strong>키 기반 인증</strong>을 사용합니다.<br>
키를 사용하는 방식에는 크게 두 가지가 있습니다.</p>
<ul>
<li>대칭키 방식 (키 1개)</li>
<li>비대칭키 방식 (공개키 / 개인키 2개)</li>
</ul>
<p>SSH는 기본적으로 비대칭키 암호화를 사용합니다.<br>
처음 서버에 접속할 때 서버는 자신의 <strong>호스트 공개키</strong>를 클라이언트에게 전달합니다.<br>
클라이언트는 이를 known_hosts 파일에 저장하고, 이후부터는 해당 서버의 신원을 검증하는 데 사용합니다.</p>
<p>이 과정 덕분에 중간자 공격을 어느 정도 방어할 수 있습니다.</p>
<hr>
<h2 id="openssh-설정-파일-구조" tabindex="-1" data-src-line="46">OpenSSH 설정 파일 구조 <a class="header-anchor" href="#openssh-설정-파일-구조" aria-hidden="true">#</a></h2>

아래는 기본적인 파일 목록입니다.</p>

클라이언트 설정은 <code>ssh_config</code>, 서버 설정은 <code>sshd_config</code> 라고 구분해서 기억해두면 됩니다.</p>
<hr>

<h3 id="로그인-대기-시간-제한" tabindex="-1" data-src-line="93">로그인 대기 시간 제한 <a class="header-anchor" href="#로그인-대기-시간-제한" aria-hidden="true">#</a></h3>

무한 대기 상태를 방지하기 위한 설정입니다.</p>
<hr>
<h3 id="root-계정-로그인-제어" tabindex="-1" data-src-line="104">root 계정 로그인 제어 <a class="header-anchor" href="#root-계정-로그인-제어" aria-hidden="true">#</a></h3>

무차별 대입 공격을 완화하는 역할을 합니다.</p>

<h3 id="공개키-인증-파일-위치" tabindex="-1" data-src-line="126">공개키 인증 파일 위치 <a class="header-anchor" href="#공개키-인증-파일-위치" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">AuthorizedKeysFile .ssh/authorized_keys
</code></pre></div></code></pre>
<p>사용자의 홈 디렉토리 아래 <code>.ssh/authorized_keys</code> 파일에 등록된 공개키를 인증에 사용합니다.</p>
<hr>
<h3 id="로그인-배너-설정" tabindex="-1" data-src-line="136">로그인 배너 설정 <a class="header-anchor" href="#로그인-배너-설정" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment">#Banner none</span>
Banner /etc/issue
</code></pre></div></code></pre>
<p>로그인 시 출력되는 경고 문구를 설정합니다.<br>
법적 고지나 접근 제한 안내 문구를 작성하는 데 사용됩니다.</p>
<hr>
<h3 id="접근-허용-사용자-제한" tabindex="-1" data-src-line="148">접근 허용 사용자 제한 <a class="header-anchor" href="#접근-허용-사용자-제한" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">AllowUsers guru
</code></pre></div></code></pre>
<p>SSH로 접속 가능한 계정을 명시적으로 제한합니다.<br>
필요한 사용자만 접근하도록 구성하는 것이 보안상 안전합니다.</p>
<p>설정 변경 후에는 반드시 SSH 서비스를 재시작해야 합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">systemctl restart sshd
</code></pre></div></code></pre>
<hr>
<h2 id="ssh-접속-방식" tabindex="-1" data-src-line="165">SSH 접속 방식 <a class="header-anchor" href="#ssh-접속-방식" aria-hidden="true">#</a></h2>
<p>SSH는 두 가지 방식으로 사용할 수 있습니다.</p>
<h3 id="인터랙티브-로그인" tabindex="-1" data-src-line="169">인터랙티브 로그인 <a class="header-anchor" href="#인터랙티브-로그인" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">ssh user@host
</code></pre></div></code></pre>
<p>원격 시스템에 로그인하여 쉘을 사용하는 방식입니다.</p>
<h3 id="명령어-단일-실행" tabindex="-1" data-src-line="177">명령어 단일 실행 <a class="header-anchor" href="#명령어-단일-실행" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">ssh user@host <span class="hljs-built_in">command</span>
</code></pre></div></code></pre>
<p>원격 서버에서 특정 명령어만 실행하고 바로 종료됩니다.<br>
자동화 스크립트에서 자주 사용됩니다.</p>
<hr>
<h2 id="파일-전송-방식" tabindex="-1" data-src-line="188">파일 전송 방식 <a class="header-anchor" href="#파일-전송-방식" aria-hidden="true">#</a></h2>
<h3 id="sftp" tabindex="-1" data-src-line="190">SFTP <a class="header-anchor" href="#sftp" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">sftp guru@192.168.11.128
</code></pre></div></code></pre>
<ul>
<li>get 파일명 : 다운로드</li>
<li>put 파일명 : 업로드</li>
</ul>
<p>대화형 인터페이스를 제공하며 비교적 사용이 직관적입니다.</p>
<hr>
<h3 id="scp" tabindex="-1" data-src-line="203">SCP <a class="header-anchor" href="#scp" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 다운로드</span>
scp user@192.168.11.128:/remote/path /local/path

<span class="hljs-comment"># 업로드</span>
scp /local/path user@192.168.11.128:/remote/path
</code></pre></div></code></pre>
<p>단일 명령으로 파일을 전송할 수 있어 스크립트에 자주 사용됩니다.</p>
<hr>
<h2 id="공개키-인증-구성하기" tabindex="-1" data-src-line="217">공개키 인증 구성하기 <a class="header-anchor" href="#공개키-인증-구성하기" aria-hidden="true">#</a></h2>
<p>비밀번호 인증 대신 공개키 인증을 사용하면 보안 수준을 크게 높일 수 있습니다.<br>
구성 순서는 다음과 같습니다.</p>
<h3 id="1-키-생성-클라이언트" tabindex="-1" data-src-line="222">1. 키 생성 (클라이언트) <a class="header-anchor" href="#1-키-생성-클라이언트" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">ssh-keygen
</code></pre></div></code></pre>
<p>공개키와 개인키가 <code>~/.ssh</code> 디렉토리에 생성됩니다.</p>
<hr>
<h3 id="2-공개키-서버-등록" tabindex="-1" data-src-line="232">2. 공개키 서버 등록 <a class="header-anchor" href="#2-공개키-서버-등록" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">ssh-copy-id user@server
</code></pre></div></code></pre>
<p>공개키가 서버의 <code>authorized_keys</code> 파일에 자동으로 등록됩니다.</p>
<hr>
<h3 id="3-ssh-접속" tabindex="-1" data-src-line="242">3. SSH 접속 <a class="header-anchor" href="#3-ssh-접속" aria-hidden="true">#</a></h3>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">ssh user@server
</code></pre></div></code></pre>
<p>정상적으로 설정되었다면 비밀번호 없이 로그인됩니다.</p>
