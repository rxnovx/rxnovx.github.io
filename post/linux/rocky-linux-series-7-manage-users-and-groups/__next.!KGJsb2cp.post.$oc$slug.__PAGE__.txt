<p>리눅스 시스템을 사용하려면 반드시 계정이 필요합니다.<br>
모든 로그인, 모든 작업은 결국 <strong>유저(user)</strong> 단위로 기록되고 제어됩니다.</p>
<p>이때 유저를 직접 하나하나 관리하기보다는,<br>
<strong>그룹을 먼저 만들고 그 그룹에 유저를 소속시키는 방식</strong>이 훨씬 효율적입니다.<br>
권한 관리 측면에서도 그렇고,<br>
실제 운영 환경에서도 이 방식이 기본이 됩니다.</p>
<p>개인적으로는 <strong>유저 관리보다 그룹 관리가 더 중요하고, 더 단순하다</strong>고 느끼는 편입니다.<br>
이 글에서는 그 흐름에 맞춰 그룹 → 유저 순서로 정리합니다.</p>
<hr>
<h2 id="group" tabindex="-1" data-src-line="17">GROUP <a class="header-anchor" href="#group" aria-hidden="true">#</a></h2>
<p>리눅스의 그룹 정보는 <code>/etc/group</code> 파일에 저장되어 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">cat</span> /etc/group
</code></pre></div></code></pre>
<p>이 파일은 한 줄이 하나의 그룹을 의미하며,<br>
각 줄은 <code>:</code> 기준으로 <strong>4개의 컬럼</strong>으로 구성됩니다.</p>
<ul>
<li>그룹 이름</li>
<li>그룹 비밀번호 (실제 사용하지 않음)</li>
<li>GID (Group ID)</li>
<li>그룹 구성원 목록</li>
</ul>
<p>형식은 아래와 같습니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">group_name:x:GID:user1,user2,user3
</code></pre></div></code></pre>
<hr>
<h3 id="groupadd--그룹-생성" tabindex="-1" data-src-line="41">groupadd : 그룹 생성 <a class="header-anchor" href="#groupadd--그룹-생성" aria-hidden="true">#</a></h3>
<p>새로운 그룹을 생성할 때 사용하는 명령어입니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># sales라는 그룹을 생성</span>
groupadd sales

<span class="hljs-comment"># fin 이라는 그룹을 생성하고 GID를 2000으로 설정</span>
groupadd -g 2000 fin
</code></pre></div></code></pre>
<p>일반적으로 GID는 자동으로 할당되지만,<br>
조직 정책이나 기존 시스템과의 연계를 위해<br>
직접 지정해야 하는 경우도 종종 있습니다.</p>
<hr>
<h3 id="groupmod--그룹-설정-변경" tabindex="-1" data-src-line="59">groupmod : 그룹 설정 변경 <a class="header-anchor" href="#groupmod--그룹-설정-변경" aria-hidden="true">#</a></h3>
<p>이미 존재하는 그룹의 설정을 변경할 때 사용합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># sales 그룹의 GID를 3000으로 수정</span>
groupmod -g 3000 sales

<span class="hljs-comment"># fin 그룹의 이름을 oper로 변경</span>
groupmod -n oper fin
</code></pre></div></code></pre>
<p>운영 중인 시스템에서는<br>
<strong>이미 사용 중인 GID를 변경하는 작업은 매우 신중해야 합니다.</strong><br>
파일 소유권과 직접적으로 연결되기 때문입니다.</p>
<hr>
<h3 id="groupdel--그룹-삭제" tabindex="-1" data-src-line="77">groupdel : 그룹 삭제 <a class="header-anchor" href="#groupdel--그룹-삭제" aria-hidden="true">#</a></h3>
<p>그룹을 삭제할 때 사용합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># oper 그룹을 삭제</span>
groupdel oper
</code></pre></div></code></pre>
<p>해당 그룹을 primary 그룹으로 사용하는 유저가 있다면 삭제되지 않습니다.<br>
이 경우 먼저 유저의 그룹을 변경해야 합니다.</p>
<hr>
<h2 id="user" tabindex="-1" data-src-line="91">USER <a class="header-anchor" href="#user" aria-hidden="true">#</a></h2>
<p>유저 관련 정보는 여러 파일에 나뉘어 관리됩니다.</p>
<ul>
<li><code>/etc/passwd</code> : 계정 기본 정보</li>
<li><code>/etc/shadow</code> : 암호 및 만료 정책</li>
<li><code>/etc/shells</code> : 로그인 가능한 쉘 목록</li>
</ul>
<p><code>/etc/passwd</code>의 한 줄은 다음과 같은 구조를 가집니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">계정명:암호:UID:GID:유저메모:홈디렉토리:로그인쉘
</code></pre></div></code></pre>
<p>실제 암호는 <code>/etc/shadow</code> 파일에 해시 형태로 저장됩니다.</p>
<hr>
<h3 id="useradd--유저-생성" tabindex="-1" data-src-line="109">useradd : 유저 생성 <a class="header-anchor" href="#useradd--유저-생성" aria-hidden="true">#</a></h3>
<p>새로운 계정을 생성하는 명령어입니다.</p>
<p>주요 옵션은 다음과 같습니다.</p>
<ul>
<li><code>-u</code> : UID 지정</li>
<li><code>-c</code> : 유저 메모(Comment)</li>
<li><code>-r</code> : 시스템 계정 생성 (UID 1~999)</li>
<li><code>-s</code> : 로그인 쉘 지정</li>
<li><code>-g</code> : primary 그룹 지정</li>
<li><code>-G</code> : secondary 그룹 지정</li>
<li><code>-m</code> : 홈 디렉토리 생성</li>
<li><code>-d</code> : 홈 디렉토리 경로 지정</li>
</ul>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># tom 이라는 계정을 생성</span>
useradd tom

<span class="hljs-comment"># user1을 생성하고 UID를 3001, 메모를 &quot;New User&quot;로 설정</span>
useradd -u 3001 -c <span class="hljs-string">&quot;New User&quot;</span> user1

<span class="hljs-comment"># 시스템 계정 derek 생성</span>
useradd -r -s /sbin/nologin -g sys -G sup1 derek

useradd -u 4989 -s /bin/csh -c <span class="hljs-string">&quot;010-1111-2222&quot;</span> susan
useradd -r -s /sbin/nologin -g sales -G sshd,kvm,dbus -m -d /oracle ora
</code></pre></div></code></pre>
<p>리눅스에는 <strong>primary 그룹과 secondary 그룹</strong> 개념이 있습니다.</p>
<ul>
<li><code>-g</code> : primary 그룹 (기본 소유 그룹)</li>
<li><code>-G</code> : secondary 그룹 (추가 소속 그룹)</li>
</ul>
<p>파일 권한과 접근 제어를 이해하려면<br>
이 구분은 반드시 알고 있어야 합니다.</p>
<hr>
<h3 id="usermod--유저-설정-변경" tabindex="-1" data-src-line="148">usermod : 유저 설정 변경 <a class="header-anchor" href="#usermod--유저-설정-변경" aria-hidden="true">#</a></h3>
<p>이미 존재하는 유저의 설정을 변경할 때 사용합니다.</p>
<p><code>useradd</code>에서 사용하던 옵션 대부분을 그대로 사용할 수 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># susan의 UID를 3030으로 변경하고</span>
<span class="hljs-comment"># primary 그룹을 sales로, 로그인 쉘을 bash로 변경</span>
usermod -u 3030 -g sales -s /bin/bash susan
</code></pre></div></code></pre>
<p>secondary 그룹을 추가할 때는 <code>-aG</code> 옵션을 사용합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># susan을 기존 그룹은 유지한 채 docker 그룹에 추가</span>
usermod -aG docker susan
</code></pre></div></code></pre>
<p><code>-a</code> 옵션 없이 <code>-G</code>만 사용하면<br>
기존 secondary 그룹이 모두 사라지므로 주의해야 합니다.</p>
<hr>
<h3 id="userdel--유저-삭제" tabindex="-1" data-src-line="172">userdel : 유저 삭제 <a class="header-anchor" href="#userdel--유저-삭제" aria-hidden="true">#</a></h3>
<p>유저를 삭제할 때 사용하는 명령어입니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># tom은 홈디렉토리까지 삭제</span>
userdel -r tom

<span class="hljs-comment"># susan은 계정만 삭제, 홈디렉토리는 유지</span>
userdel susan
</code></pre></div></code></pre>
<p>운영 환경에서는<br>
데이터 보존 여부를 반드시 확인한 후 삭제하는 것이 안전합니다.</p>
<hr>
<h3 id="특정-유저가-만든-파일-정리" tabindex="-1" data-src-line="189">특정 유저가 만든 파일 정리 <a class="header-anchor" href="#특정-유저가-만든-파일-정리" aria-hidden="true">#</a></h3>
<p>계정은 삭제했지만,<br>
파일 시스템에는 해당 UID를 가진 파일이 남아있는 경우가 많습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># UID 1701이 소유한 파일 및 디렉토리 삭제</span>
find / -uid 1701 -<span class="hljs-built_in">exec</span> <span class="hljs-built_in">rm</span> -rf {} +
</code></pre></div></code></pre>
<p>소유자가 없는 파일(<code>-nouser</code>)을 처리하는 예시는 아래와 같습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 소유자가 없는 파일을 /tmp/backup 으로 이동</span>
<span class="hljs-built_in">mkdir</span> /tmp/backup
find / -nouser 2&gt; /dev/null -<span class="hljs-built_in">exec</span> <span class="hljs-built_in">mv</span> {} /tmp/backup \;
</code></pre></div></code></pre>
<p>이 작업은 반드시 신중하게 진행해야 합니다.</p>

<h2 id="shadow-파일과-비밀번호-정책" tabindex="-1" data-src-line="211">Shadow 파일과 비밀번호 정책 <a class="header-anchor" href="#shadow-파일과-비밀번호-정책" aria-hidden="true">#</a></h2>
