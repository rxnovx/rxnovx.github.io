a:T12fc,<nav class="md-toc"><ul><li><a href="#들어가기">들어가기 </a></li><li><a href="#grep-명령어">grep 명령어 </a></li><li><a href="#regular-expression">Regular Expression </a></li></ul></nav><h2 id="들어가기" tabindex="-1" data-src-line="2">들어가기 <a class="header-anchor" href="#들어가기" aria-hidden="true">#</a></h2>
<p>grep과 정규표현식은 중요하고 또 특히 정규표현식은 리눅스 뿐 아니라 프로그래밍이나 여러가지 부분에서 사용이 됩니다.<br>
이번 포스트에서는 우선 기초만 정리를 하였습니다.<br>
정규표현식에 대해서는 추후 자세히 설명하는 포스트를 정리하도록 하겠습니다.</p>
<h2 id="grep-명령어" tabindex="-1" data-src-line="8">grep 명령어 <a class="header-anchor" href="#grep-명령어" aria-hidden="true">#</a></h2>
<p>grep은 파일이나 표준 입력에서 문자열을 검색하기 위한 기본 명령어입니다.<br>
옵션 조합에 따라 검색 결과를 상당히 유연하게 제어할 수 있습니다.</p>
<ul>
<li><code>-i</code> : 대소문자를 구분하지 않고 검색합니다.</li>
<li><code>-v</code> : 검색어가 포함되지 않은 행을 출력합니다.</li>
<li><code>-e</code> : 여러 개의 검색어를 지정합니다.<br>
<code>-e 검색어1 -e 검색어2 -e 검색어3</code></li>
<li><code>-C NUM</code> : 검색어 기준으로 위아래 NUM 줄을 함께 출력합니다.</li>
<li><code>-A NUM</code> : 검색어 기준으로 아래 NUM 줄을 함께 출력합니다.</li>
<li><code>-B NUM</code> : 검색어 기준으로 위 NUM 줄을 함께 출력합니다.</li>
</ul>

<h2 id="regular-expression" tabindex="-1" data-src-line="27">Regular Expression <a class="header-anchor" href="#regular-expression" aria-hidden="true">#</a></h2>
<p>정규표현식은 문자열 패턴을 정의하기 위한 규칙입니다.<br>
grep은 기본적으로 정규표현식을 지원합니다.</p>
<ul>
<li>
<p><code>^</code> : 정규표현식의 시작을 의미합니다.</p>
</li>
<li>
<p><code>$</code> : 정규표현식의 끝을 의미합니다.</p>
</li>
<li>
<p><code>.</code> : 임의의 문자 1개를 의미합니다.</p>
</li>
<li>
<p><code>[]</code> : 대괄호 안 문자 중 하나를 의미합니다.</p>
<ul>
<li><code>[a-e]</code> : a부터 e 중 하나를 의미합니다.</li>
</ul>
</li>
<li>
<p><code>{}</code> : 바로 앞 문자의 반복 횟수를 지정합니다.</p>
</li>
<li>
<p><code>*</code> : 바로 앞 문자가 0회 이상 반복됩니다.</p>
</li>
<li>
<p><code>+</code> : 바로 앞 문자가 1회 이상 반복됩니다.</p>
</li>
<li>
<p><code>?</code> : 바로 앞 문자가 0 또는 1회 반복됩니다.</p>
<ul>
<li><code>a*b</code> : b, ab, aab, aaab, aaaab</li>
<li><code>a+b</code> : ab, aab, aaab, aaaab</li>
<li><code>a?b</code> : b, ab</li>
</ul>
</li>
<li>
<p><code>()</code> : 소괄호는 하나의 묶음으로 처리됩니다.</p>
</li>
</ul>
