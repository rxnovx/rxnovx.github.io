<h2 id="들어가기" tabindex="-1" data-src-line="4">들어가기 <a class="header-anchor" href="#들어가기" aria-hidden="true">#</a></h2>
<p>텍스트 에디터는 리눅스 환경에서 매우 중요한 비중을 차지합니다.<br>
대부분의 시스템 설정 파일이 텍스트 기반으로 관리되기 때문에,<br>
에디터를 능숙하게 사용할 수 있어야 설정을 수정하거나 새로 작성할 수 있습니다.</p>
<p>리눅스에는 vi, vim, nano 등 여러 텍스트 편집기가 존재하지만,<br>
본 내용에서는 가장 범용적으로 사용되는 vim을 기준으로 정리합니다.</p>

튜토리얼을 완료하기만 해도 기본기는 익숙해져 있을겁니다.<br>

<h2 id="vi-and-vim" tabindex="-1" data-src-line="25">VI AND VIM <a class="header-anchor" href="#vi-and-vim" aria-hidden="true">#</a></h2>
<ul>
<li>vi : Visual Display Editor 입니다.</li>
<li>vim : Vi IMproved 입니다.</li>
</ul>
<p>vim은 기존 vi 에디터를 개선한 확장 버전입니다.<br>
현재 대부분의 리눅스 배포판에서는 vim 또는 vi 호환 버전이 기본 제공됩니다.</p>
<hr>
<h2 id="vi-에디터" tabindex="-1" data-src-line="35">VI 에디터 <a class="header-anchor" href="#vi-에디터" aria-hidden="true">#</a></h2>
<h3 id="3가지-모드로-동작합니다" tabindex="-1" data-src-line="37">3가지 모드로 동작합니다. <a class="header-anchor" href="#3가지-모드로-동작합니다" aria-hidden="true">#</a></h3>
<ul>
<li>명령 모드 : 커서 이동, 삭제, 복사 등의 작업을 수행합니다.</li>
<li>입력 모드 : 실제 텍스트를 입력하는 모드입니다.</li>
<li>콜론 모드 : 저장, 종료, 검색, 치환 등의 명령을 실행합니다.</li>
</ul>
<p>모드 개념을 이해하지 못하면 vi 사용이 매우 어렵게 느껴질 수 있습니다.</p>
<hr>
<h2 id="vim-명령모드--콜론모드" tabindex="-1" data-src-line="47">VIM 명령모드 &amp; 콜론모드 <a class="header-anchor" href="#vim-명령모드--콜론모드" aria-hidden="true">#</a></h2>
<ul>
<li>:set number (set nu) : 왼쪽에 줄 번호를 표시합니다.</li>
<li>:wq : 저장 후 종료합니다.</li>
<li>:q : 종료합니다. 변경 사항이 있으면 종료되지 않습니다.</li>
<li>:q! : 변경 사항을 무시하고 강제로 종료합니다.</li>
</ul>
<h3 id="커서-이동" tabindex="-1" data-src-line="54">커서 이동 <a class="header-anchor" href="#커서-이동" aria-hidden="true">#</a></h3>
<ul>
<li>
<p>h : 왼쪽으로 이동합니다.</p>
</li>
<li>
<p>j : 아래로 이동합니다.</p>
</li>
<li>
<p>k : 위로 이동합니다.</p>
</li>
<li>
<p>l : 오른쪽으로 이동합니다.</p>
</li>
<li>
<p>숫자G : 해당 행 번호로 이동합니다.</p>
</li>
<li>
<p>G : 마지막 행으로 이동합니다.</p>
</li>
<li>
<p>$ : 현재 행의 끝으로 이동합니다.</p>
</li>
<li>
<p>^ : 현재 행의 처음으로 이동합니다.</p>
</li>
</ul>
<h3 id="이동-단위" tabindex="-1" data-src-line="72">이동 단위 <a class="header-anchor" href="#이동-단위" aria-hidden="true">#</a></h3>
<ul>
<li>w : 단어 단위로 앞으로 이동합니다.</li>
<li>b : 단어 단위로 뒤로 이동합니다.</li>
<li>숫자 + 명령어 : 명령을 숫자만큼 반복 실행합니다.</li>
</ul>
<h3 id="삭제" tabindex="-1" data-src-line="78">삭제 <a class="header-anchor" href="#삭제" aria-hidden="true">#</a></h3>
<ul>
<li>x : 커서 위치의 문자를 삭제합니다.</li>
<li>dw : 한 단어를 삭제합니다.</li>
<li>dd : 한 행을 삭제합니다.</li>
<li>d$, d^ : 커서부터 행의 끝 또는 처음까지 삭제합니다.</li>
<li>dG : 커서부터 파일 끝까지 삭제합니다.</li>
</ul>
<h3 id="복사-및-붙여넣기" tabindex="-1" data-src-line="86">복사 및 붙여넣기 <a class="header-anchor" href="#복사-및-붙여넣기" aria-hidden="true">#</a></h3>
<ul>
<li>yw : 한 단어를 복사합니다.</li>
<li>yy : 한 행을 복사합니다.</li>
<li>p : 커서 아래에 붙여넣습니다.</li>
<li>P : 커서 위에 붙여넣습니다.</li>
</ul>
<p>삭제된 내용은 버퍼에 저장되며, 바로 붙여넣기가 가능합니다.</p>
<h3 id="실행-취소" tabindex="-1" data-src-line="95">실행 취소 <a class="header-anchor" href="#실행-취소" aria-hidden="true">#</a></h3>
<ul>
<li>u : 이전 작업을 취소합니다.</li>
</ul>
<hr>
<h2 id="vim-입력모드-진입-방법" tabindex="-1" data-src-line="101">VIM 입력모드 진입 방법 <a class="header-anchor" href="#vim-입력모드-진입-방법" aria-hidden="true">#</a></h2>
<ul>
<li>a : 커서 다음 위치에서 입력을 시작합니다.</li>
<li>i : 커서 현재 위치에서 입력을 시작합니다.</li>
<li>o : 다음 줄을 생성하고 입력을 시작합니다.</li>
<li>esc : 입력 모드를 종료하고 명령 모드로 돌아갑니다.</li>
</ul>
<p>입력 모드에서는 명령어가 동작하지 않으므로 주의가 필요합니다.</p>
<hr>
<h2 id="vim-콜론모드" tabindex="-1" data-src-line="112">VIM 콜론모드 <a class="header-anchor" href="#vim-콜론모드" aria-hidden="true">#</a></h2>
<ul>
<li>
<p>/검색어 : 검색을 수행합니다.</p>
<ul>
<li>n : 다음 검색 결과로 이동합니다.</li>
<li>N : 이전 검색 결과로 이동합니다.</li>
</ul>
</li>
<li>
<p>:시작행,끝행s/검색어/변경어/g : 범위 지정 치환을 수행합니다.</p>
<ul>
<li>예 : :23,27s/old/new/g</li>
<li>예 : :%s/tcp/breaktime/g</li>
</ul>
</li>
<li>
<p>:2,20d : 2행부터 20행까지 삭제합니다.</p>
</li>
<li>
<p>:w [경로] : 지정한 경로에 다른 이름으로 저장합니다.</p>
</li>
</ul>
<hr>
<h2 id="vi-에디터-커스터마이징" tabindex="-1" data-src-line="130">VI 에디터 커스터마이징 <a class="header-anchor" href="#vi-에디터-커스터마이징" aria-hidden="true">#</a></h2>
<ul>
<li>홈 디렉터리에 <code>.vimrc</code> 파일을 생성하여 기본 설정을 정의할 수 있습니다.</li>
<li>자주 사용하는 옵션을 미리 설정해두면 작업 효율이 크게 향상됩니다.</li>
</ul>
<p>예를 들어 줄 번호 표시, 탭 설정 등을 등록할 수 있습니다.</p>
<hr>
<h2 id="communication-channels" tabindex="-1" data-src-line="139">Communication Channels <a class="header-anchor" href="#communication-channels" aria-hidden="true">#</a></h2>
<p>리눅스에는 기본적으로 3가지 표준 채널이 존재합니다.</p>
<ul>
<li>STDIN  : 표준 입력입니다.</li>
<li>STDOUT : 표준 출력입니다.</li>
<li>STDERR : 표준 에러 출력입니다.</li>
</ul>
<p>파일 디스크립터 번호는 각각 0, 1, 2로 할당되어 있습니다.</p>
