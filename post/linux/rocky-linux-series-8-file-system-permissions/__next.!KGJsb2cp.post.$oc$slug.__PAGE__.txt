<p>이전 글들에서는 리눅스에서 파일과 디렉터리를 다루는 방법을 중심으로 살펴봤습니다.<br>
이번 글에서는 그 파일과 디렉터리에 <strong>누가, 무엇을, 어디까지 할 수 있는지</strong>를 제어하는 핵심 개념인 <strong>파일 시스템 권한(File System Permissions)</strong> 을 정리합니다.</p>
<p>리눅스는 기본적으로 멀티 유저 시스템입니다.<br>
혼자 쓰는 서버라 하더라도, 권한 개념은 보안과 안정성을 지탱하는 가장 기본적인 장치입니다.<br>
이 장은 이후 사용자 관리, 보안 설정, 서버 운영 전반의 토대가 됩니다.</p>
<hr>
<h2 id="file-ownership" tabindex="-1" data-src-line="12">File Ownership <a class="header-anchor" href="#file-ownership" aria-hidden="true">#</a></h2>
<p>리눅스의 모든 파일과 디렉터리는 <strong>소유자(owner)</strong> 와 <strong>그룹(group)</strong> 을 가집니다.<br>
권한 판단의 출발점은 항상 이 두 가지입니다.</p>
<h3 id="chown--파일의-소유자-및-그룹-변경" tabindex="-1" data-src-line="17">chown : 파일의 소유자 및 그룹 변경 <a class="header-anchor" href="#chown--파일의-소유자-및-그룹-변경" aria-hidden="true">#</a></h3>
<p><code>chown</code> 명령어는 파일 또는 디렉터리의 소유자와 그룹을 변경할 때 사용합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">chown</span> [옵션] 소유자:그룹 대상
</code></pre></div></code></pre>
<h4 id="기본-예제" tabindex="-1" data-src-line="25">기본 예제 <a class="header-anchor" href="#기본-예제" aria-hidden="true">#</a></h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 소유자를 test 유저로 변경</span>

</code></pre></div></code></pre>
<h4 id="재귀적-변경--r" tabindex="-1" data-src-line="38">재귀적 변경 (-R) <a class="header-anchor" href="#재귀적-변경--r" aria-hidden="true">#</a></h4>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 하위 파일과 디렉터리까지 모두 변경</span>

</code></pre></div></code></pre>
<p>운영 환경에서는 특정 디렉터리 트리 전체의 소유권을 변경해야 하는 경우가 많기 때문에 <code>-R</code> 옵션은 자주 사용됩니다.</p>
<hr>
<h2 id="file-and-directory-permissions" tabindex="-1" data-src-line="49">File and Directory Permissions <a class="header-anchor" href="#file-and-directory-permissions" aria-hidden="true">#</a></h2>
<p>권한(permission)은 <strong>누가 무엇을 할 수 있는지</strong>를 정의하는 규칙입니다.<br>
권한이 없다면 파일을 읽을 수도, 수정할 수도, 실행할 수도 없습니다.</p>
<p><code>ls -l</code> 또는 <code>ls -al</code> 명령을 실행하면 왼쪽에 10자리 문자열이 출력됩니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">drwxr-xr-x
</code></pre></div></code></pre>
<p>이 문자열 안에 파일 타입과 권한 정보가 모두 들어 있습니다.</p>
