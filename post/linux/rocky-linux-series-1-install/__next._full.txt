<h2 id="들어가기" tabindex="-1" data-src-line="4">들어가기 <a class="header-anchor" href="#들어가기" aria-hidden="true">#</a></h2>
<p>최근 회사에서 Redhat Linux 9.7 을 사용하게 되어 HPE 교육센터에서 교육을 수강했습니다.<br>
해당 교육을 수강하고나서, 필요할 때마다 꺼내보기 위해 리눅스 배우기 시리즈로 글을 작성합니다.</p>
<p>대학 수업에서도, 이전 회사에서 일을 할 때부터 리눅스를 자주 다뤄왔으며 CentOS, Ubuntu 두 종류의 배포판 리눅스를 사용해 본 경험이 있습니다.<br>
다만, 지금까지 정식적으로 교육은 받아 본 적이 없고 인터넷에 작성된 블로그나 문서를 보면서 배운 리눅스라 사용법은 알지만 구멍이 송송 뚫린 지식이기 때문에<br>
이번 정식 교육을 통해 리눅스 지식에 뚫린 구멍을 메꾸고자 합니다.</p>
<hr>
<h2 id="linux-설치를-위한-도구-준비" tabindex="-1" data-src-line="15">Linux 설치를 위한 도구 준비 <a class="header-anchor" href="#linux-설치를-위한-도구-준비" aria-hidden="true">#</a></h2>
<p>리눅스를 설치하기 위해선 당연하지만 PC 한대가 추가로 있어야 설치가 가능합니다.<br>

<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249464472-image.webp" alt="image.png"></p>
<h4 id="3-3-3-installation-destination" tabindex="-1" data-src-line="258">3-3-3. Installation Destination <a class="header-anchor" href="#3-3-3-installation-destination" aria-hidden="true">#</a></h4>
<p>설치할 디스크를 설정하는 단계입니다.</p>
<p>전문가 또는 특수한 목적으로 디스크 영역을 수동으로 설정할 경우에는<br>
디스크를 선택한 뒤 Storage Configuration 에서 Custom을 선택하여 직접 디스크를 나눠주지만,<br>
학습 단계에서는 필요없습니다. Automatic로 진행 후 좌측 상단의 Done 버튼을 누르도록 합니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249532984-image.webp" alt="image.png"></p>
<h4 id="3-3-4-설치-진행" tabindex="-1" data-src-line="268">3-3-4. 설치 진행 <a class="header-anchor" href="#3-3-4-설치-진행" aria-hidden="true">#</a></h4>
<p>다 끝나셨으면 우측 하단의 Begin Installation을 눌러 설치를 진행합니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249686250-image.webp" alt="image.png"></p>
<h4 id="3-3-5-설치-완료" tabindex="-1" data-src-line="274">3-3-5. 설치 완료 <a class="header-anchor" href="#3-3-5-설치-완료" aria-hidden="true">#</a></h4>
<p>설치가 완료되면 우측 하단의 Reboot System 버튼을 누릅니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249835868-image.webp" alt="image.png"></p>
<h4 id="3-3-6-부팅-이미지-언마운트" tabindex="-1" data-src-line="280">3-3-6. 부팅 이미지 언마운트 <a class="header-anchor" href="#3-3-6-부팅-이미지-언마운트" aria-hidden="true">#</a></h4>
<p>그대로 부팅을 하게 되면 다시 설치 이미지로 부팅이 되기 때문에 아래의 설정으로 돌아가<br>
[Connect CD/DVD Drive] 를 체크 해제 해줍니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249999356-image.webp" alt="image.png"></p>
