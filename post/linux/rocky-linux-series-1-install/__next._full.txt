<h2 id="들어가기" tabindex="-1" data-src-line="4">들어가기 <a class="header-anchor" href="#들어가기" aria-hidden="true">#</a></h2>
<p>최근 회사에서 Redhat Linux 9.7을 사용하게 되어 HPE 교육센터에서 교육을 수강했습니다.<br>
해당 교육을 수강하고 나서, 필요할 때마다 꺼내보기 위해 <strong>리눅스 배우기 시리즈</strong>로 글을 작성합니다.</p>
<p>대학 수업에서도, 이전 회사에서 일할 때부터 리눅스를 자주 다뤄왔으며 CentOS, Ubuntu 두 종류의 배포판 리눅스를 사용해 본 경험이 있습니다.<br>
다만, 지금까지 정식으로 교육을 받아본 적이 없고 인터넷에 작성된 블로그나 문서를 보면서 익힌 리눅스라 사용법은 알지만 구멍이 송송 뚫린 지식이었습니다.<br>
이번 정식 교육을 통해 그 구멍들을 메꾸고, 앞으로의 시리즈에서 체계적으로 정리해 나가고자 합니다.</p>
<hr>
<h2 id="rocky-linux란" tabindex="-1" data-src-line="15">Rocky Linux란? <a class="header-anchor" href="#rocky-linux란" aria-hidden="true">#</a></h2>
<p>Rocky Linux는 Red Hat Enterprise Linux(RHEL)를 소스 기반으로 1:1 호환을 목표로 만들어진 <strong>무료 엔터프라이즈 리눅스 배포판</strong>입니다.</p>
<p>원래 RHEL의 무료 다운스트림 배포판으로 오랫동안 사랑받아온 CentOS가 2021년부터 정책 변경으로 사실상 단종(CentOS Stream으로 전환)되면서, 그 대안으로 Rocky Linux와 AlmaLinux가 커뮤니티 주도로 등장했습니다.</p>
<div class="table-scroll" tabindex="0" role="region" aria-label="Scrollable table"><table>
<thead>
<tr>
<th scope="col">배포판</th>
<th scope="col">특징</th>
</tr>
</thead>
<tbody>
<tr>
<td>RHEL</td>
<td>유료, 공식 Red Hat 지원</td>
</tr>
<tr>
<td>CentOS Stream</td>
<td>RHEL 업스트림(선행 버전), 불안정할 수 있음</td>
</tr>
<tr>
<td>Rocky Linux</td>
<td>RHEL 다운스트림, 무료, 1:1 호환</td>
</tr>
<tr>
<td>AlmaLinux</td>
<td>Rocky Linux와 유사한 RHEL 다운스트림</td>
</tr>
</tbody>
</table>
</div><p>회사 서버 환경이 RHEL 기반이라면, Rocky Linux로 로컬에서 학습하고 익힌 내용을 그대로 실무에 적용할 수 있다는 것이 가장 큰 장점입니다.</p>
<hr>
<h2 id="linux-설치를-위한-도구-준비" tabindex="-1" data-src-line="32">Linux 설치를 위한 도구 준비 <a class="header-anchor" href="#linux-설치를-위한-도구-준비" aria-hidden="true">#</a></h2>
<p>리눅스를 설치하려면 당연히 PC 한 대가 추가로 있어야 하지만, 학습 목적이라면 굳이 실물 PC를 구매할 필요가 없습니다.<br>
우리는 <strong>가상화(Virtualization) 소프트웨어</strong>를 이용해 기존 PC 위에 가상의 컴퓨터(가상머신)를 만들고, 그 안에 리눅스를 설치할 것입니다.</p>
<blockquote>
<p><strong>가상화란?</strong><br>
하나의 물리적인 컴퓨터 자원(CPU, 메모리, 디스크 등)을 소프트웨어적으로 분리하여 마치 여러 대의 컴퓨터처럼 사용하는 기술입니다.<br>
가상머신 안에서 일어나는 일은 호스트(실제) 운영체제에 영향을 주지 않으므로 안전하게 실습할 수 있습니다.</p>
</blockquote>
<p>이번 포스트에서 필요한 것은 아래 두 가지입니다.</p>
<ul>
<li><strong>VMware</strong> (가상화 소프트웨어)</li>
<li><strong>Rocky Linux ISO 이미지</strong> (설치 디스크 이미지)</li>
</ul>
<hr>
<h2 id="vmware-다운로드-및-설치" tabindex="-1" data-src-line="48">VMware 다운로드 및 설치 <a class="header-anchor" href="#vmware-다운로드-및-설치" aria-hidden="true">#</a></h2>

<ul>
<li><strong>VMware Workstation</strong> — Windows용</li>
<li><strong>VMware Fusion</strong> — macOS용</li>
</ul>
<p>저는 현재 Mac을 사용 중이므로 Fusion을 사용할 예정입니다. 다운로드하는 파일명만 다를 뿐 이후 설치 과정은 Windows와 거의 동일합니다.</p>

<p><strong>VMware는 원래 유료였지만</strong>, 2024년부터 Broadcom이 VMware를 인수한 이후 개인 사용자에게는 무료로 제공하고 있습니다.<br>
단, 다운로드를 위해 Broadcom 계정 가입이 필수입니다.</p>

<td>최소한의 패키지만 포함. 필요한 것만 추가 설치하는 방식으로 학습에 적합</td>
</tr>
<tr>
<td>DVD</td>
<td>약 10GB</td>
<td>대부분의 패키지 포함. 오프라인 설치 가능</td>
</tr>
<tr>
<td>Boot</td>
<td>수백 MB</td>

</tr>

</table>
</div><p>학습 단계에서는 <strong>Minimal ISO</strong>로도 충분하며, 필요한 패키지는 나중에 <code>dnf</code> 명령어로 설치할 수 있습니다.</p>
<p>다운로드가 완료되면 VMware를 실행하여 설치를 진행합니다.</p>

<h3 id="2-1-디스크-용량-조정-선택" tabindex="-1" data-src-line="243">2-1. 디스크 용량 조정 (선택) <a class="header-anchor" href="#2-1-디스크-용량-조정-선택" aria-hidden="true">#</a></h3>

<p>설정 방법:<br>
<strong>Hard Disk (NVMe)</strong> 항목 클릭 → <strong>Disk size</strong> 에 <code>100</code> 입력 → <strong>Apply</strong></p>

</blockquote>

<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769248742113-image.webp" alt="image.png"></p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769248778119-image.webp" alt="image.png"></p>

</blockquote>
<h3 id="3-2-언어-설정" tabindex="-1" data-src-line="285">3-2. 언어 설정 <a class="header-anchor" href="#3-2-언어-설정" aria-hidden="true">#</a></h3>
<p>설치 언어는 <strong>English</strong>로 설정합니다.</p>
<p>한국어로 선택하면 홈 디렉토리명이 한글로 생성될 수 있으며, 이로 인해 일부 스크립트나 프로그램에서 예상치 못한 오류가 발생하기도 합니다.<br>
서버 환경에서는 기본적으로 영어를 사용하는 것이 표준이므로, 처음부터 영어 환경에 익숙해지는 것을 권장합니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249135915-image.webp" alt="image.png"></p>
<h3 id="3-3-설치-설정-installation-summary" tabindex="-1" data-src-line="294">3-3. 설치 설정 (Installation Summary) <a class="header-anchor" href="#3-3-설치-설정-installation-summary" aria-hidden="true">#</a></h3>
<p>언어 설정 이후 <strong>Installation Summary</strong> 화면이 나타납니다.<br>
이 화면에서 설치에 필요한 항목들을 구성합니다.</p>
<p>필수로 설정해야 할 항목은 아래 세 가지입니다.</p>
<ul>
<li><strong>Root Account</strong> — root 계정 활성화 여부</li>
<li><strong>User Creation</strong> — 일반 사용자 계정 생성</li>
<li><strong>Installation Destination</strong> — 설치할 디스크 지정</li>
</ul>
<p>나머지 항목은 기본값으로 진행해도 문제없습니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249313704-image.webp" alt="image.png"></p>
<h4 id="3-3-1-root-account-설정" tabindex="-1" data-src-line="309">3-3-1. Root Account 설정 <a class="header-anchor" href="#3-3-1-root-account-설정" aria-hidden="true">#</a></h4>
<p><code>root</code>는 리눅스에서 모든 권한을 가진 최고 관리자 계정입니다.<br>
보안 측면에서 root 계정으로 직접 로그인하는 것은 권장하지 않습니다.</p>
<p>여기서는 <strong>Disable root account</strong>를 선택하여 root 직접 로그인을 비활성화합니다.<br>
필요 시 이후에 <code>sudo passwd root</code> 명령어로 root 암호를 설정하고 활성화할 수 있습니다.</p>
<p>설정 완료 후 좌측 상단의 <strong>Done</strong> 버튼을 클릭합니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249431738-image.webp" alt="image.png"></p>
<h4 id="3-3-2-user-creation-사용자-계정-생성" tabindex="-1" data-src-line="321">3-3-2. User Creation (사용자 계정 생성) <a class="header-anchor" href="#3-3-2-user-creation-사용자-계정-생성" aria-hidden="true">#</a></h4>
<p>로그인에 사용할 일반 사용자 계정을 생성합니다.</p>
<ul>
<li><strong>Full Name</strong> : 표시될 이름 (한글도 가능하지만 영문 권장)</li>
<li><strong>User Name</strong> : 로그인 ID (영문 소문자, 숫자, 하이픈만 사용)</li>
<li><strong>Password</strong> : 로그인 비밀번호</li>
</ul>
<blockquote>
<p><strong>주의</strong>: 비밀번호가 너무 단순하면(예: <code>1234</code>, <code>password</code>) 경고가 표시됩니다.<br>
이 경우 <strong>Done</strong> 버튼을 두 번 눌러야 강제로 적용됩니다.</p>
</blockquote>
<p><strong>Make this user administrator</strong> 항목을 체크하면 해당 계정에서 <code>sudo</code> 명령어를 통해 관리자 권한을 사용할 수 있습니다. 학습 환경에서는 체크하는 것을 권장합니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249464472-image.webp" alt="image.png"></p>
<h4 id="3-3-3-installation-destination-디스크-설정" tabindex="-1" data-src-line="336">3-3-3. Installation Destination (디스크 설정) <a class="header-anchor" href="#3-3-3-installation-destination-디스크-설정" aria-hidden="true">#</a></h4>
<p>설치할 디스크를 선택하는 단계입니다.</p>
<p>가상머신에서 생성한 디스크가 자동으로 표시됩니다. 해당 디스크를 클릭하여 선택 상태(체크 표시)로 만들고, <strong>Storage Configuration</strong>은 <strong>Automatic</strong>을 선택합니다.</p>
<blockquote>
<p>파티션을 수동으로 분리하고 싶다면 Custom을 선택할 수 있지만, 학습 단계에서는 자동 파티셔닝으로 충분합니다.<br>
자동 설정 시 <code>/</code>, <code>/boot</code>, <code>/home</code>, swap 등의 파티션이 자동으로 나뉩니다.</p>
</blockquote>
<p>설정 완료 후 <strong>Done</strong> 버튼을 클릭합니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249532984-image.webp" alt="image.png"></p>
<h4 id="3-3-4-설치-시작" tabindex="-1" data-src-line="349">3-3-4. 설치 시작 <a class="header-anchor" href="#3-3-4-설치-시작" aria-hidden="true">#</a></h4>
<p>세 가지 설정이 모두 완료되면 우측 하단의 <strong>Begin Installation</strong> 버튼이 활성화됩니다.<br>
버튼을 눌러 설치를 시작합니다.</p>
<p>설치 소요 시간은 PC 사양에 따라 다르지만, 일반적으로 5~15분 정도 걸립니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249686250-image.webp" alt="image.png"></p>
<h4 id="3-3-5-설치-완료-및-재부팅" tabindex="-1" data-src-line="358">3-3-5. 설치 완료 및 재부팅 <a class="header-anchor" href="#3-3-5-설치-완료-및-재부팅" aria-hidden="true">#</a></h4>
<p>설치가 완료되면 우측 하단에 <strong>Reboot System</strong> 버튼이 나타납니다.<br>
버튼을 클릭하여 시스템을 재시작합니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249835868-image.webp" alt="image.png"></p>
<h4 id="3-3-6-부팅-이미지-언마운트-중요" tabindex="-1" data-src-line="365">3-3-6. 부팅 이미지 언마운트 (중요!) <a class="header-anchor" href="#3-3-6-부팅-이미지-언마운트-중요" aria-hidden="true">#</a></h4>
<p>재부팅 직후, ISO 이미지가 여전히 연결되어 있으면 다시 설치 화면으로 부팅될 수 있습니다.<br>
아래 설정으로 돌아가 <strong>Connect CD/DVD Drive</strong> 체크를 <strong>해제</strong>합니다.</p>
<p><img src="/images/_posts/linux/rocky-linux-series-1-install/1769249999356-image.webp" alt="image.png"></p>
<blockquote>
<p>타이밍이 늦어 설치 화면이 다시 나타났다면, 그냥 가상머신을 강제 종료하고 ISO 연결을 해제한 뒤 다시 부팅하면 됩니다.</p>
</blockquote>

<p>정상적으로 부팅이 완료되면 아래와 같이 로그인 프롬프트가 나타납니다.</p>
<p>앞서 <strong>User Creation</strong> 단계에서 설정한 사용자 이름과 비밀번호를 입력하여 로그인합니다.</p>

<h3 id="설치-확인-명령어" tabindex="-1" data-src-line="400">설치 확인 명령어 <a class="header-anchor" href="#설치-확인-명령어" aria-hidden="true">#</a></h3>
<p>로그인 후 아래 명령어를 입력하여 설치가 정상적으로 완료되었는지 확인해볼 수 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># Rocky Linux 버전 확인</span>
<span class="hljs-built_in">cat</span> /etc/rocky-release

<span class="hljs-comment"># 커널 버전 확인</span>
<span class="hljs-built_in">uname</span> -r

<span class="hljs-comment"># 디스크 사용량 확인</span>
<span class="hljs-built_in">df</span> -h

<span class="hljs-comment"># 메모리 사용량 확인</span>
free -h
</code></pre></div></code></pre>
<p>명령어들이 정상적으로 출력된다면 Rocky Linux 설치가 완료된 것입니다.</p>

<h2 id="5-마치면서" tabindex="-1" data-src-line="422">5. 마치면서 <a class="header-anchor" href="#5-마치면서" aria-hidden="true">#</a></h2>
<p>Rocky Linux를 VMware 가상머신 환경에 설치하는 전체 과정을 정리했습니다.</p>

<ol>
<li>VMware 설치 (Broadcom 계정 필요)</li>

<li>ISO 파일을 가상 DVD로 연결</li>

<li>재부팅 전 ISO 언마운트</li>
<li>로그인 확인</li>
</ol>
