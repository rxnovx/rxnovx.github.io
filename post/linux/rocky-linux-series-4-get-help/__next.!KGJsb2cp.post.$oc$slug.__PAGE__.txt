<h2 id="로그인-세션에-대한-정보를-얻기" tabindex="-1" data-src-line="4">로그인 세션에 대한 정보를 얻기 <a class="header-anchor" href="#로그인-세션에-대한-정보를-얻기" aria-hidden="true">#</a></h2>
<h3 id="로그인-사용자를-확인하는-방법" tabindex="-1" data-src-line="6">로그인 사용자를 확인하는 방법 <a class="header-anchor" href="#로그인-사용자를-확인하는-방법" aria-hidden="true">#</a></h3>
<p>리눅스에서 현재 로그인한 사용자가 누구인지,<br>
어떤 터미널을 통해 접속했는지는 기본적으로 확인해야 할 정보입니다.<br>
문제 상황을 추적하거나 접근 권한을 확인할 때 자주 사용됩니다.</p>
<ul>
<li><strong>UID</strong> : user id</li>
<li><strong>GID</strong> : group id</li>
<li><strong>terminal</strong> : tty, pts 등 접속 터미널 정보</li>
</ul>
<hr>
<h3 id="커맨드로-확인하는-방법" tabindex="-1" data-src-line="18">커맨드로 확인하는 방법 <a class="header-anchor" href="#커맨드로-확인하는-방법" aria-hidden="true">#</a></h3>
<p>가장 기본적으로 사용하는 명령어는 <code>id</code> 입니다.<br>
현재 사용자 기준으로 UID, GID, 소속 그룹 정보를 한 번에 출력합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">id</span>
</code></pre></div></code></pre>
<p>필요한 정보만 확인하고 싶을 경우에는 다음과 같이 나누어 사용할 수 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">id</span> -un      <span class="hljs-comment"># 사용자 이름</span>
<span class="hljs-built_in">whoami</span>     <span class="hljs-comment"># 현재 사용자 이름</span>
<span class="hljs-built_in">id</span> -Gn     <span class="hljs-comment"># 소속 그룹 목록</span>
<span class="hljs-built_in">tty</span>        <span class="hljs-comment"># 현재 터미널</span>
</code></pre></div></code></pre>

<h2 id="명령어-문서에서-도움말-확인하기" tabindex="-1" data-src-line="43">명령어 문서에서 도움말 확인하기 <a class="header-anchor" href="#명령어-문서에서-도움말-확인하기" aria-hidden="true">#</a></h2>
<p>대부분의 리눅스 명령어는 자체적인 도움말을 포함하고 있습니다.<br>
짧고 빠르게 옵션이나 사용법을 확인할 때 유용합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">command</span> --<span class="hljs-built_in">help</span>
</code></pre></div></code></pre>
<p>출력 내용은 간단하지만,<br>
자주 사용하는 옵션을 확인하기에는 충분한 정보가 제공됩니다.</p>
<hr>
<h2 id="man-과-info-명령어로-메뉴얼을-확인하기" tabindex="-1" data-src-line="57">man 과 info 명령어로 메뉴얼을 확인하기 <a class="header-anchor" href="#man-과-info-명령어로-메뉴얼을-확인하기" aria-hidden="true">#</a></h2>
<p>보다 자세한 설명이 필요할 경우에는 <code>man</code> 명령어를 사용합니다.<br>
각 명령어에 대한 공식 매뉴얼을 텍스트 환경에서 확인할 수 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">man [section] name
</code></pre></div></code></pre>
<p>매뉴얼 화면에서 사용할 수 있는 기본 조작은 다음과 같습니다.</p>
<ul>
<li><code>Enter</code> : 한 줄씩 이동</li>
<li><code>Space</code> : 한 페이지씩 이동</li>
<li><code>b</code> : 이전 페이지로 이동</li>
<li><code>/</code> : 검색 모드 진입 (<code>n</code>으로 다음 결과 이동)</li>
</ul>
<p>매뉴얼은 섹션별로 구성되어 있으며,<br>
명령어, 설정 파일, 시스템 호출 등 용도에 따라 구분되어 있습니다.</p>
<p>키워드 기반으로 매뉴얼을 검색하고 싶을 경우에는 다음 명령어를 사용합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">man -k 키워드
</code></pre></div></code></pre>
<p>이는 내부적으로 매뉴얼 인덱스를 검색하는 방식이며,<br>
환경에 따라 인덱스가 최신 상태가 아닐 수도 있습니다.</p>
<p>이럴 경우에는 <code>mandb</code> 명령어를 사용하여<br>
수동으로 매뉴얼 인덱스 데이터베이스를 생성할 수 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">mandb
</code></pre></div></code></pre>
<hr>
<h2 id="man-페이지의-기호를-예제로-이해하기" tabindex="-1" data-src-line="94">man 페이지의 기호를 예제로 이해하기 <a class="header-anchor" href="#man-페이지의-기호를-예제로-이해하기" aria-hidden="true">#</a></h2>
<p><code>man</code> 페이지에서 사용하는 기호들은<br>
처음 보면 의미를 파악하기 어렵습니다.<br>
아래에서는 실제 메뉴얼에 등장하는 예시를 기준으로<br>
각 기호가 어떤 의미를 가지는지 정리합니다.</p>
<hr>
<h3 id="대괄호---생략-가능한-옵션-또는-인수" tabindex="-1" data-src-line="103">대괄호 <code>[]</code> : 생략 가능한 옵션 또는 인수 <a class="header-anchor" href="#대괄호---생략-가능한-옵션-또는-인수" aria-hidden="true">#</a></h3>
<p>대괄호로 묶인 항목은 반드시 입력할 필요가 없는 선택 사항입니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">ls [-a] [-l] [file ...]
</code></pre></div></code></pre>
<p>위 예시는 다음과 같이 해석할 수 있습니다.</p>
<ul>
<li><code>-a</code>, <code>-l</code> 옵션은 필요할 때만 사용합니다.</li>
<li><code>file</code> 인수는 생략할 수 있습니다.</li>
<li>인수를 생략하면 현재 디렉토리를 기준으로 동작합니다.</li>
</ul>
<hr>
<h3 id="꺾쇠-괄호---반드시-필요한-값" tabindex="-1" data-src-line="119">꺾쇠 괄호 <code>&lt;&gt;</code> : 반드시 필요한 값 <a class="header-anchor" href="#꺾쇠-괄호---반드시-필요한-값" aria-hidden="true">#</a></h3>
<p>꺾쇠 괄호로 표시된 항목은 반드시 값을 입력해야 합니다.<br>
실제 메뉴얼에서는 문자열, 숫자, 경로 등이 들어갑니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">useradd -u &lt;UID&gt; &lt;username&gt;
</code></pre></div></code></pre>
<p>위 예시는 다음을 의미합니다.</p>
<ul>
<li><code>&lt;UID&gt;</code>에는 숫자 값이 반드시 들어가야 합니다.</li>
<li><code>&lt;username&gt;</code>은 생성할 사용자 이름입니다.</li>
<li>두 값 모두 생략할 수 없습니다.</li>
</ul>
<hr>
<h3 id="세로-막대---여러-항목-중-하나-선택" tabindex="-1" data-src-line="136">세로 막대 <code>|</code> : 여러 항목 중 하나 선택 <a class="header-anchor" href="#세로-막대---여러-항목-중-하나-선택" aria-hidden="true">#</a></h3>
<p>세로 막대는 여러 선택지 중 하나를 선택해야 함을 의미합니다.<br>
동시에 사용할 수는 없습니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">shutdown [-h | -r | -c] [time]
</code></pre></div></code></pre>
<p>위 예시는 다음과 같이 해석됩니다.</p>
<ul>
<li><code>-h</code>, <code>-r</code>, <code>-c</code> 중 하나만 사용할 수 있습니다.</li>
<li>시스템 종료, 재부팅, 예약 취소 중 하나를 선택합니다.</li>
</ul>
<hr>
<h3 id="말줄임표---반복-가능" tabindex="-1" data-src-line="152">말줄임표 <code>...</code> : 반복 가능 <a class="header-anchor" href="#말줄임표---반복-가능" aria-hidden="true">#</a></h3>
<p>말줄임표는 동일한 형태의 인수를 여러 개 사용할 수 있음을 의미합니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">chmod [OPTION]... MODE[,MODE]... FILE...
</code></pre></div></code></pre>
<p>위 예시는 다음을 의미합니다.</p>
<ul>
<li><code>OPTION</code>은 여러 개 지정할 수 있습니다.</li>
<li><code>FILE</code> 인수는 하나 이상 지정할 수 있습니다.</li>
<li>여러 파일에 동일한 권한 설정을 적용할 수 있습니다.</li>
</ul>
<hr>
<h3 id="기호를-읽는-순서" tabindex="-1" data-src-line="168">기호를 읽는 순서 <a class="header-anchor" href="#기호를-읽는-순서" aria-hidden="true">#</a></h3>
<p>처음 <code>man</code> 페이지를 볼 때는 다음 순서로 읽는 것이 좋습니다.</p>
<ol>
<li>대괄호(<code>[]</code>)로 선택 사항을 구분합니다.</li>
<li>꺾쇠 괄호(<code>&lt;&gt;</code>)로 반드시 필요한 값을 확인합니다.</li>
<li>세로 막대(<code>|</code>)로 동시에 사용할 수 없는 옵션을 확인합니다.</li>
<li>말줄임표(<code>...</code>)로 반복 가능한 인수를 파악합니다.</li>
</ol>
<p>기호의 의미를 알고 나면,<br>
긴 메뉴얼에서도 필요한 사용법만 빠르게 골라볼 수 있습니다.</p>
<p><code>man</code> 외에도 <code>info</code> 명령어를 통해 문서를 확인할 수 있습니다.<br>
일부 GNU 계열 명령어는 <code>info</code> 문서에 더 자세한 설명이 포함되어 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">info 명령어
</code></pre></div></code></pre>
<hr>
<p>현재 로그인한 사용자나 시스템 접속 이력을 확인하기 위한 명령어도 자주 사용됩니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">who</span>     <span class="hljs-comment"># 현재 로그인한 사용자</span>
last    <span class="hljs-comment"># 로그인 이력</span>
</code></pre></div></code></pre>
<hr>
<h2 id="여러-가지-시스템-정보-확인-방법" tabindex="-1" data-src-line="199">여러 가지 시스템 정보 확인 방법 <a class="header-anchor" href="#여러-가지-시스템-정보-확인-방법" aria-hidden="true">#</a></h2>
<p>리눅스 시스템의 기본 정보를 확인할 수 있는 대표적인 명령어는 다음과 같습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">cat</span> /etc/os-release   <span class="hljs-comment"># 운영체제 버전 정보</span>
hostnamectl           <span class="hljs-comment"># 시스템, 커널, 하드웨어 정보 개요</span>
free -h               <span class="hljs-comment"># 메모리 사용량 (-h: 사람이 읽기 쉬운 단위)</span>
lscpu                 <span class="hljs-comment"># CPU 정보</span>
ip addr               <span class="hljs-comment"># 네트워크 인터페이스 및 IP 정보</span>
</code></pre></div></code></pre>
<p>과거에 사용되던 <code>ifconfig</code> 명령어는 현재 deprecated 상태이며,<br>
대신 <code>ip</code> 명령어 사용</p>
