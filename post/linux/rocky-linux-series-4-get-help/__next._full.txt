<h2 id="man-페이지의-기호를-예제로-이해하기" tabindex="-1" data-src-line="94">man 페이지의 기호를 예제로 이해하기 <a class="header-anchor" href="#man-페이지의-기호를-예제로-이해하기" aria-hidden="true">#</a></h2>

<h3 id="대괄호---생략-가능한-옵션-또는-인수" tabindex="-1" data-src-line="103">대괄호 <code>[]</code> : 생략 가능한 옵션 또는 인수 <a class="header-anchor" href="#대괄호---생략-가능한-옵션-또는-인수" aria-hidden="true">#</a></h3>

<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">text</span><button class="copy-button">Copy</button></div><pre class="language-text"><code>ls <span class="hljs-selector-attr">[-a]</span> <span class="hljs-selector-attr">[-l]</span> <span class="hljs-selector-attr">[file ...]</span>

<li><code>file</code> 인수는 생략할 수 있습니다.</li>
<li>인수를 생략하면 현재 디렉토리를 기준으로 동작합니다.</li>

<h3 id="꺾쇠-괄호---반드시-필요한-값" tabindex="-1" data-src-line="119">꺾쇠 괄호 <code>&lt;&gt;</code> : 반드시 필요한 값 <a class="header-anchor" href="#꺾쇠-괄호---반드시-필요한-값" aria-hidden="true">#</a></h3>
<p>꺾쇠 괄호로 표시된 항목은 반드시 값을 입력해야 합니다.<br>
실제 메뉴얼에서는 문자열, 숫자, 경로 등이 들어갑니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">text</span><button class="copy-button">Copy</button></div><pre class="language-text"><code>useradd -u <span class="hljs-tag">&lt;<span class="hljs-name">UID</span>&gt;</span> <span class="hljs-tag">&lt;<span class="hljs-name">username</span>&gt;</span>
</code></pre></div></code></pre>
<p>위 예시는 다음을 의미합니다.</p>
<ul>
<li><code>&lt;UID&gt;</code>에는 숫자 값이 반드시 들어가야 합니다.</li>
<li><code>&lt;username&gt;</code>은 생성할 사용자 이름입니다.</li>
<li>두 값 모두 생략할 수 없습니다.</li>
</ul>
<hr>
<h3 id="세로-막대---여러-항목-중-하나-선택" tabindex="-1" data-src-line="136">세로 막대 <code>|</code> : 여러 항목 중 하나 선택 <a class="header-anchor" href="#세로-막대---여러-항목-중-하나-선택" aria-hidden="true">#</a></h3>
<p>세로 막대는 여러 선택지 중 하나를 선택해야 함을 의미합니다.<br>
동시에 사용할 수는 없습니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">text</span><button class="copy-button">Copy</button></div><pre class="language-text"><code>shutdown [-h | <span class="hljs-type">-r</span> | <span class="hljs-type">-c</span>] [<span class="hljs-built_in">time</span>]
</code></pre></div></code></pre>
<p>위 예시는 다음과 같이 해석됩니다.</p>
<ul>
<li><code>-h</code>, <code>-r</code>, <code>-c</code> 중 하나만 사용할 수 있습니다.</li>
<li>시스템 종료, 재부팅, 예약 취소 중 하나를 선택합니다.</li>
</ul>
<hr>
<h3 id="말줄임표---반복-가능" tabindex="-1" data-src-line="152">말줄임표 <code>...</code> : 반복 가능 <a class="header-anchor" href="#말줄임표---반복-가능" aria-hidden="true">#</a></h3>
<p>말줄임표는 동일한 형태의 인수를 여러 개 사용할 수 있음을 의미합니다.</p>
<pre><code class="language-text"><div class="code-block"><div class="code-header"><span class="code-title">text</span><button class="copy-button">Copy</button></div><pre class="language-text"><code>chmod [OPTION]<span class="hljs-string">...</span> MODE[,MODE]<span class="hljs-string">...</span> FILE.<span class="hljs-string">..</span>
</code></pre></div></code></pre>
<p>위 예시는 다음을 의미합니다.</p>
<ul>
<li><code>OPTION</code>은 여러 개 지정할 수 있습니다.</li>
<li><code>FILE</code> 인수는 하나 이상 지정할 수 있습니다.</li>
<li>여러 파일에 동일한 권한 설정을 적용할 수 있습니다.</li>
</ul>
<hr>
<h3 id="기호를-읽는-순서" tabindex="-1" data-src-line="168">기호를 읽는 순서 <a class="header-anchor" href="#기호를-읽는-순서" aria-hidden="true">#</a></h3>
<p>처음 <code>man</code> 페이지를 볼 때는 다음 순서로 읽는 것이 좋습니다.</p>
<ol>
<li>대괄호(<code>[]</code>)로 선택 사항을 구분합니다.</li>
<li>꺾쇠 괄호(<code>&lt;&gt;</code>)로 반드시 필요한 값을 확인합니다.</li>
<li>세로 막대(<code>|</code>)로 동시에 사용할 수 없는 옵션을 확인합니다.</li>
<li>말줄임표(<code>...</code>)로 반복 가능한 인수를 파악합니다.</li>
</ol>
<p>기호의 의미를 알고 나면,<br>
긴 메뉴얼에서도 필요한 사용법만 빠르게 골라볼 수 있습니다.</p>
<p><code>man</code> 외에도 <code>info</code> 명령어를 통해 문서를 확인할 수 있습니다.<br>
일부 GNU 계열 명령어는 <code>info</code> 문서에 더 자세한 설명이 포함되어 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-built_in">info</span> 명령어
</code></pre></div></code></pre>
<hr>
<p>현재 로그인한 사용자나 시스템 접속 이력을 확인하기 위한 명령어도 자주 사용됩니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button class="copy-button">Copy</button></div><pre class="language-bash"><code><span class="hljs-attribute">who</span>     <span class="hljs-comment"># 현재 로그인한 사용자</span>
<span class="hljs-literal">last</span>    <span class="hljs-comment"># 로그인 이력</span>
</code></pre></div></code></pre>
<hr>
<h2 id="여러-가지-시스템-정보-확인-방법" tabindex="-1" data-src-line="199">여러 가지 시스템 정보 확인 방법 <a class="header-anchor" href="#여러-가지-시스템-정보-확인-방법" aria-hidden="true">#</a></h2>
<p>리눅스 시스템의 기본 정보를 확인할 수 있는 대표적인 명령어는 다음과 같습니다.</p>
