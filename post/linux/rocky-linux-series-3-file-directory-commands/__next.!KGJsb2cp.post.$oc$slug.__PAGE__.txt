<h2 id="들어가기" tabindex="-1" data-src-line="4">들어가기 <a class="header-anchor" href="#들어가기" aria-hidden="true">#</a></h2>
<p>리눅스 시스템에서 파일과 디렉토리를 생성하고 삭제하고 수정하는 방법에 대해 정리했습니다.<br>
윈도우 시스템을 사용해봤다면 크게 낯설지는 않을 것입니다.<br>
폴더와 파일이라는 개념 자체는 거의 같습니다.</p>
<hr>
<h2 id="파일시스템이란" tabindex="-1" data-src-line="12">파일시스템이란? <a class="header-anchor" href="#파일시스템이란" aria-hidden="true">#</a></h2>
<p>파일시스템은 데이터를 저장하고 관리하기 위한 구조를 말합니다.<br>
윈도우, 유닉스, 리눅스 등 대부분의 운영체제에서 공통으로 사용되는 개념입니다.</p>
<p>파일의 크기가 크고 개수가 적은지,<br>
파일의 크기가 작고 개수가 많은지에 따라<br>
적합한 파일시스템이 달라집니다.</p>
<p>대표적으로 윈도우에서는 NTFS를 사용합니다.<br>
과거에는 FAT32도 많이 사용되었습니다.</p>
<p>리눅스에서는 ext4와 같은 전용 파일시스템을 주로 사용하며,<br>
필요에 따라 FAT32와 같은 파일시스템도 지원합니다.</p>
<hr>
<h2 id="유닉스리눅스에서의-파일-구조-특징" tabindex="-1" data-src-line="29">유닉스/리눅스에서의 파일 구조 특징 <a class="header-anchor" href="#유닉스리눅스에서의-파일-구조-특징" aria-hidden="true">#</a></h2>
<p>유닉스/리눅스에서의 파일 구조 특징은 아래와 같습니다.</p>
<ul>
<li>
<p>singly rooted (최상단 디렉토리)<br>
: 하나의 루트(/) 디렉토리를 기준으로 모든 디렉토리가 구성됨</p>
</li>
<li>
<p>cAsE SensiTiviTY<br>
: 파일 이름에서 대소문자를 명확하게 구분함</p>
</li>
<li>
<p>long file names<br>
: 긴 파일 이름을 지원함</p>
</li>
<li>
<p>supports links<br>
: 링크 기능을 지원함 (하드 링크, 심볼릭 링크)</p>
</li>
<li>
<p>timestamps various file operations<br>
: 파일에 대해 여러 종류의 시간 정보(생성, 수정, 접근 등)를 관리함</p>
</li>
</ul>
<hr>
<h2 id="파일시스템을-탐색하는-방법" tabindex="-1" data-src-line="50">파일시스템을 탐색하는 방법 <a class="header-anchor" href="#파일시스템을-탐색하는-방법" aria-hidden="true">#</a></h2>
<p>리눅스는 윈도우와 마찬가지로 트리 구조의 파일 구조를 가지고 있습니다.<br>
이러한 트리 구조에서는 경로가 중요합니다.</p>
<p>경로에는 두 가지 종류가 있으며,<br>
절대경로와 상대경로로 나뉩니다.</p>
<p>또한 원하는 디렉토리로 이동하기 위한 명령어도 필요합니다.<br>
아래에서 각각 살펴보겠습니다.</p>
<hr>
<h3 id="절대경로" tabindex="-1" data-src-line="63">절대경로 <a class="header-anchor" href="#절대경로" aria-hidden="true">#</a></h3>
<p>절대경로는 최상위 경로(/)부터 시작하여 특정 위치를 가리키는 경로를 말합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 현재 위치한 곳은 홈 디렉토리</span>
<span class="hljs-comment"># package.json 파일을 열고자 할 때</span>
vi /home/user/workspace/project1/package.json
</code></pre></div></code></pre>
<hr>
<h3 id="상대경로" tabindex="-1" data-src-line="75">상대경로 <a class="header-anchor" href="#상대경로" aria-hidden="true">#</a></h3>
<p>상대경로는 현재 내가 위치한 디렉토리를 기준으로 경로를 지정하는 방식입니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 현재 위치한 곳은 홈 디렉토리</span>
<span class="hljs-comment"># package.json 파일을 열고자 할 때</span>
vi workspace/project1/package.json
</code></pre></div></code></pre>
<hr>
<h3 id="트리-구조-안에서-원하는-디렉토리로-이동하는-명령어-cd" tabindex="-1" data-src-line="87">트리 구조 안에서 원하는 디렉토리로 이동하는 명령어 cd <a class="header-anchor" href="#트리-구조-안에서-원하는-디렉토리로-이동하는-명령어-cd" aria-hidden="true">#</a></h3>
<p>cd(change directory) 명령어는 트리 구조 안에서 원하는 디렉토리로 이동하는 명령어입니다.<br>
인수로 경로를 입력받습니다.</p>
<p>현재 위치한 경로를 확인하기 위해서는 pwd 명령어를 사용합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">cd</span> ~    <span class="hljs-comment"># ~ (tilde)는 home directory를 의미함</span>
<span class="hljs-built_in">pwd</span>
/home/user
</code></pre></div></code></pre>
<h3 id="디렉토리-내부-파일-목록을-출력해주는-명령어-ls" tabindex="-1" data-src-line="99">디렉토리 내부 파일 목록을 출력해주는 명령어 ls <a class="header-anchor" href="#디렉토리-내부-파일-목록을-출력해주는-명령어-ls" aria-hidden="true">#</a></h3>
<p>현재 위치한 디렉토리 또는 특정 디렉토리 내부에 어떤 파일과 디렉토리가 있는지 확인하는 명령어입니다.</p>
<p>ls 명령어는 리눅스에서 가장 자주 사용하는 기본 명령어 중 하나입니다.<br>
옵션 없이 실행하면 현재 디렉토리의 파일과 디렉토리 이름만 출력합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ls</span>
</code></pre></div></code></pre>
<p>특정 디렉토리의 내용을 확인하고 싶다면 경로를 인수로 전달합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ls</span> /etc
</code></pre></div></code></pre>
<p>옵션을 사용하면 출력 형태를 변경할 수 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ls</span> [옵션] [디렉토리]
</code></pre></div></code></pre>
<p>자주 사용하는 옵션은 다음과 같습니다.</p>
<ul>
<li>-l : 파일의 상세 정보를 함께 출력</li>
<li>-a : 숨김 파일을 포함하여 출력</li>
</ul>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 상세 정보 출력</span>
<span class="hljs-built_in">ls</span> -l

<span class="hljs-comment"># 숨김 파일 포함</span>

<p>ls -l 옵션을 사용하면 파일의 권한, 소유자, 크기, 수정 시간 등을 함께 확인할 수 있습니다.<br>
이 출력 결과는 파일 권한과 소유권을 이해하는 데 자주 활용됩니다.</p>
<p>ls 명령어는 단독으로도 많이 사용되지만,<br>
cd, pwd와 함께 디렉토리 이동과 탐색 과정에서 자연스럽게 사용됩니다.</p>
<p>추가로 ls는 리눅스를 사용하면서 가장 많이 사용되는 명령어 입니다.</p>
<hr>
<h2 id="디렉토리-조작-관련-명령어" tabindex="-1" data-src-line="148">디렉토리 조작 관련 명령어 <a class="header-anchor" href="#디렉토리-조작-관련-명령어" aria-hidden="true">#</a></h2>
<p>디렉토리를 조작하기 위한 명령어를 알아보겠습니다.<br>
디렉토리를 생성하거나 삭제하는 명령어입니다.</p>
<ul>
<li>
<p><strong>mkdir</strong> : 디렉토리 생성</p>
<ul>
<li><code>-m</code> : 생성 시 퍼미션 지정</li>
<li><code>-p</code> : 상위 디렉토리까지 함께 생성</li>
</ul>
</li>
<li>
<p><strong>rmdir</strong> : 빈 디렉토리 삭제</p>
<ul>
<li><code>-p</code> : 상위 디렉토리까지 함께 삭제 (비어 있을 경우)</li>
</ul>
</li>
</ul>
<hr>
<h2 id="파일-조작-관련-명령어" tabindex="-1" data-src-line="164">파일 조작 관련 명령어 <a class="header-anchor" href="#파일-조작-관련-명령어" aria-hidden="true">#</a></h2>
<p>파일을 조작하는 명령어에 대해 알아보겠습니다.<br>
파일을 복사하거나 이동하는 명령어입니다.</p>
<ul>
<li>
<p><strong>cp</strong> : 파일/디렉토리 복사</p>
<ul>
<li>여러 파일 복사 가능: <code>cp a b c .</code></li>
<li><code>-i</code> : 덮어쓰기 전 확인 (alias 권장)</li>
<li><code>-r</code>, <code>-R</code> : 디렉토리 전체 복사</li>
</ul>
</li>
<li>
<p><strong>mv</strong> : 파일/디렉토리 이동 및 이름 변경</p>
<ul>
<li><code>-i</code> : 덮어쓰기 전 확인 (alias 권장)</li>
<li>디렉토리는 옵션 없이 이동 가능</li>
</ul>
</li>
</ul>
<hr>
<h2 id="삭제-및-파일-생성-명령어" tabindex="-1" data-src-line="183">삭제 및 파일 생성 명령어 <a class="header-anchor" href="#삭제-및-파일-생성-명령어" aria-hidden="true">#</a></h2>
<ul>
<li>
<p><strong>rm</strong> : 파일/디렉토리 삭제</p>
<ul>
<li><code>-i</code> : 삭제 전 확인</li>
<li><code>-f</code> : 강제 삭제</li>
<li><code>-r</code>, <code>-R</code> : 디렉토리 재귀 삭제</li>
</ul>
</li>
<li>
<p><strong>touch</strong> : 빈 파일 생성 / 타임스탬프 변경</p>
<ul>
<li>파일 존재 여부로 동작을 제어할 때 활용</li>
<li>예: <code>/etc/nologin</code> → 일반 사용자 로그인 차단</li>
</ul>
</li>
</ul>
<hr>
<div class="callout callout-tip">
<h3 class="callout-title">TIP : Alias</h3><p>자주 쓰는 옵션을 기본 동작으로 설정하는 기능으로<br>
cp나 rm, mv 명령어를 쓸 때 파일을 덮어쓸 경우 -i 옵션을 주지 않아도 항상 주도록<br>
Alias를 설정해두면 파일이 덮어써지거나 삭제되는 것을 방지할 수 있음.</p>

</code></pre></div></code></pre>
<p><code>.bashrc</code>에 정의하면 로그인 후에도 유지됨</p>

<h2 id="바로가기-만들기--파일-링크-생성" tabindex="-1" data-src-line="210">바로가기 만들기 : 파일 링크 생성 <a class="header-anchor" href="#바로가기-만들기--파일-링크-생성" aria-hidden="true">#</a></h2>

<li>
<p><strong>ln</strong> : 링크 생성</p>
<ul>
<li>
<p>하드링크 : 같은 파일에 이름만 하나 더 추가</p>

<li>다른 디스크(파일시스템) 간 생성 불가</li>
</ul>
</li>
<li>
<p>소프트링크(<code>-s</code>) : 경로를 가리키는 링크</p>
<ul>
<li>디스크가 달라도 생성 가능</li>
</ul>
</li>
</ul>
</li>
</ul>
