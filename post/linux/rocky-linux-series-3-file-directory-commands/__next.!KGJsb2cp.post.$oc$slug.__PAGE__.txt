<h2 id="들어가기" tabindex="-1" data-src-line="4">들어가기 <a class="header-anchor" href="#들어가기" aria-hidden="true">#</a></h2>
<p>리눅스 시스템에서 파일과 디렉토리를 탐색하고, 생성하고, 삭제하고, 수정하는 방법에 대해 정리했습니다.<br>
Windows를 사용해봤다면 파일과 폴더라는 개념 자체는 낯설지 않을 것입니다.<br>
다만 리눅스는 파일시스템 구조와 명명 규칙, 파일을 다루는 철학 자체가 Windows와 꽤 다릅니다.<br>
이 차이점을 이해하면서 익혀나가면 훨씬 자연스럽게 손에 익을 것입니다.</p>
<hr>
<h2 id="파일시스템이란" tabindex="-1" data-src-line="13">파일시스템이란? <a class="header-anchor" href="#파일시스템이란" aria-hidden="true">#</a></h2>
<p>파일시스템(Filesystem)은 <strong>저장장치에 데이터를 어떻게 저장하고 관리할지 정의하는 구조와 규칙</strong>입니다.<br>
우리가 파일을 저장하고 불러올 수 있는 것은 파일시스템이 디스크 위에서 데이터를 정리해주기 때문입니다.</p>
<p>파일시스템마다 지원하는 최대 파일 크기, 파일명 길이, 권한 체계, 저널링(갑작스러운 종료 시 데이터 보호) 여부 등이 다릅니다.<br>
따라서 용도에 맞는 파일시스템을 선택하는 것이 중요합니다.</p>
<p>대표적인 파일시스템은 아래와 같습니다.</p>

</div><blockquote>
<p>Rocky Linux(RHEL 계열)의 기본 파일시스템은 <strong>XFS</strong>입니다.<br>
일반 학습 환경에서는 큰 차이를 느끼기 어렵지만, 엔터프라이즈 환경에서는 이 선택이 중요한 이슈가 되기도 합니다.</p>
</blockquote>
<hr>
<h3 id="inode란" tabindex="-1" data-src-line="37">inode란? <a class="header-anchor" href="#inode란" aria-hidden="true">#</a></h3>
<p>리눅스 파일시스템을 이해할 때 <strong>inode(아이노드)</strong> 개념은 빼놓을 수 없습니다.</p>
<p>리눅스에서 파일은 크게 두 가지 정보로 구성됩니다.</p>
<ul>
<li><strong>데이터 블록</strong> : 파일의 실제 내용</li>
<li><strong>inode</strong> : 파일의 메타데이터(소유자, 권한, 크기, 타임스탬프, 데이터 블록 위치 등)</li>
</ul>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">[파일명] → [inode 번호] → [inode] → [데이터 블록]
  (디렉토리가 관리)     (메타데이터)   (실제 내용)
</code></pre></div></code></pre>
<p>파일명 자체는 inode를 가리키는 포인터일 뿐입니다.<br>
이것이 나중에 배울 <strong>하드링크(Hard Link)</strong> 의 원리이기도 합니다.<br>
inode 번호는 <code>ls -i</code> 명령어로 확인할 수 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ls</span> -i /etc/hostname
<span class="hljs-comment"># 출력 예: 134217751 /etc/hostname</span>
</code></pre></div></code></pre>
<hr>
<h2 id="유닉스리눅스-파일-구조의-특징" tabindex="-1" data-src-line="62">유닉스/리눅스 파일 구조의 특징 <a class="header-anchor" href="#유닉스리눅스-파일-구조의-특징" aria-hidden="true">#</a></h2>
<h3 id="단일-루트-구조-singly-rooted" tabindex="-1" data-src-line="64">단일 루트 구조 (Singly Rooted) <a class="header-anchor" href="#단일-루트-구조-singly-rooted" aria-hidden="true">#</a></h3>
<p>Windows에서는 드라이브별로 루트가 나뉩니다 (<code>C:\</code>, <code>D:\</code>).<br>
리눅스는 다릅니다. <strong>모든 파일과 디렉토리는 단 하나의 루트 <code>/</code> 아래에 존재</strong>합니다.</p>
<p>USB를 연결하거나 추가 디스크를 붙이더라도, 별도 드라이브 문자가 생기는 게 아니라<br>
<code>/mnt/usb</code>처럼 기존 디렉토리 트리의 어딘가에 <strong>마운트(mount)</strong> 되는 방식으로 편입됩니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">/
├── home/
│   └── user/
├── etc/
├── var/
├── mnt/
│   └── usb/       ← USB 연결 시 여기에 마운트됨
└── ...
</code></pre></div></code></pre>
<h3 id="대소문자-구분-case-sensitivity" tabindex="-1" data-src-line="83">대소문자 구분 (Case Sensitivity) <a class="header-anchor" href="#대소문자-구분-case-sensitivity" aria-hidden="true">#</a></h3>
<p>리눅스는 파일명에서 <strong>대소문자를 명확히 구분</strong>합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">touch</span> file.txt File.txt FILE.txt
<span class="hljs-built_in">ls</span>
<span class="hljs-comment"># file.txt  File.txt  FILE.txt  ← 세 개가 모두 다른 파일로 존재</span>
</code></pre></div></code></pre>
<p>Windows에서 <code>file.txt</code>와 <code>File.txt</code>는 같은 파일로 취급되지만,<br>
리눅스에서는 완전히 별개의 파일입니다.<br>
이 특성 때문에 스크립트나 프로그램에서 파일명을 다룰 때 오타가 발생하기 쉬우니 주의가 필요합니다.</p>
<h3 id="긴-파일명-지원-long-file-names" tabindex="-1" data-src-line="97">긴 파일명 지원 (Long File Names) <a class="header-anchor" href="#긴-파일명-지원-long-file-names" aria-hidden="true">#</a></h3>
<p>ext4, XFS 기준으로 파일명의 최대 길이는 <strong>255바이트</strong>입니다.<br>
한글은 UTF-8 기준 한 글자에 3바이트이므로 약 85자까지 가능합니다.</p>
<h3 id="링크-지원-supports-links" tabindex="-1" data-src-line="102">링크 지원 (Supports Links) <a class="header-anchor" href="#링크-지원-supports-links" aria-hidden="true">#</a></h3>
<p>같은 파일 데이터를 여러 경로에서 참조할 수 있는 <strong>하드링크와 심볼릭 링크</strong>를 지원합니다. 뒤에서 자세히 다룹니다.</p>
<h3 id="파일-타임스탬프-timestamps" tabindex="-1" data-src-line="106">파일 타임스탬프 (Timestamps) <a class="header-anchor" href="#파일-타임스탬프-timestamps" aria-hidden="true">#</a></h3>
<p>리눅스는 파일마다 세 가지 시간 정보를 관리합니다.</p>
<div class="table-scroll" tabindex="0" role="region" aria-label="Scrollable table"><table>

</tr>

</code></pre></div></code></pre>

<h2 id="리눅스-표준-디렉토리-구조-fhs" tabindex="-1" data-src-line="122">리눅스 표준 디렉토리 구조 (FHS) <a class="header-anchor" href="#리눅스-표준-디렉토리-구조-fhs" aria-hidden="true">#</a></h2>
<p>리눅스는 <strong>FHS(Filesystem Hierarchy Standard)</strong> 라는 표준에 따라 디렉토리 구조가 정해져 있습니다.<br>
어떤 리눅스 배포판이든 최상위 디렉토리 구성은 거의 동일합니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">/
├── bin/        → 기본 실행 파일 (ls, cp, mv 등)
├── sbin/       → 시스템 관리용 실행 파일 (root 권한 필요)
├── etc/        → 시스템 전체 설정 파일
├── home/       → 일반 사용자 홈 디렉토리
├── root/       → root 계정의 홈 디렉토리
├── var/        → 가변 데이터 (로그, 캐시, 메일 등)
├── tmp/        → 임시 파일 (재부팅 시 삭제)
├── usr/        → 사용자 설치 프로그램 및 라이브러리
│   ├── bin/    → 일반 실행 파일 (대부분의 명령어)
│   ├── sbin/   → 시스템 관리 실행 파일
│   └── local/  → 직접 빌드·설치한 프로그램
├── lib/        → 공유 라이브러리
├── dev/        → 디바이스 파일 (하드웨어를 파일로 표현)
├── proc/       → 실행 중인 프로세스 정보 (가상 파일시스템)
├── sys/        → 커널 및 하드웨어 정보 (가상 파일시스템)
├── mnt/        → 임시 마운트 포인트
├── media/      → USB, CD 등 이동식 미디어 마운트 포인트
├── boot/       → 부트로더, 커널 이미지
└── opt/        → 서드파티 소프트웨어 설치 경로
</code></pre></div></code></pre>
<p>자주 마주치는 디렉토리만 짚어두면:</p>
<ul>
<li><code>/etc</code> : 거의 모든 서비스의 설정 파일이 여기에 있습니다. (<code>/etc/ssh/sshd_config</code>, <code>/etc/hosts</code> 등)</li>
<li><code>/var/log</code> : 시스템 로그 파일이 저장되는 곳. 문제가 생겼을 때 가장 먼저 확인합니다.</li>
<li><code>/tmp</code> : 재부팅하면 지워지는 임시 디렉토리. 테스트용 파일을 만들기 좋습니다.</li>
<li><code>/home/사용자명</code> : 내 작업 파일은 여기에 저장합니다.</li>
</ul>

<h2 id="경로-표현-방식" tabindex="-1" data-src-line="159">경로 표현 방식 <a class="header-anchor" href="#경로-표현-방식" aria-hidden="true">#</a></h2>
<h3 id="절대경로-absolute-path" tabindex="-1" data-src-line="161">절대경로 (Absolute Path) <a class="header-anchor" href="#절대경로-absolute-path" aria-hidden="true">#</a></h3>
<p>절대경로는 <strong>루트 <code>/</code> 부터 시작하는 전체 경로</strong>입니다.<br>
현재 위치에 관계없이 항상 동일한 위치를 가리킵니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">vi /home/user/workspace/project1/package.json
<span class="hljs-built_in">cat</span> /etc/hostname
<span class="hljs-built_in">ls</span> /var/log
</code></pre></div></code></pre>
<p>스크립트나 서버 설정 파일 등에서는 절대경로를 사용하는 것이 안전합니다.<br>
현재 위치가 달라져도 동일하게 동작하기 때문입니다.</p>
<h3 id="상대경로-relative-path" tabindex="-1" data-src-line="175">상대경로 (Relative Path) <a class="header-anchor" href="#상대경로-relative-path" aria-hidden="true">#</a></h3>
<p>상대경로는 <strong>현재 위치를 기준으로 하는 경로</strong>입니다.<br>
절대경로보다 짧게 표현할 수 있어 직접 타이핑할 때 편리합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 현재 위치: /home/user</span>
vi workspace/project1/package.json  <span class="hljs-comment"># /home/user/workspace/project1/package.json 과 동일</span>
</code></pre></div></code></pre>
<p>상대경로에서 자주 쓰이는 특수 표현이 있습니다.</p>
<div class="table-scroll" tabindex="0" role="region" aria-label="Scrollable table"><table>
<thead>
<tr>
<th scope="col">표현</th>
<th scope="col">의미</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>.</code> (점 하나)</td>
<td>현재 디렉토리</td>
</tr>
<tr>
<td><code>..</code> (점 두 개)</td>
<td>상위 디렉토리</td>
</tr>
<tr>
<td><code>~</code> (틸드)</td>

<tr>

</tbody>

<span class="hljs-built_in">ls</span> ..         <span class="hljs-comment"># 상위 디렉토리 목록</span>

</code></pre></div></code></pre>

<h2 id="탐색-명령어" tabindex="-1" data-src-line="204">탐색 명령어 <a class="header-anchor" href="#탐색-명령어" aria-hidden="true">#</a></h2>
<h3 id="pwd--현재-위치-확인" tabindex="-1" data-src-line="206">pwd — 현재 위치 확인 <a class="header-anchor" href="#pwd--현재-위치-확인" aria-hidden="true">#</a></h3>
<p><strong>pwd(Print Working Directory)</strong> 는 현재 내가 있는 디렉토리의 절대경로를 출력합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">[user@localhost ~]$ <span class="hljs-built_in">pwd</span>
/home/user
</code></pre></div></code></pre>
<p>처음 로그인하면 홈 디렉토리(<code>/home/사용자명</code>)에 위치합니다.<br>
미로처럼 복잡한 디렉토리를 돌아다니다 길을 잃었을 때 현재 위치를 확인하는 용도로 자주 씁니다.</p>
<hr>
<h3 id="cd--디렉토리-이동" tabindex="-1" data-src-line="220">cd — 디렉토리 이동 <a class="header-anchor" href="#cd--디렉토리-이동" aria-hidden="true">#</a></h3>
<p><strong>cd(Change Directory)</strong> 는 다른 디렉토리로 이동하는 명령어입니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">cd</span> /etc              <span class="hljs-comment"># 절대경로로 이동</span>
<span class="hljs-built_in">cd</span> Documents         <span class="hljs-comment"># 현재 위치의 하위 디렉토리로 이동 (상대경로)</span>
<span class="hljs-built_in">cd</span> ..                <span class="hljs-comment"># 상위 디렉토리로 이동</span>
<span class="hljs-built_in">cd</span> ~                 <span class="hljs-comment"># 홈 디렉토리로 이동</span>
<span class="hljs-built_in">cd</span>                   <span class="hljs-comment"># 인수 없이 실행해도 홈 디렉토리로 이동</span>
<span class="hljs-built_in">cd</span> -                 <span class="hljs-comment"># 바로 이전에 있던 디렉토리로 이동</span>
</code></pre></div></code></pre>
<p><code>cd -</code>는 두 디렉토리를 왔다 갔다 할 때 특히 유용합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">cd</span> /etc/ssh

<span class="hljs-comment"># ... 작업 ...</span>
<span class="hljs-built_in">cd</span> -           <span class="hljs-comment"># /etc/ssh 로 즉시 복귀</span>
</code></pre></div></code></pre>
<hr>
<h3 id="ls--디렉토리-목록-확인" tabindex="-1" data-src-line="245">ls — 디렉토리 목록 확인 <a class="header-anchor" href="#ls--디렉토리-목록-확인" aria-hidden="true">#</a></h3>
<p><strong>ls(List)</strong> 는 파일과 디렉토리 목록을 출력하는 명령어입니다.<br>
리눅스에서 가장 자주 사용하는 명령어 중 하나입니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ls</span>             <span class="hljs-comment"># 현재 디렉토리 목록</span>
<span class="hljs-built_in">ls</span> /etc        <span class="hljs-comment"># 특정 디렉토리 목록</span>
<span class="hljs-built_in">ls</span> -l          <span class="hljs-comment"># 상세 정보 포함</span>
<span class="hljs-built_in">ls</span> -a          <span class="hljs-comment"># 숨김 파일 포함 (. 으로 시작하는 파일)</span>

<span class="hljs-built_in">ls</span> -lh         <span class="hljs-comment"># 파일 크기를 사람이 읽기 쉬운 단위로 출력 (KB, MB, GB)</span>

<span class="hljs-built_in">ls</span> -lS         <span class="hljs-comment"># 파일 크기 기준 내림차순 정렬</span>

<span class="hljs-built_in">ls</span> -1          <span class="hljs-comment"># 한 줄에 하나씩 출력</span>
</code></pre></div></code></pre>
<h4 id="ls--l-출력-형식-읽기" tabindex="-1" data-src-line="263">ls -l 출력 형식 읽기 <a class="header-anchor" href="#ls--l-출력-형식-읽기" aria-hidden="true">#</a></h4>
<p><code>ls -l</code>을 실행하면 아래와 같은 형식의 출력이 나타납니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">-rw-r--r--. 1 user user 1234 Jan 24 21:00 example.txt
drwxr-xr-x. 2 user user 4096 Jan 24 20:00 mydir
</code></pre></div></code></pre>
<p>각 필드의 의미는 다음과 같습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">[파일 타입 + 권한] [하드링크 수] [소유자] [그룹] [크기(bytes)] [수정 시간] [파일명]
 -rw-r--r--.          1          user      user    1234        Jan 24 21:00  example.txt
</code></pre></div></code></pre>

권한 체계는 이후 시리즈에서 별도로 자세히 다룹니다.</p>

<h2 id="와일드카드-wildcard" tabindex="-1" data-src-line="294">와일드카드 (Wildcard) <a class="header-anchor" href="#와일드카드-wildcard" aria-hidden="true">#</a></h2>
<p>파일을 다룰 때 특정 패턴에 맞는 여러 파일을 한 번에 지정하고 싶을 때 <strong>와일드카드</strong>를 사용합니다.</p>
<div class="table-scroll" tabindex="0" role="region" aria-label="Scrollable table"><table>
<thead>
<tr>
<th scope="col">와일드카드</th>
<th scope="col">의미</th>
<th scope="col">예시</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>*</code></td>
<td>0개 이상의 임의 문자</td>
<td><code>*.txt</code> → 확장자가 .txt인 모든 파일</td>
</tr>
<tr>
<td><code>?</code></td>
<td>임의의 문자 1개</td>
<td><code>file?.txt</code> → file1.txt, fileA.txt 등</td>
</tr>
<tr>
<td><code>[abc]</code></td>
<td>괄호 안의 문자 중 하나</td>
<td><code>file[123].txt</code> → file1.txt, file2.txt, file3.txt</td>
</tr>
<tr>
<td><code>[a-z]</code></td>
<td>범위 내 문자 중 하나</td>
<td><code>file[a-z].txt</code> → filea.txt ~ filez.txt</td>
</tr>
<tr>
<td><code>[!abc]</code></td>
<td>괄호 안의 문자를 제외한 나머지</td>
<td><code>file[!0-9].txt</code> → 숫자가 아닌 문자가 붙은 파일</td>
</tr>
</tbody>
</table>
</div><pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ls</span> *.conf          <span class="hljs-comment"># .conf로 끝나는 모든 파일</span>
<span class="hljs-built_in">ls</span> log_202?.txt    <span class="hljs-comment"># log_2020.txt ~ log_2029.txt 등</span>
<span class="hljs-built_in">cp</span> *.jpg /backup/  <span class="hljs-comment"># 현재 디렉토리의 모든 jpg 파일을 backup으로 복사</span>
<span class="hljs-built_in">rm</span> temp_*          <span class="hljs-comment"># temp_ 로 시작하는 파일 전체 삭제</span>
</code></pre></div></code></pre>
<blockquote>
<p>와일드카드는 쉘이 명령어 실행 전에 먼저 해석합니다.<br>
<code>rm temp_*</code> 를 실행하면 쉘이 <code>temp_</code>로 시작하는 파일 목록으로 확장한 뒤 <code>rm</code>에 전달합니다.<br>
따라서 패턴에 해당하는 파일이 없으면 오류가 발생할 수 있습니다.</p>
</blockquote>

<h2 id="디렉토리-조작-명령어" tabindex="-1" data-src-line="319">디렉토리 조작 명령어 <a class="header-anchor" href="#디렉토리-조작-명령어" aria-hidden="true">#</a></h2>
<h3 id="mkdir--디렉토리-생성" tabindex="-1" data-src-line="321">mkdir — 디렉토리 생성 <a class="header-anchor" href="#mkdir--디렉토리-생성" aria-hidden="true">#</a></h3>
<p><strong>mkdir(Make Directory)</strong> 는 새 디렉토리를 생성합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">mkdir</span> mydir               <span class="hljs-comment"># 현재 위치에 mydir 생성</span>
<span class="hljs-built_in">mkdir</span> /tmp/testdir        <span class="hljs-comment"># 절대경로로 생성</span>
<span class="hljs-built_in">mkdir</span> dir1 dir2 dir3      <span class="hljs-comment"># 여러 디렉토리를 한 번에 생성</span>
</code></pre></div></code></pre>
<p><strong><code>-p</code> 옵션</strong>: 중간 경로가 없어도 한 번에 생성합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 중간 디렉토리가 없는 경우</span>
<span class="hljs-built_in">mkdir</span> a/b/c
<span class="hljs-comment"># mkdir: cannot create directory &#x27;a/b/c&#x27;: No such file or directory</span>

<span class="hljs-built_in">mkdir</span> -p a/b/c            <span class="hljs-comment"># a, a/b, a/b/c 를 한 번에 모두 생성</span>
</code></pre></div></code></pre>
<p>이미 존재하는 디렉토리에 <code>-p</code> 옵션을 사용해도 오류 없이 무시됩니다.<br>
스크립트에서 디렉토리 존재 여부를 신경 쓰지 않고 생성할 때 유용합니다.</p>
<p><strong><code>-m</code> 옵션</strong>: 생성과 동시에 권한을 지정합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">mkdir</span> -m 700 private_dir    <span class="hljs-comment"># 소유자만 접근 가능한 디렉토리 생성</span>
</code></pre></div></code></pre>
<hr>
<h3 id="rmdir--빈-디렉토리-삭제" tabindex="-1" data-src-line="352">rmdir — 빈 디렉토리 삭제 <a class="header-anchor" href="#rmdir--빈-디렉토리-삭제" aria-hidden="true">#</a></h3>
<p><strong>rmdir(Remove Directory)</strong> 는 <strong>비어 있는</strong> 디렉토리만 삭제합니다.<br>
파일이 있는 디렉토리는 삭제되지 않습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">rmdir</span> mydir               <span class="hljs-comment"># 비어 있으면 삭제</span>
<span class="hljs-built_in">rmdir</span> -p a/b/c            <span class="hljs-comment"># c, b, a 순서로 비어 있으면 연속 삭제</span>
</code></pre></div></code></pre>
<p>실제로는 내용물이 있는 디렉토리째 삭제하는 경우가 더 많기 때문에, <code>rm -r</code>을 더 자주 사용합니다.</p>

<h2 id="파일-조작-명령어" tabindex="-1" data-src-line="366">파일 조작 명령어 <a class="header-anchor" href="#파일-조작-명령어" aria-hidden="true">#</a></h2>
<h3 id="cp--파일디렉토리-복사" tabindex="-1" data-src-line="368">cp — 파일/디렉토리 복사 <a class="header-anchor" href="#cp--파일디렉토리-복사" aria-hidden="true">#</a></h3>
<p><strong>cp(Copy)</strong> 는 파일이나 디렉토리를 복사합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">cp</span> 원본 사본
</code></pre></div></code></pre>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">cp</span> file.txt file_backup.txt         <span class="hljs-comment"># 같은 위치에 다른 이름으로 복사</span>

<span class="hljs-built_in">cp</span> -r mydir/ /tmp/                  <span class="hljs-comment"># 디렉토리째 복사 (-r 필수)</span>
</code></pre></div></code></pre>

<h3 id="mv--파일디렉토리-이동-및-이름-변경" tabindex="-1" data-src-line="401">mv — 파일/디렉토리 이동 및 이름 변경 <a class="header-anchor" href="#mv--파일디렉토리-이동-및-이름-변경" aria-hidden="true">#</a></h3>

<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">mv</span> 원본 대상

<h3 id="rm--파일디렉토리-삭제" tabindex="-1" data-src-line="430">rm — 파일/디렉토리 삭제 <a class="header-anchor" href="#rm--파일디렉토리-삭제" aria-hidden="true">#</a></h3>
<p><strong>rm(Remove)</strong> 은 파일이나 디렉토리를 삭제합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">rm</span> file.txt                 <span class="hljs-comment"># 파일 삭제</span>
<span class="hljs-built_in">rm</span> file1.txt file2.txt      <span class="hljs-comment"># 여러 파일 삭제</span>
<span class="hljs-built_in">rm</span> *.<span class="hljs-built_in">log</span>                    <span class="hljs-comment"># 확장자가 .log인 파일 전체 삭제</span>
<span class="hljs-built_in">rm</span> -r mydir/                <span class="hljs-comment"># 디렉토리와 내용물 전체 삭제</span>
<span class="hljs-built_in">rm</span> -rf mydir/               <span class="hljs-comment"># 확인 없이 강제 삭제</span>
</code></pre></div></code></pre>
<div class="callout callout-warning">
<h3 class="callout-title">주의 — rm은 휴지통이 없습니다</h3><p></p>
<p>GUI 환경의 삭제는 휴지통에 들어가 복구가 가능하지만,<br>
<strong>리눅스의 <code>rm</code>은 즉시 영구 삭제</strong>입니다. 복구가 거의 불가능합니다.</p>
<p>특히 <code>rm -rf</code>는 디렉토리 전체를 묻지도 따지지도 않고 삭제하기 때문에<br>
아래와 같은 실수는 시스템 전체를 날릴 수 있습니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 절대 실행하면 안 되는 명령어 예시</span>
<span class="hljs-built_in">rm</span> -rf /         <span class="hljs-comment"># 루트 디렉토리 전체 삭제 (시스템 파괴)</span>
<span class="hljs-built_in">rm</span> -rf /*        <span class="hljs-comment"># 루트 아래 모든 것 삭제</span>
</code></pre></div></code></pre>
<p>와일드카드 사용 시에는 항상 <code>ls</code>로 먼저 대상을 확인하고 삭제하는 습관을 들이세요.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ls</span> *.<span class="hljs-built_in">log</span>         <span class="hljs-comment"># 먼저 어떤 파일이 해당되는지 확인</span>
<span class="hljs-built_in">rm</span> *.<span class="hljs-built_in">log</span>         <span class="hljs-comment"># 확인 후 삭제</span>
</code></pre></div></code></pre>
</div>

<h3 id="touch--파일-생성--타임스탬프-변경" tabindex="-1" data-src-line="474">touch — 파일 생성 / 타임스탬프 변경 <a class="header-anchor" href="#touch--파일-생성--타임스탬프-변경" aria-hidden="true">#</a></h3>
<p><strong>touch</strong> 는 두 가지 용도로 사용됩니다.</p>
<p><strong>1. 빈 파일 생성</strong></p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">touch</span> newfile.txt           <span class="hljs-comment"># 내용이 없는 빈 파일 생성</span>
<span class="hljs-built_in">touch</span> file1.txt file2.txt   <span class="hljs-comment"># 여러 파일 동시 생성</span>
</code></pre></div></code></pre>
<p><strong>2. 타임스탬프 갱신</strong></p>
<p>이미 존재하는 파일에 <code>touch</code>를 사용하면 내용은 그대로이고 <code>mtime</code>과 <code>atime</code>이 현재 시각으로 갱신됩니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">touch</span> existing_file.txt    <span class="hljs-comment"># 타임스탬프만 현재 시각으로 갱신</span>
</code></pre></div></code></pre>
<p><strong>활용 사례</strong></p>
<p><code>touch</code>는 단순해 보이지만 다양한 상황에서 쓰입니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># 파일 존재 여부로 특정 동작을 제어하는 패턴 (flag 파일)</span>
<span class="hljs-built_in">touch</span> /etc/nologin    <span class="hljs-comment"># 이 파일이 존재하면 root 외 일반 사용자 로그인 차단</span>
<span class="hljs-built_in">rm</span> /etc/nologin       <span class="hljs-comment"># 삭제하면 다시 로그인 가능</span>

<span class="hljs-comment"># 스크립트에서 빈 로그 파일을 미리 만들어두기</span>
<span class="hljs-built_in">touch</span> /var/log/myapp.log

<span class="hljs-comment"># Makefile에서 의존성 타임스탬프 조작</span>
<span class="hljs-built_in">touch</span> Makefile
</code></pre></div></code></pre>

<h2 id="링크-생성--ln" tabindex="-1" data-src-line="511">링크 생성 : ln <a class="header-anchor" href="#링크-생성--ln" aria-hidden="true">#</a></h2>
<p>리눅스에서 <strong>링크(Link)</strong> 는 하나의 파일 데이터를 여러 경로에서 참조하거나 바로가기를 만드는 기능입니다.<br>
링크에는 두 종류가 있습니다.</p>
<h3 id="하드링크-hard-link" tabindex="-1" data-src-line="516">하드링크 (Hard Link) <a class="header-anchor" href="#하드링크-hard-link" aria-hidden="true">#</a></h3>
<p>하드링크는 <strong>같은 inode를 가리키는 파일명을 하나 더 만드는 것</strong>입니다.<br>
원본과 링크가 동일한 inode를 공유하므로, 어느 쪽을 수정해도 같은 데이터가 변경됩니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ln</span> 원본파일 링크파일
<span class="hljs-built_in">ln</span> file.txt hardlink.txt
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">file.txt    ─┐
              ├→ inode 12345 → 실제 데이터
hardlink.txt ─┘
</code></pre></div></code></pre>
<p>원본 파일을 삭제해도 링크된 파일이 남아 있으면 데이터는 유지됩니다.<br>
inode에 대한 참조(링크) 수가 0이 될 때 비로소 실제 데이터가 삭제됩니다.</p>
<p><strong>하드링크의 제한</strong></p>
<ul>
<li>다른 파일시스템(다른 파티션/디스크)간 하드링크 생성 불가</li>
<li>디렉토리에 하드링크 생성 불가 (시스템 무결성 이슈)</li>
</ul>
<hr>
<h3 id="심볼릭-링크-symbolic-link--soft-link" tabindex="-1" data-src-line="542">심볼릭 링크 (Symbolic Link / Soft Link) <a class="header-anchor" href="#심볼릭-링크-symbolic-link--soft-link" aria-hidden="true">#</a></h3>
<p>심볼릭 링크는 <strong>파일 경로를 가리키는 별도의 파일</strong>을 만드는 것입니다.<br>
Windows의 바로가기(.lnk)와 개념이 유사합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ln</span> -s 원본파일 링크파일
<span class="hljs-built_in">ln</span> -s /etc/nginx/nginx.conf ~/nginx.conf
<span class="hljs-built_in">ln</span> -s /usr/local/bin/python3.11 /usr/local/bin/python   <span class="hljs-comment"># 버전 관리에 자주 활용</span>
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">symlink.txt → &quot;/home/user/original.txt&quot; → inode 12345 → 실제 데이터
  (별도 inode, 경로 저장)
</code></pre></div></code></pre>
<p>원본 파일이 삭제되면 심볼릭 링크는 <strong>깨진 링크(Dangling Link)</strong> 가 됩니다.<br>
<code>ls -l</code> 에서 붉은색으로 표시됩니다.</p>
<p><strong>심볼릭 링크의 장점</strong></p>
<ul>
<li>파일시스템 경계를 넘어 생성 가능</li>
<li>디렉토리에도 생성 가능</li>
<li>원본 경로를 저장하므로 링크 대상 확인이 쉬움</li>
</ul>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">ls</span> -l symlink.txt
<span class="hljs-comment"># lrwxrwxrwx. 1 user user 20 Jan 24 21:00 symlink.txt -&gt; /home/user/original.txt</span>

<span class="hljs-built_in">readlink</span> symlink.txt    <span class="hljs-comment"># 링크가 가리키는 경로 출력</span>
</code></pre></div></code></pre>
<hr>

<h2 id="alias--자주-쓰는-명령어-단축키-만들기" tabindex="-1" data-src-line="589">Alias — 자주 쓰는 명령어 단축키 만들기 <a class="header-anchor" href="#alias--자주-쓰는-명령어-단축키-만들기" aria-hidden="true">#</a></h2>
<p><code>alias</code>는 자주 사용하는 명령어(+ 옵션 조합)에 별명을 붙이는 기능입니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">alias</span> ll=<span class="hljs-string">&#x27;ls -alh&#x27;</span>
<span class="hljs-built_in">alias</span> la=<span class="hljs-string">&#x27;ls -a&#x27;</span>
<span class="hljs-built_in">alias</span> <span class="hljs-built_in">rm</span>=<span class="hljs-string">&#x27;rm -i&#x27;</span>
<span class="hljs-built_in">alias</span> <span class="hljs-built_in">cp</span>=<span class="hljs-string">&#x27;cp -i&#x27;</span>
<span class="hljs-built_in">alias</span> <span class="hljs-built_in">mv</span>=<span class="hljs-string">&#x27;mv -i&#x27;</span>
</code></pre></div></code></pre>
<p>설정 후에는 <code>ll</code>만 입력해도 <code>ls -alh</code>가 실행됩니다.</p>
<p>현재 세션에서만 유효한 alias는 터미널을 닫으면 사라집니다.<br>
재시작 후에도 유지하려면 <code>~/.bashrc</code> 파일에 추가합니다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-comment"># ~/.bashrc 에 추가</span>
<span class="hljs-built_in">alias</span> ll=<span class="hljs-string">&#x27;ls -alh&#x27;</span>
<span class="hljs-built_in">alias</span> <span class="hljs-built_in">rm</span>=<span class="hljs-string">&#x27;rm -i&#x27;</span>
<span class="hljs-built_in">alias</span> <span class="hljs-built_in">cp</span>=<span class="hljs-string">&#x27;cp -i&#x27;</span>
<span class="hljs-built_in">alias</span> <span class="hljs-built_in">mv</span>=<span class="hljs-string">&#x27;mv -i&#x27;</span>

<span class="hljs-comment"># 변경 사항 즉시 적용</span>
<span class="hljs-built_in">source</span> ~/.bashrc
</code></pre></div></code></pre>
<blockquote>
<p><code>rm</code>, <code>cp</code>, <code>mv</code>에 <code>-i</code> 옵션을 alias로 걸어두는 것은 <strong>리눅스 입문 시기에 가장 먼저 해야 할 설정</strong> 중 하나입니다.<br>
실수로 파일을 덮어쓰거나 삭제하는 상황을 예방해줍니다.</p>
</blockquote>
<p>등록된 alias 목록 확인:</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash"><span class="hljs-built_in">alias</span>         <span class="hljs-comment"># 모든 alias 목록 출력</span>

<h2 id="마치면서" tabindex="-1" data-src-line="647">마치면서 <a class="header-anchor" href="#마치면서" aria-hidden="true">#</a></h2>
<p>이번 글에서는 리눅스 파일시스템의 구조와 파일·디렉토리를 다루는 핵심 명령어들을 정리했습니다.<br>
전부 외울 필요는 없습니다. 자주 쓰다 보면 자연스럽게 손에 익고,<br>
가끔 쓰는 옵션은 <code>man ls</code>나 <code>ls --help</code>로 확인하면 됩니다.</p>
<p>특히 <code>rm</code>의 동작은 한 번 더 주의 깊게 기억해두는 것을 권장합니다.<br>
서버 환경에서 실수로 <code>/</code> 아래 중요한 파일을 날리면 복구가 정말 어렵습니다.<br>
<code>alias rm='rm -i'</code> 설정 하나만으로도 많은 사고를 예방할 수 있습니다.</p>
<p>다음 글에서는 터미널에서 각종 정보를 얻거나 명령어 매뉴얼을 확인하는 방법,<br>
그리고 파일 내용을 읽고 검색하는 명령어(<code>cat</code>, <code>less</code>, <code>grep</code> 등)에 대해 정리하겠습니다.</p>
