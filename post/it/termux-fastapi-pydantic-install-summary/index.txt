25:T13a5,<h2 id="들어가기" tabindex="-1" data-src-line="1">들어가기 <a class="header-anchor" href="#들어가기" aria-hidden="true">#</a></h2>
<p>Termux에서 간단히 FastAPI 테스트를 하려다가 설치 단계에서 계속 막혔다. 처음에는 <code>fastapi</code> 자체 문제라고 생각했지만, 실제 원인은 <code>pydantic-core</code> 빌드에 필요한 도구가 누락된 상태였다.</p>
<p>같은 증상을 겪는 분들이 로그를 붙잡고 오래 헤매지 않도록, 내가 확인한 오류 흐름과 해결 순서를 정리한다.</p>
<div class="callout callout-note">
<p>이 글은 아래 원문을 참고해 핵심 흐름을 재구성한 요약 기록이다. 원문 전문을 복제하지 않고, 실제 설치 시 필요한 포인트 중심으로 정리했다.</p>
</div>
<hr>
<h2 id="1-설치할-때-어떤-에러가-나왔나" tabindex="-1" data-src-line="12">1. 설치할 때 어떤 에러가 나왔나 <a class="header-anchor" href="#1-설치할-때-어떤-에러가-나왔나" aria-hidden="true">#</a></h2>
<p>실패 흐름은 아래처럼 반복됐다.</p>
<ol>
<li><code>python -m pip install fastapi</code></li>
<li>의존성 설치 중 <code>pydantic-core</code> 빌드 실패</li>
<li><code>pip</code> 업그레이드 안내가 뜨지만 Termux 환경에서는 이 방식이 도움이 안 됨</li>
<li><code>python -m pip install pydantic</code> 단독 설치 시 <code>can't find Rust compiler</code></li>
<li>Rust 설치 후에는 <code>aarch64-linux-android-ar</code> 관련 오류가 추가로 발생</li>
</ol>
<p>여기까지 오면 결론은 명확하다. <strong>파이썬 패키지 자체 문제가 아니라, Termux의 네이티브 빌드 툴체인 부족 문제</strong>다.</p>
<hr>
<h2 id="2-해결-순서-그대로-따라-하면-됨" tabindex="-1" data-src-line="26">2. 해결 순서 (그대로 따라 하면 됨) <a class="header-anchor" href="#2-해결-순서-그대로-따라-하면-됨" aria-hidden="true">#</a></h2>
<p>아래 순서로 설치하니 정상적으로 진행됐다.</p>
<pre><code class="language-bash"><div class="code-block"><div class="code-header"><span class="code-title">bash</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-bash"><code class="hljs language-bash">pkg install binutils
pkg install rust
pkg install build-essential
python -m pip install pydantic
python -m pip install fastapi
</code></pre></div></code></pre>
<p>왜 이 순서가 중요한지는 아래 두 줄로 요약된다.</p>
<ul>
<li><code>rust</code>: <code>pydantic-core</code>를 빌드할 때 필요</li>
<li><code>binutils</code>: <code>aarch64-linux-android-ar</code> 같은 툴 제공</li>
</ul>
<p>가능하면 가상환경(venv)에서 진행하는 것을 추천한다. 기존 패키지와 충돌 가능성을 줄일 수 있다.</p>
<hr>
<h2 id="3-설치-후-확인할-점-접속-범위" tabindex="-1" data-src-line="47">3. 설치 후 확인할 점 (접속 범위) <a class="header-anchor" href="#3-설치-후-확인할-점-접속-범위" aria-hidden="true">#</a></h2>
<p>설치가 끝난 뒤 서버 실행 자체는 됐지만, 접속 범위는 따로 확인이 필요했다.</p>
<ul>
<li>휴대폰 내부 <code>localhost</code> 접속: 가능</li>
<li>같은 와이파이의 다른 PC에서 안드로이드 IP 접속: 환경에 따라 실패 가능</li>
</ul>
<p>이 부분은 파이썬 라이브러리 문제가 아니라 안드로이드 단 정책/네트워크 제한 영향이 크다. 외부 기기 접근이 필요하면 방화벽, 포트, 단말 보안 정책을 함께 점검해야 한다.</p>
<hr>
<h2 id="4-빠른-체크리스트" tabindex="-1" data-src-line="58">4. 빠른 체크리스트 <a class="header-anchor" href="#4-빠른-체크리스트" aria-hidden="true">#</a></h2>
<ul>
<li>오류 로그에 <code>Rust compiler</code> / <code>aarch64-linux-android-ar</code>가 보이는지 확인</li>
<li><code>binutils</code>, <code>rust</code>, <code>build-essential</code> 먼저 설치</li>
<li><code>pydantic</code> 설치 성공 후 <code>fastapi</code> 설치</li>
<li>로컬 접속과 외부 기기 접속을 분리해서 테스트</li>
</ul>
<hr>
<h2 id="마무리" tabindex="-1" data-src-line="67">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>Termux에서 FastAPI가 설치되지 않을 때는 <code>fastapi</code> 자체보다 <code>pydantic-core</code>의 네이티브 빌드 환경을 먼저 의심하는 게 훨씬 빠르다. 같은 오류를 만난 분들께 이 순서가 바로 해결에 도움이 되었으면 한다.</p>
