<nav class="md-toc"><ul><li><a href="#일본어-3강-자기소개------">일본어 3강: 자기소개 — ～は～です · じゃありません · ですか </a><ul><li><a href="#들어가기-앞서">들어가기 앞서 </a></li><li><a href="#1-기본-문형-">1. 기본 문형: ～は～です </a><ul><li><a href="#예문">예문 </a></li></ul></li><li><a href="#2-부정문-">2. 부정문: ～は～じゃありません </a><ul><li><a href="#예문-1">예문 </a></li></ul></li><li><a href="#3-의문문-">3. 의문문: ～は～ですか </a><ul><li><a href="#예문-및-대답">예문 및 대답 </a></li></ul></li><li><a href="#4-조사---소속소유-표현">4. 조사 の — 소속·소유 표현 </a><ul><li><a href="#예문-2">예문 </a></li></ul></li><li><a href="#5-조사---도-표현">5. 조사 も — ‘~도’ 표현 </a></li><li><a href="#6-자주-쓰는-자기소개-어휘">6. 자주 쓰는 자기소개 어휘 </a><ul><li><a href="#국적">국적 </a></li><li><a href="#직업">직업 </a></li><li><a href="#소속-표현">소속 표현 </a></li></ul></li><li><a href="#7-자기소개-실전-예문">7. 자기소개 실전 예문 </a></li><li><a href="#8-문형-정리">8. 문형 정리 </a></li><li><a href="#마무리">마무리 </a></li></ul></li></ul></nav><h2 id="들어가기-앞서" tabindex="-1" data-src-line="5">들어가기 앞서 <a class="header-anchor" href="#들어가기-앞서" aria-hidden="true">#</a></h2>
<p>드디어 문장입니다!<br>
3강에서는 일본어에서 가장 먼저 배우는 문형인 <strong>명사문</strong>을 다룹니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li><code>～は～です</code> 로 긍정 문장을 만들 수 있습니다.</li>
<li><code>～は～じゃありません</code> 으로 부정 문장을 만들 수 있습니다.</li>
<li><code>～は～ですか</code> 로 의문 문장을 만들 수 있습니다.</li>
<li>조사 <code>は</code> · <code>も</code> · <code>の</code> 의 기본 쓰임을 이해할 수 있습니다.</li>
<li>간단한 자기소개를 일본어로 할 수 있습니다.</li>
</ul>
</blockquote>
<hr>
<h2 id="1-기본-문형-" tabindex="-1" data-src-line="19">1. 기본 문형: ～は～です <a class="header-anchor" href="#1-기본-문형-" aria-hidden="true">#</a></h2>
<p>일본어 명사문의 기본 구조는 다음과 같습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">[주어] は [명사] です。
</code></pre></div></code></pre>

<tr>
<td>は</td>
<td>주제 조사</td>

</tr>
<tr>
<td>です</td>
<td>정중한 서술어</td>

</div><h3 id="예문" tabindex="-1" data-src-line="32">예문 <a class="header-anchor" href="#예문" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">わたしは キム・チョルスです。
와타시와 키무 쵸루스데스。
(저는 김철수입니다.)

わたしは かんこくじんです。
와타시와 칸코쿠진데스。
(저는 한국인입니다.)

わたしは かいしゃいんです。
와타시와 카이샤인데스。
(저는 회사원입니다.)
</code></pre></div></code></pre>
<blockquote>
<p>⚠️ <strong>주의</strong>: <code>は</code> 는 조사로 쓰일 때 <strong>‘와(wa)’</strong> 로 읽습니다. 문자 그대로 '하(ha)'로 읽지 않도록 주의하세요.</p>
</blockquote>

<h2 id="2-부정문-" tabindex="-1" data-src-line="52">2. 부정문: ～は～じゃありません <a class="header-anchor" href="#2-부정문-" aria-hidden="true">#</a></h2>

<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">[주어] は [명사] じゃありません。
</code></pre></div></code></pre>

<h2 id="3-의문문-" tabindex="-1" data-src-line="79">3. 의문문: ～は～ですか <a class="header-anchor" href="#3-의문문-" aria-hidden="true">#</a></h2>
<p>일본어 의문문은 문장 끝에 <code>か</code> 를 붙이기만 하면 됩니다.<br>
어순 변화가 없고, 억양을 올릴 필요도 없습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">[주어] は [명사] ですか。
</code></pre></div></code></pre>
<h3 id="예문-및-대답" tabindex="-1" data-src-line="88">예문 및 대답 <a class="header-anchor" href="#예문-및-대답" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">Q: あなたは がくせいですか。
   아나타와 가쿠세이데스카?
   (당신은 학생입니까?)

A: はい、がくせいです。
   하이、가쿠세이데스。
   (네, 학생입니다.)

A: いいえ、がくせいじゃありません。
   이이에、가쿠세이쟈아리마셍。
   (아니요, 학생이 아닙니다.)
</code></pre></div></code></pre>
<blockquote>
<p>💡 <strong>팁</strong>: 일본어에서 <code>あなた(당신)</code> 는 직접 사용하면 다소 어색할 수 있습니다. 실제 회화에서는 상대방의 이름이나 직함을 사용하는 것이 자연스럽습니다.</p>
</blockquote>

<h2 id="마무리" tabindex="-1" data-src-line="214">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>이제 일본어로 <strong>간단한 자기소개</strong>를 할 수 있게 되었습니다.<br>
<code>は・も・の</code> 세 조사는 앞으로도 모든 문장에서 계속 등장하므로 확실히 익혀두는 것이 중요합니다.</p>
<p>다음 강에서는 <strong>지시대명사(これ·それ·あれ·どれ)</strong> 를 배우며 주변 사물을 일본어로 표현해 봅니다.</p>
<hr>
<blockquote>
<p>📚 <strong>시리즈 목차</strong></p>
<p><strong>[초급 전반 — N5 레벨]</strong></p>
<ul>
<li>1강: 히라가나 · 가타카나 완전 정복</li>
<li>2강: 발음 규칙 — 탁음 · 반탁음 · 요음 · 촉음 · 장음</li>
<li><strong>3강</strong>: 자기소개 — ～は～です · じゃありません · ですか ← 현재 글</li>
<li>4강: 지시대명사 — これ · それ · あれ · どれ</li>
<li>5강: 숫자와 시간 표현 — ～時 · ～分 · ～円</li>
<li>6강: 동사 기초 — ます형 · 이동 표현 (～へ行きます)</li>
<li>7강: 조사 — を · で · と · に</li>
<li>8강: 수수 표현 — あげます · もらいます · くれます</li>
<li>9강: 형용사 — い형용사 · な형용사 활용</li>
<li>10강: 존재 표현 — います · あります · 위치 표현</li>
</ul>
<p><strong>[초급 후반 — N4 레벨]</strong></p>
<ul>
<li>11강: て형 만들기 — 동사 그룹별 활용</li>
<li>12강: ~ている — 진행 · 상태 표현</li>
<li>13강: ~てください · ~てもいいです · ~てはいけません</li>
<li>14강: 가능 표현 — 동사 가능형 · ～ことができます</li>
<li>15강: 경험 표현 — ～たことがあります</li>
<li>16강: 조건 표현 — ～たら · ～ば · ～と · ～なら</li>
<li>17강: 수수 표현 심화 — ～てあげる · もらう · くれる</li>
<li>18강: 경어 표현 — 존경어 · 겸양어 · 정중어 완전 정리</li>
</ul>
