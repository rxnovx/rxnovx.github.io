<p>“일본어를 말할 수 있습니다”, “수영을 할 수 없습니다” —<br>
능력과 가능성을 나타내는 표현은 자기소개나 일상 대화에서 정말 자주 쓰입니다.<br>
일본어에서는 가능 표현을 만드는 방법이 크게 두 가지입니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>1·2·3그룹 동사의 가능형을 모두 만들 수 있습니다.</li>
<li>～ことができます와 가능형의 차이·뉘앙스를 구분할 수 있습니다.</li>
<li>가능 표현에서 쓰이는 조사(を→が)의 변화를 이해할 수 있습니다.</li>
<li>가능·불가능을 다양한 정중도로 표현할 수 있습니다.</li>
</ul>
</blockquote>

<h2 id="6-가능형의-조사-변화----" tabindex="-1" data-src-line="133">6. 가능형의 조사 변화 — を → が <a class="header-anchor" href="#6-가능형의-조사-변화----" aria-hidden="true">#</a></h2>
<p>가능 표현에서는 목적어 조사 <code>を</code>가 <code>が</code>로 바뀌는 경우가 많습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">【일반 동사】

</code></pre></div></code></pre>

<p>💡 <strong>を도 틀리지는 않습니다</strong><br>

<code>にほんごを はなせます</code>도 자연스럽습니다. 단, <code>が</code>가 더 전형적인 표현입니다.</p>
</blockquote>

<h2 id="마무리" tabindex="-1" data-src-line="349">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>가능형 변환 규칙을 다시 한번 정리합니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">1그룹: 어미 う단 → え단 + る
      かく → かける / はなす → はなせる / のむ → のめる

2그룹: る 제거 + られる
      たべる → たべられる / みる → みられる

3그룹: する → できる / くる → こられる
</code></pre></div></code></pre>
<p>일상 회화에서는 <strong>가능형</strong>, 공식적인 자리·문서에서는 <strong>ことができます</strong>를 선택하면 자연스럽습니다.</p>
<p>다음 강에서는 <strong>경험 표현</strong> — <code>～たことがあります</code>를 배우며 과거의 경험을 일본어로 표현하는 방법을 익혀봅니다.</p>
