들어가기 앞서 #

“일본어를 말할 수 있습니다”, “수영을 할 수 없습니다” —
능력과 가능성을 나타내는 표현은 자기소개나 일상 대화에서 정말 자주 쓰입니다.
일본어에서는 가능 표현을 만드는 방법이 크게 두 가지입니다.

이 글을 읽고 나면:

  • 1·2·3그룹 동사의 가능형을 모두 만들 수 있습니다.
  • ～ことができます와 가능형의 차이·뉘앙스를 구분할 수 있습니다.
  • 가능 표현에서 쓰이는 조사(を→が)의 변화를 이해할 수 있습니다.
  • 가능·불가능을 다양한 정중도로 표현할 수 있습니다.

1. 가능 표현의 두 가지 방법 #

방법 형태 예시
① 가능형 동사를 가능형으로 변환 にほんごが はなせます
② ことができます 동사 기본형 + ことができます にほんごを はなすことができます

두 방법 모두 "~할 수 있다"는 뜻이지만, 뉘앙스와 사용 상황이 약간 다릅니다.
먼저 가능형 만드는 법부터 익혀봅니다.

2. 가능형 만들기 — 2그룹 #

2그룹은 가장 단순합니다.

plain
2그룹: 어미 る 제거 + られる (→ られます)
사전형 가능형 의미
たべる たべられる 먹을 수 있다
みる みられる 볼 수 있다
おきる おきられる 일어날 수 있다
ねる ねられる 잘 수 있다
おしえる おしえられる 가르칠 수 있다
でる でられる 나갈 수 있다

💡 구어체 축약: 회화에서는 られる의 ら를 빼고 れる만 쓰는 경우가 많습니다.
(ら抜き言葉 — 「ら」빠진 말)

plain
たべられる → たべれる (구어체)
みられる  → みれる  (구어체)

문어체·공식 문서에서는 られる가 정확한 표현입니다.

3. 가능형 만들기 — 3그룹 #

3그룹은 불규칙이므로 통째로 암기합니다.

plain
する → できる
くる → こられる
사전형 가능형 의미
する できる 할 수 있다
くる こられる 올 수 있다

4. 가능형 만들기 — 1그룹 #

1그룹은 어미의 う단 → え단 + る 로 변환합니다.

plain
1그룹: 어미 う단 → え단 + る (→ ます)
う단 어미 え단 변환 예시
く → け かく → かける 쓸 수 있다
ぐ → げ およぐ → およげる 수영할 수 있다
す → せ はなす → はなせる 말할 수 있다
つ → て まつ → まてる 기다릴 수 있다
ぬ → ね しぬ → しねる 죽을 수 있다
ぶ → べ あそぶ → あそべる 놀 수 있다
む → め のむ → のめる 마실 수 있다
る → れ かえる → かえれる 돌아갈 수 있다
う → え かう → かえる ※ 살 수 있다

⚠️ かう(사다) 가능형 かえる는 かえる(돌아가다)와 발음이 같습니다. 문맥으로 구분합니다.

6. 가능형의 조사 변화 — を → が #

가능 표현에서는 목적어 조사 を가 が로 바뀌는 경우가 많습니다.

plain
【일반 동사】
にほんごを はなします。
일본어를 말합니다.

【가능형】
にほんごが はなせます。
일본어를 말할 수 있습니다.

💡 を도 틀리지는 않습니다
현대 일본어 회화에서는 가능형에 を를 쓰는 경우도 많습니다.
にほんごを はなせます도 자연스럽습니다. 단, が가 더 전형적인 표현입니다.

조사 변화 예시 #

plain
さけを のむ → さけが のめます
(술을 마신다 → 술을 마실 수 있습니다)

かんじを かく → かんじが かけます
(한자를 쓴다 → 한자를 쓸 수 있습니다)

くるまを うんてんする → くるまが うんてんできます
(차를 운전한다 → 차를 운전할 수 있습니다)

7. 가능형 활용표 #

가능형 자체가 2그룹 동사처럼 활용됩니다.

형태 만드는 법 たべる 예시
현재 긍정 가능형 기본 たべられます
현재 부정 られる → られない たべられません
과거 긍정 られる → られた たべられました
과거 부정 られる → られなかった たべられませんでした 
plain
むかしは からい ものが たべられませんでした。
예전에는 매운 것을 먹을 수 없었습니다.

こどものころ、はやく おきられませんでした。
어릴 때, 일찍 일어날 수 없었습니다.

いちじかんで ここまで こられました。
1시간 만에 여기까지 올 수 있었습니다.

8. ～ことができます #

두 번째 가능 표현 방법입니다.

plain
동사 기본형(사전형) + ことができます
(~할 수 있습니다)
사전형 ことができます형 의미
はなす はなすことができます 말할 수 있습니다
よむ よむことができます 읽을 수 있습니다
する することができます 할 수 있습니다
いく いくことができます 갈 수 있습니다

예문 #

plain
わたしは にほんごと えいごを はなすことができます。
나는 일본어와 영어를 말할 수 있습니다.

このアプリで かんたんに やくすことができます。
이 앱으로 간단하게 번역할 수 있습니다.

ここでは クレジットカードを つかうことができます。
여기서는 신용카드를 사용할 수 있습니다.

부정형 #

plain
동사 기본형 + ことができません
(~할 수 없습니다)

じかんが なくて、いくことができませんでした。
시간이 없어서, 갈 수 없었습니다.

からだの ぐあいが わるくて、しごとに いくことができません。
몸 상태가 좋지 않아서, 일을 하러 갈 수 없습니다.

9. 가능형 vs ことができます — 뉘앙스 차이 #

항목 가능형 ことができます
문체 회화체·구어체 격식체·문어체
자연스러움 일상 대화에 자연스러움 공식 문서·자기소개서에 적합
길이 짧고 간결 길고 정중한 느낌 
plain
【일상 회화 — 가능형이 더 자연스러움】
にほんごが はなせます。
일본어를 말할 수 있습니다.

【자기소개서·공식 문서 — ことができます가 더 적합】
にほんごを はなすことができます。
일본어를 말할 수 있습니다.

💡 실용 포인트: 일상 회화에서는 가능형을, 이력서·자기소개·공식 장면에서는 ことができます를 쓰는 것이 자연스럽습니다.

10. 가능 표현 응용 #

① ~ことができるようになりました — ~할 수 있게 되었습니다 (변화) #

plain
べんきょうして、かんじが よめるようになりました。
공부해서, 한자를 읽을 수 있게 되었습니다.

にほんに きてから、にほんごが はなせるようになりました。
일본에 온 후, 일본어를 말할 수 있게 되었습니다.

② ~ことができなくなりました — ~할 수 없게 되었습니다 (상실) #

plain
けがで、しばらく はしることができなくなりました。
부상으로, 당분간 달릴 수 없게 되었습니다.

③ どのくらい ~ことができますか — 어느 정도 ~할 수 있습니까? #

plain
にほんごは どのくらい はなせますか。
일본어는 어느 정도 말할 수 있습니까?

どんな りょうりが つくれますか。
어떤 요리를 만들 수 있습니까?

11. 실전 회화 — 취업 면접 #

plain
めんせつかん：どんな げんごが はなせますか。
             도나 겐고가 하나세마스카?
             (어떤 언어를 말할 수 있습니까?)

おうぼしゃ：にほんごと えいごを はなすことができます。
           니혼고토 에이고오 하나스코토가 데키마스。
           (일본어와 영어를 말할 수 있습니다.)
           
           かんこくごも すこし はなせます。
           칸코쿠고모 스코시 하나세마스。
           (한국어도 조금 말할 수 있습니다.)

めんせつかん：パソコンは つかえますか。
             파소콘와 츠카에마스카?
             (컴퓨터는 사용할 수 있습니까?)

おうぼしゃ：はい、ワードや エクセルは もちろん、
           하이、와아도야 에쿠세루와 모치론、
           (네, 워드나 엑셀은 물론이고,)
           
           プログラミングも することができます。
           프로그라밍구모 스루코토가 데키마스。
           (프로그래밍도 할 수 있습니다.)

めんせつかん：しゅっちょうは できますか。
             슛쵸우와 데키마스카?
             (출장은 가능합니까?)

おうぼしゃ：はい、こくないは もちろん、かいがいにも
           いくことができます。
           하이、코쿠나이와 모치론、카이가이니모
           이쿠코토가 데키마스。
           (네, 국내는 물론, 해외에도 갈 수 있습니다.)

めんせつかん：いつから はたらくことが できますか。
             이츠카라 하타라쿠코토가 데키마스카?
             (언제부터 일할 수 있습니까?)

おうぼしゃ：らいげつから すぐに はじめられます。
           라이게츠카라 스구니 하지메라레마스。
           (다음 달부터 바로 시작할 수 있습니다.)

12. 문형 정리 #

문형 의미 예문
가능형 + ます ~할 수 있습니다 はなせます
가능형 + ません ~할 수 없습니다 はなせません
가능형 + ました ~할 수 있었습니다 はなせました
가능형 + ませんでした ~할 수 없었습니다 はなせませんでした
기본형 + ことができます ~할 수 있습니다 (격식) はなすことができます
기본형 + ことができません ~할 수 없습니다 (격식) はなすことができません
가능형 + ようになりました ~할 수 있게 되었습니다 はなせるようになりました

마무리 #

가능형 변환 규칙을 다시 한번 정리합니다.

plain
1그룹: 어미 う단 → え단 + る
      かく → かける / はなす → はなせる / のむ → のめる

2그룹: る 제거 + られる
      たべる → たべられる / みる → みられる

3그룹: する → できる / くる → こられる

일상 회화에서는 가능형, 공식적인 자리·문서에서는 ことができます를 선택하면 자연스럽습니다.

다음 강에서는 경험 표현 — ～たことがあります를 배우며 과거의 경험을 일본어로 표현하는 방법을 익혀봅니다.

📚 시리즈 목차

[초급 전반 — N5 레벨] ✅ 완료

  • 1강 ~ 10강 완료

[초급 후반 — N4 레벨]

  • 11강: て형 만들기 — 동사 그룹별 활용
  • 12강: ~ている — 진행 · 상태 · 습관 표현
  • 13강: ~てください · ~てもいいです · ~てはいけません
  • 14강: 가능 표현 — 동사 가능형 · ～ことができます ← 현재 글
  • 15강: 경험 표현 — ～たことがあります
  • 16강: 조건 표현 — ～たら · ～ば · ～と · ～なら
  • 17강: 수수 표현 심화 — ～てあげる · もらう · くれる
  • 18강: 경어 표현 — 존경어 · 겸양어 · 정중어 완전 정리
