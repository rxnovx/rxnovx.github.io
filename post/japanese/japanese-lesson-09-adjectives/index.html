들어가기 앞서 #

일본어 형용사는 크게 두 종류로 나뉩니다. い형용사와 な형용사입니다.
두 종류는 생김새도 다르고 활용 방식도 다르지만, 원리를 익히면 모든 형용사에 일관되게 적용할 수 있습니다.

이 글을 읽고 나면:

  • い형용사와 な형용사를 구분할 수 있습니다.
  • 현재 긍정·부정, 과거 긍정·부정 4가지 형태를 만들 수 있습니다.
  • 명사를 수식하는 형태(연체형)를 만들 수 있습니다.
  • 부사적 활용(~く·~に)을 이해할 수 있습니다.
  • 자주 쓰이는 형용사 50개를 익힐 수 있습니다.

1. い형용사란? #

사전형(기본형)이 い로 끝나는 형용사입니다.
어미 い 를 직접 변형하여 활용합니다.

대표 い형용사 25개 #

い형용사 읽기 의미
おおきい 오오키이 크다
ちいさい 치이사이 작다
たかい 타카이 높다, 비싸다
やすい 야스이 저렴하다
ながい 나가이 길다
みじかい 미지카이 짧다
あつい 아츠이 덥다, 뜨겁다
さむい 사무이 춥다
つめたい 츠메타이 차갑다
あたらしい 아타라시이 새롭다
ふるい 후루이 오래되다, 낡다
いい / よい 이이 / 요이 좋다
わるい 와루이 나쁘다
おもしろい 오모시로이 재미있다
つまらない 츠마라나이 재미없다
むずかしい 무즈카시이 어렵다
やさしい 야사시이 쉽다, 친절하다
たのしい 타노시이 즐겁다
かなしい 카나시이 슬프다
いそがしい 이소가시이 바쁘다
おいしい 오이시이 맛있다
まずい 마즈이 맛없다
はやい 하야이 빠르다, 이르다
おそい 오소이 느리다, 늦다
あかるい 아카루이 밝다

2. い형용사 활용표 #

어미 い 를 기준으로 변형합니다. いい(좋다) 는 불규칙이므로 주의!

형태 만드는 법 たかい 예시 いい 예시
현재 긍정 기본형 たかいです いいです
현재 부정 い → くない たかくないです よくないです ⚠️
과거 긍정 い → かった たかかったです よかったです ⚠️
과거 부정 い → くなかった たかくなかったです よくなかったです ⚠️

⚠️ いい의 불규칙 활용
いい는 부정·과거 활용 시 よい 의 형태로 변합니다.

  • いいです → よくないです (좋지 않습니다)
  • いいです → よかったです (좋았습니다)
  • いいです → よくなかったです (좋지 않았습니다)

예문 #

plain
このレストランは たかいです。
이 레스토랑은 비쌉니다.

このレストランは たかくないです。
이 레스토랑은 비싸지 않습니다.

あのえいがは おもしろかったです。
저 영화는 재미있었습니다.

きのうの テストは むずかしくなかったです。
어제 시험은 어렵지 않았습니다.

きょうは てんきが いいです。
오늘은 날씨가 좋습니다.

あのみせは よかったです。
그 가게는 좋았습니다.

3. い형용사의 명사 수식 (연체형) #

명사 앞에 그대로 붙여서 수식합니다. 형태 변화 없이 기본형을 사용합니다.

plain
い형용사 + 명사

plain
おおきい いぬ
큰 개

あたらしい かばん
새 가방

おいしい りょうり
맛있는 요리

むずかしい もんだい
어려운 문제

부정형으로 수식 #

부정형(くない)도 명사를 수식할 수 있습니다.

plain
たかくない レストラン
비싸지 않은 레스토랑

おもしろくない えいが
재미없는 영화

4. い형용사의 부사적 활용 (~く) #

い형용사의 어미 い 를 く 로 바꾸면 부사가 됩니다.

plain
い → く

はやい → はやく (빠르게)
やさしい → やさしく (친절하게)
おおきい → おおきく (크게)

plain
はやく はしります。
빠르게 달립니다.

やさしく おしえてください。
친절하게 가르쳐 주세요.

おおきく こえを だしてください。
크게 목소리를 내주세요.

5. な형용사란? #

な형용사는 사전형이 な로 끝나지 않고, 명사를 수식할 때 な를 붙이는 형용사입니다.
활용 방식이 명사문(です·じゃありません)과 동일합니다.

대표 な형용사 25개 #

な형용사 읽기 의미
きれい(な) 키레이 예쁘다, 깨끗하다
すき(な) 스키 좋아하다
きらい(な) 키라이 싫어하다
じょうず(な) 죠우즈 잘하다
へた(な) 헤타 못하다
しんせつ(な) 신세츠 친절하다
ていねい(な) 테이네이 정중하다, 꼼꼼하다
ゆうめい(な) 유우메이 유명하다
にぎやか(な) 니기야카 활기차다, 번화하다
しずか(な) 시즈카 조용하다
べんり(な) 벤리 편리하다
ふべん(な) 후벤 불편하다
たいせつ(な) 타이세츠 소중하다
だいじょうぶ(な) 다이죠우부 괜찮다
いやだ(な) 이야다 싫다
すてき(な) 스테키 멋지다
まじめ(な) 마지메 성실하다
げんき(な) 겐키 건강하다, 활기차다
ひま(な) 히마 한가하다
たいへん(な) 타이헨 힘들다, 대변이다
かんたん(な) 칸탄 간단하다
ふくざつ(な) 후쿠자츠 복잡하다
とくべつ(な) 토쿠베츠 특별하다
あんぜん(な) 안젠 안전하다
だいすき(な) 다이스키 매우 좋아하다

⚠️ きれい는 い로 끝나지만 な형용사!
きれい 는 겉모습이 い형용사처럼 보이지만 な형용사입니다.
→ きれいくない ❌ → きれいじゃない ✅

6. な형용사 활용표 #

명사문(です / じゃありません)과 동일하게 활용합니다.

형태 만드는 법 しずか 예시
현재 긍정 ～です しずかです
현재 부정 ～じゃありません しずかじゃありません
과거 긍정 ～でした しずかでした
과거 부정 ～じゃありませんでした しずかじゃありませんでした

예문 #

plain
このまちは にぎやかです。
이 마을은 활기찹니다.

このまちは しずかじゃありません。
이 마을은 조용하지 않습니다.

むかしは このまちは しずかでした。
옛날에는 이 마을은 조용했습니다.

かれは まじめじゃありませんでした。
그는 성실하지 않았습니다.

7. な형용사의 명사 수식 (연체형) #

명사 앞에서 수식할 때는 な를 붙입니다.

plain
な형용사 + な + 명사

plain
きれいな はな
예쁜 꽃

しずかな まち
조용한 마을

ゆうめいな レストラン
유명한 레스토랑

べんりな アプリ
편리한 앱

しんせつな ひと
친절한 사람

⚠️ 명사 수식 시에만 な를 붙입니다!

plain
✅ しずかです (조용합니다) ← な 없음
✅ しずかな まち (조용한 마을) ← な 있음
❌ しずかです まち

8. な형용사의 부사적 활용 (~に) #

な형용사를 부사로 쓸 때는 に를 붙입니다.

plain
な형용사 + に

しずかに → 조용히
ていねいに → 정중하게, 꼼꼼하게
じょうずに → 능숙하게
げんきに → 활기차게

plain
しずかに してください。
조용히 해 주세요.

ていねいに かきました。
꼼꼼하게 썼습니다.

にほんごを じょうずに はなしたいです。
일본어를 능숙하게 말하고 싶습니다.

9. い형용사 vs な형용사 비교 총정리 #

항목 い형용사 な형용사
현재 긍정 たかいです しずかです
현재 부정 たかくないです しずかじゃありません
과거 긍정 たかかったです しずかでした
과거 부정 たかくなかったです しずかじゃありませんでした
명사 수식 たかい + 명사 しずかな + 명사
부사형 たかく しずかに

10. 주의가 필요한 형용사 #

① きらい vs すきじゃない #

plain
すしが きらいです。 (초밥이 싫습니다.) ← 강한 표현
すしが すきじゃありません。 (초밥을 좋아하지 않습니다.) ← 부드러운 표현

② じょうず vs とくい / へた vs にがて #

표현 의미 뉘앙스
じょうず 잘한다 객관적 평가
とくい 잘한다, 자신 있다 주관적·자신감
へた 못한다 객관적 평가
にがて 서투르다, 약하다 주관적·겸손 
plain
かれは えいごが じょうずです。
그는 영어를 잘합니다. (객관적)

わたしは えいごが とくいです。
나는 영어에 자신 있습니다. (주관적)

わたしは すうがくが にがてです。
나는 수학이 약합니다. (겸손한 표현)

③ はやい의 두 가지 의미 #

plain
はやい → 速い (속도가 빠르다) / 早い (시간이 이르다)

でんしゃが はやいです。 (전철이 빠릅니다.) ← 속도
おきるのが はやいです。 (일어나는 것이 이릅니다.) ← 시간

11. 형용사를 활용한 다양한 표현 #

① ~すぎます — 너무 ~하다 #

plain
い형용사: い → すぎます
な형용사: な 없이 + すぎます

このスープは あつすぎます。
이 수프는 너무 뜨겁습니다.

このもんだいは むずかしすぎます。
이 문제는 너무 어렵습니다.

このまちは にぎやかすぎます。
이 마을은 너무 시끄럽습니다.

② ~くなります / ~になります — ~해집니다 (변화) #

plain
い형용사: い → く + なります
な형용사: な 없이 + に + なります

さむくなりました。
추워졌습니다.

にほんごが じょうずになりました。
일본어가 능숙해졌습니다.

まちが にぎやかになりました。
마을이 활기차게 되었습니다.

③ ~くします / ~にします — ~하게 합니다 (만들다) #

plain
い형용사: い → く + します
な형용사: な 없이 + に + します

へやを きれいにします。
방을 깨끗이 합니다.

こえを おおきくしてください。
목소리를 크게 해 주세요.

12. 실전 회화 — 카페에서 #

plain
A: このケーキ、おいしそうですね。
   코노 케에키、오이시소우데스네。
   (이 케이크, 맛있어 보이네요.)

B: そうですね。でも、あのチョコケーキの ほうが おいしそうですよ。
   소우데스네。데모、아노 쵸코 케에키노 호우가 오이시소우데스요。
   (그렇네요. 그런데, 저 초코케이크가 더 맛있어 보여요.)

A: じゃあ、あれを ふたつ ください。
   쟈아、아레오 후타츠 쿠다사이。
   (그럼, 저것 두 개 주세요.)

[나중에]

A: どうでしたか。おいしかったですか。
   도우데시타카。오이시캇타데스카?
   (어떠셨나요? 맛있었나요?)

B: とても おいしかったです！でも、ちょっと あまかったですね。
   토테모 오이시캇타데스！데모、촛토 아마캇타데스네。
   (정말 맛있었어요! 그런데, 좀 달았네요.)

A: そうですね。つぎは もっと からいのを たべてみましょうか。
   소우데스네。츠기와 못토 카라이노오 타베테미마쇼우카。
   (그렇네요. 다음엔 더 매운 것을 먹어볼까요.)

13. 형용사 문형 정리 #

문형 의미 예문
い형용사 + です ~합니다 おいしいです
い → くないです ~하지 않습니다 おいしくないです
い → かったです ~했습니다 おいしかったです
い → くなかったです ~하지 않았습니다 おいしくなかったです
な형용사 + です ~합니다 しずかです
な + じゃありません ~하지 않습니다 しずかじゃありません
な + でした ~했습니다 しずかでした
い형용사 + すぎます 너무 ~합니다 たかすぎます
い → くなります ~해집니다 さむくなります
な + になります ~해집니다 きれいになります
い형용사 + 명사 ~ 명사 おいしい ケーキ
な + な + 명사 ~ 명사 しずかな まち

마무리 #

형용사 활용의 핵심은 딱 두 가지입니다.

  • い형용사: 어미 い 를 직접 변형 (く·かった·くなかった)
  • な형용사: です·じゃありません·でした 와 동일하게 활용, 명사 수식 시만 な 추가

특히 いい → よい 불규칙, きれい는 な형용사 두 가지는 반드시 주의해야 합니다.

다음 강에서는 존재 표현(います·あります) 과 위치를 나타내는 표현을 배웁니다.

  • 1강: 히라가나 · 가타카나 완전 정복
  • 2강: 발음 규칙 — 탁음 · 반탁음 · 요음 · 촉음 · 장음
  • 3강: 자기소개 — ～は～です · じゃありません · ですか
  • 4강: 지시대명사 — これ · それ · あれ · どれ
  • 5강: 숫자와 시간 표현 — ～時 · ～分 · ～円
  • 6강: 동사 기초 — ます형 · 이동 표현 (～へ行きます)
  • 7강: 조사 — を · で · と · に · へ · が
  • 8강: 수수 표현 — あげます · もらいます · くれます
  • 9강: 형용사 — い형용사 · な형용사 활용 ← 현재 글
  • 10강: 존재 표현 — います · あります · 위치 표현

[초급 후반 — N4 레벨]

  • 11강: て형 만들기 — 동사 그룹별 활용

  • 13강: ~てください · ~てもいいです · ~てはいけません
  • 14강: 가능 표현 — 동사 가능형 · ～ことができます
  • 15강: 경험 표현 — ～たことがあります
  • 16강: 조건 표현 — ～たら · ～ば · ～と · ～なら
  • 17강: 수수 표현 심화 — ～てあげる · もらう · くれる
  • 18강: 경어 표현 — 존경어 · 겸양어 · 정중어 완전 정리
