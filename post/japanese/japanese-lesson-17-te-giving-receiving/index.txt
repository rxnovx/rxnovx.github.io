<p>8강에서 <code>あげます·もらいます·くれます</code>로 물건을 주고받는 표현을 익혔습니다.<br>
이번 강에서는 그것을 <strong>て형과 결합</strong>하여 <strong>“행위를 주고받는”</strong> 은혜 표현으로 확장합니다.</p>
<p>“친구가 도와줬어요”, “선생님께 가르쳐 받았어요”, “내가 대신 해줬어요” —<br>
이런 표현들이 모두 이번 강의 내용입니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>～てあげる·～てもらう·～てくれる의 차이를 완벽히 구분할 수 있습니다.</li>
<li>각 표현의 겸양·존경 변형(てさしあげる·ていただく·てくださる)을 상황에 맞게 쓸 수 있습니다.</li>
<li>부탁·감사·불만 등 다양한 감정을 수수 표현으로 자연스럽게 표현할 수 있습니다.</li>
<li>8강 내용과 연결해 수수 표현 전체 체계를 완성할 수 있습니다.</li>
</ul>
</blockquote>

【올바른 표현】

<h2 id="3---내가-상대에게-부탁해-해-받는다" tabindex="-1" data-src-line="79">3. ～てもらう — 내가 (상대에게 부탁해) 해 받는다 <a class="header-anchor" href="#3---내가-상대에게-부탁해-해-받는다" aria-hidden="true">#</a></h2>
<h3 id="기본-구조-1" tabindex="-1" data-src-line="81">기본 구조 <a class="header-anchor" href="#기본-구조-1" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">동사 て형 + もらう / もらいます
(~해 받습니다 / ~해 받았습니다)
</code></pre></div></code></pre>
<p><strong>방향</strong>: 나 ← 타인 (내가 받는 쪽)<br>
<strong>뉘앙스</strong>: 내가 부탁하거나 요청하여 상대가 해준 행위에 초점</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">わたしは ともだちに にほんごを おしえてもらいました。
나는 친구에게 일본어를 가르쳐 받았습니다.
(= 친구가 일본어를 가르쳐 주었습니다 — 내가 주어)

かれに みちを おしえてもらいました。
그에게 길을 가르쳐 받았습니다.

いしゃに くすりを だしてもらいました。
의사에게 약을 처방받았습니다.

ともだちに しゃしんを とってもらいました。
친구에게 사진을 찍어 받았습니다.
</code></pre></div></code></pre>
<h3 id="의-핵심-뉘앙스" tabindex="-1" data-src-line="106">てもらう의 핵심 뉘앙스 <a class="header-anchor" href="#의-핵심-뉘앙스" aria-hidden="true">#</a></h3>
<p><code>てもらう</code>는 단순히 상대가 해줬다는 것이 아니라, <strong>“내가 요청/부탁해서 해줬다”</strong> 는 뉘앙스가 담겨 있습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">【てもらう — 부탁해서 해줬다】
しゃしんを とってもらいました。
(부탁해서) 사진을 찍어 받았습니다.

【てくれる — 자발적으로 해줬다】
しゃしんを とってくれました。
(상대가 알아서) 사진을 찍어 주었습니다.
</code></pre></div></code></pre>
<h3 id="----정중한-부탁" tabindex="-1" data-src-line="120">てもらいたい / てもらえますか — 정중한 부탁 <a class="header-anchor" href="#----정중한-부탁" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">ちょっと てつだってもらいたいんですが。
좀 도와주셨으면 하는데요.

もう いちど せつめいしてもらえますか。
다시 한번 설명해 주실 수 있겠습니까?

これを みてもらえないでしょうか。
이것을 봐 주실 수 없겠습니까?
</code></pre></div></code></pre>
<blockquote>
<p>💡 <strong>てもらえますか vs てくださいますか</strong><br>
둘 다 정중한 부탁이지만:</p>
<ul>
<li><code>てもらえますか</code> → “~해 받을 수 있겠습니까?” (받는 나가 주어)</li>
<li><code>てくださいますか</code> → “~해 주시겠습니까?” (주는 상대가 주어)<br>
뉘앙스는 비슷하며 둘 다 자연스럽습니다.</li>
</ul>
</blockquote>

<h2 id="5------완전-비교" tabindex="-1" data-src-line="185">5. てあげる · てもらう · てくれる 완전 비교 <a class="header-anchor" href="#5------완전-비교" aria-hidden="true">#</a></h2>
<p>같은 상황을 세 가지 시점으로 표현합니다.</p>
<p><strong>상황: 친구가 내 짐을 들어줬다.</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① てあげる (주는 쪽 = 친구, 받는 쪽 = 나):
  ともだちは わたしに にもつを もってあげました。
  친구는 나에게 짐을 들어주었습니다.
  → 어색! 친구→나 상황에 あげる를 쓰면 친구 시점이 되어 부자연스러움

② てもらう (받는 쪽 = 나가 주어):
  わたしは ともだちに にもつを もってもらいました。
  나는 친구에게 (부탁해서) 짐을 들어 받았습니다. ✅

③ てくれる (주는 쪽 = 친구가 주어):
  ともだちが わたしの にもつを もってくれました。
  친구가 내 짐을 들어주었습니다. ✅
</code></pre></div></code></pre>
<blockquote>
<p>💡 <strong>실용 포인트</strong></p>
<ul>
<li>내가 주어일 때: <strong>てもらいました</strong></li>
<li>친구가 주어일 때: <strong>てくれました</strong></li>
<li>친구→나 상황에 <strong>てあげました</strong> 는 어색합니다</li>
</ul>
</blockquote>

<h2 id="마무리" tabindex="-1" data-src-line="393">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>수수 표현은 일본어 학습자에게 가장 어려운 문법 중 하나지만,<br>
<strong>“누가 누구를 위해 하느냐”</strong> 라는 하나의 원칙만 지키면 됩니다.</p>
<ul>
<li><strong>てあげる</strong>: 내가 → 상대를 위해 (단, 윗사람에게는 てさしあげる)</li>
<li><strong>てもらう</strong>: 내가 ← 부탁해서 해 받음 (단, 윗사람에게는 ていただく)</li>
<li><strong>てくれる</strong>: 상대가 → 나를 위해 자발적으로 (단, 윗사람은 てくださる)</li>
</ul>
<p>특히 <code>てもらう</code>와 <code>てくれる</code>의 뉘앙스 차이 — <strong>부탁해서 vs 자발적으로</strong> — 를 구분하는 것이 자연스러운 일본어의 핵심입니다.</p>
<p>드디어 다음 강이 <strong>마지막 18강 — 경어 표현</strong>입니다!<br>
존경어·겸양어·정중어를 완전히 정리하며 시리즈를 마무리합니다.</p>
