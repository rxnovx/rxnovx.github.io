들어가기 앞서 #

て형은 일본어 중급 문법의 시작이자 핵심입니다.
12강의 ~ている, 13강의 ~てください, 14강의 가능형, 17강의 수수 표현 심화까지 — 앞으로 배울 거의 모든 문법이 て형을 기반으로 합니다.

て형을 완전히 익히는 것은 일본어 실력의 분기점이라고 해도 과언이 아닙니다.

이 글을 읽고 나면:

  • 1·2·3그룹 동사의 て형을 모두 만들 수 있습니다.
  • 1그룹 동사의 어미별 て형 변환 규칙을 외울 수 있습니다.
  • て형을 이용한 기초 표현(~てから·~てください·~ても)을 익힐 수 있습니다.
  • 자주 쓰이는 동사 30개의 て형을 즉시 떠올릴 수 있습니다.

1. て형이란? #

て형은 동사의 어미를 て(또는 で) 로 바꾼 형태입니다.
그 자체로는 문장이 끝나지 않으며, 뒤에 다른 표현이 붙어 다양한 의미를 만듭니다.

plain
たべる → たべ【て】
いく  → い【って】
のむ  → の【んで】

て형이 쓰이는 대표적인 패턴:

패턴 의미
～てください ~해 주세요
～ている ~하고 있습니다
～てから ~하고 나서
～てもいいです ~해도 됩니다
～てはいけません ~해서는 안 됩니다
～てあげます ~해 줍니다
～てみます ~해 봅니다

2. 2그룹 동사의 て형 — 가장 간단 #

2그룹 동사는 규칙이 가장 단순합니다.

plain
2그룹: 어미 る를 제거 + て
사전형 て형
たべる たべて
みる みて
おきる おきて
ねる ねて
おしえる おしえて
でる でて
きる(着る) きて
しめる しめて
おぼえる おぼえて
はじめる はじめて

3. 3그룹 동사의 て형 — 불규칙 암기 #

3그룹은 딱 두 개입니다. 통째로 외웁니다.

plain
する → して
くる → きて
사전형 て형 예
する して べんきょうする → べんきょうして
くる きて くる → きて

4. 1그룹 동사의 て형 — 어미별 규칙 #

1그룹은 어미에 따라 변환 방식이 다릅니다. 총 4가지 패턴으로 나뉩니다.

패턴 ① : く → いて / ぐ → いで #

사전형 て형 의미
かく かいて 쓰다
きく きいて 듣다
はたらく はたらいて 일하다
およぐ およいで 수영하다
いそぐ いそいで 서두르다

⚠️ いく(가다)는 예외!
いく는 く로 끝나지만 て형이 いいて가 아니라 いって 입니다.
이 예외는 반드시 따로 암기해야 합니다.

패턴 ② : す → して #

사전형 て형 의미
はなす はなして 말하다
かえす かえして 돌려주다
だす だして 내다
けす けして 끄다

패턴 ③ : つ·る·う → って #

사전형 て형 의미
まつ まって 기다리다
かえる かえって 돌아가다
わかる わかって 알다
とる とって 찍다, 잡다
かう かって 사다
つかう つかって 사용하다
あう あって 만나다
いう いって — ※ いく와 혼동 주의 말하다

패턴 ④ : ぬ·ぶ·む → んで #

사전형 て형 의미
しぬ しんで 죽다
あそぶ あそんで 놀다
よぶ よんで 부르다
のむ のんで 마시다
よむ よんで 읽다
やすむ やすんで 쉬다
たのむ たのんで 부탁하다

5. 1그룹 て형 규칙 총정리표 #

외우기 쉽도록 한 표로 정리합니다.

어미 て형 변환 예시
く → いて かく → かいて
ぐ → いで およぐ → およいで
す → して はなす → はなして
つ → って まつ → まって
る → って かえる → かえって
う → って かう → かって
ぬ → んで しぬ → しんで
ぶ → んで あそぶ → あそんで
む → んで のむ → のんで
いく → いって いく → いって (예외!)

💡 암기 팁 — 음율로 외우기
「く→いて、ぐ→いで、す→して、つるう→って、ぬぶむ→んで」
리듬감 있게 반복해서 읽으면 자연스럽게 외워집니다.

7. て형 기초 표현 #

て형을 이용한 핵심 표현들을 미리 익혀둡니다.
각 표현은 이후 강에서 더 자세히 다루지만, 지금부터 패턴으로 익혀두면 좋습니다.

① ～てください — ~해 주세요 #

plain
ちょっと まってください。
잠깐 기다려 주세요.

ここに なまえを かいてください。
여기에 이름을 써 주세요.

もう いちど いってください。
다시 한번 말씀해 주세요.

② ～てから — ~하고 나서 #

plain
しゅくだいを してから、あそびます。
숙제를 하고 나서, 놉니다.

ごはんを たべてから、はをみがきます。
밥을 먹고 나서, 이를 닦습니다.

にほんへ いってから、にほんごが うまくなりました。
일본에 가고 나서, 일본어가 능숙해졌습니다.

③ ～てもいいです — ~해도 됩니다 #

plain
ここで しゃしんを とってもいいですか。
여기서 사진을 찍어도 됩니까?

もう かえってもいいですよ。
이제 돌아가도 됩니다.

このペンを つかってもいいですか。
이 펜을 사용해도 됩니까?

④ ～てはいけません — ~해서는 안 됩니다 #

plain
ここで たばこを すってはいけません。
여기서 담배를 피워서는 안 됩니다.

じゅぎょうちゅうに スマホを みてはいけません。
수업 중에 스마트폰을 봐서는 안 됩니다.

⑤ ～てみます — ~해 봅니다 #

plain
このりょうりを たべてみます。
이 요리를 먹어 봅니다.

にほんごで はなしてみてください。
일본어로 말해 보세요.

いちど やってみましょう。
한번 해 봅시다.

⑥ ～ています — ~하고 있습니다 (진행) #

plain
いま でんわして います。
지금 전화하고 있습니다.

ともだちを まっています。
친구를 기다리고 있습니다.

💡 ~ています는 12강에서 더 자세히 다룹니다.

8. て형을 이용한 동작 연결 #

て형은 동작을 시간 순서대로 연결할 때도 씁니다.

plain
[동작1]て、[동작2]て、[동작3]ます

plain
あさ、おきて、かおを あらって、ごはんを たべます。
아침에, 일어나서, 세수하고, 밥을 먹습니다.

えきに ついて、きっぷを かって、でんしゃに のります。
역에 도착해서, 표를 사서, 전철을 탑니다.

かいしゃに いって、しごとを して、うちに かえります。
회사에 가서, 일을 하고, 집에 돌아옵니다.

⚠️ て형 연결의 주의점
て형으로 동작을 연결할 때, 주어는 모두 동일해야 합니다.
주어가 다른 동작을 연결할 때는 て형 대신 ~て、~て 구조가 어색해지므로 별도 문장으로 씁니다.

9. た형 — て형과 함께 익히는 과거형 #

て형을 알면 た형(과거형) 도 자동으로 만들 수 있습니다.
규칙이 완전히 동일하며, て를 た로 바꾸기만 하면 됩니다.

て형 た형 의미
たべて たべた 먹었다
のんで のんだ 마셨다
いって いった 갔다
して した 했다
きて きた 왔다
かいて かいた 썼다
まって まった 기다렸다 
plain
きのう ともだちと えいがを みた。
어제 친구와 영화를 봤어.

あさ はやく おきた。
아침 일찍 일어났어.

💡 た형에 です를 붙이면 정중한 과거형 ~ました와 같은 의미입니다.
たべた = たべました (た형이 반말, ました가 정중체)

10. 실전 회화 — 아침 일과 #

plain
A: まいあさ なにを していますか。
   마이아사 나니오 시테이마스카?
   (매일 아침 무엇을 하십니까?)

B: ろくじに おきて、シャワーを あびて、
   로쿠지니 오키테、샤와아오 아비테、
   (6시에 일어나서, 샤워를 하고,)
   
   ごはんを たべてから、かいしゃに いきます。
   고한오 타베테카라、카이샤니 이키마스。
   (밥을 먹고 나서, 회사에 갑니다.)

A: かいしゃには なにで いきますか。
   카이샤니와 나니데 이키마스카?
   (회사에는 무엇으로 가십니까?)

B: でんしゃに のって、バスに のりかえて いきます。
   덴샤니 놋테、바스니 노리카에테 이키마스。
   (전철을 타고, 버스로 갈아타서 갑니다.)

A: じかんは どのくらい かかりますか。
   지칸와 도노쿠라이 카카리마스카?
   (시간은 얼마나 걸립니까?)

B: だいたい いちじかんぐらい かかります。
   다이타이 이치지칸구라이 카카리마스。
   (대략 1시간 정도 걸립니다.)

A: たいへんですね。かいしゃに ついてから、まず なにを しますか。
   타이헨데스네。카이샤니 츠이테카라、마즈 나니오 시마스카?
   (힘드시겠네요. 회사에 도착하고 나서, 먼저 무엇을 하십니까?)

B: コーヒーを のんでから、メールを チェックします。
   코히이오 논데카라、메에루오 체크시마스。
   (커피를 마시고 나서, 이메일을 체크합니다.)

11. 문형 정리 #

문형 의미 예문
て형 + ください ~해 주세요 まってください
て형 + から ~하고 나서 たべてから いきます
て형 + もいいです ~해도 됩니다 とってもいいですか
て형 + はいけません ~해서는 안 됩니다 みてはいけません
て형 + みます ~해 봅니다 たべてみます
て형 + います ~하고 있습니다 まっています
て형 + て + 동사 ~하고 ~합니다 (연결) おきて、たべて、いきます
て형 → た형 ~했습니다 (반말 과거) たべた·のんだ

マとめ #

て형 변환 규칙을 다시 한번 정리합니다.

plain
2그룹: る → て
3그룹: する → して / くる → きて
1그룹:
  く → いて (※いく → いって 예외)
  ぐ → いで
  す → して
  つ·る·う → って
  ぬ·ぶ·む → んで

て형은 처음에는 복잡해 보이지만, 패턴을 리듬으로 외우고 동사 30개의 て형을 반복 연습하면 자연스럽게 몸에 익습니다. て형이 손에 익으면 이후 모든 활용이 훨씬 수월해집니다.

다음 강에서는 て형의 첫 번째 응용인 ~ている(진행·상태 표현) 을 완전히 익힙니다.
