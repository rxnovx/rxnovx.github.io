<p>“일본에 가 본 적 있어요?”, “스시를 먹어 본 적 있습니까?” —<br>
경험을 묻고 답하는 표현은 여행·자기소개·일상 대화 어디서든 자주 등장합니다.<br>
이번 강에서는 <strong>과거의 경험을 나타내는 핵심 표현 <code>～たことがあります</code></strong> 를 중심으로, 관련 응용 표현까지 완전히 익혀봅니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>た형(과거형)을 동사 그룹별로 만들 수 있습니다.</li>
<li>～たことがあります로 경험을 표현할 수 있습니다.</li>
<li>경험 유무를 자연스럽게 묻고 답할 수 있습니다.</li>
<li>～たことがない·～たばかり·～たあとで 등 응용 표현을 익힐 수 있습니다.</li>
</ul>

<h2 id="6-응용-표현----막-했습니다" tabindex="-1" data-src-line="187">6. 응용 표현 ① — ～たばかりです (막 ~했습니다) <a class="header-anchor" href="#6-응용-표현----막-했습니다" aria-hidden="true">#</a></h2>
<p>た형 + <code>ばかり</code>는 <strong>방금 막 ~했다</strong>는 표현입니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">동사 た형 + ばかりです
(막 ~했습니다 / 방금 ~했습니다)
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">にほんに きたばかりです。
막 일본에 왔습니다. (온 지 얼마 안 됐습니다.)

しごとを はじめたばかりです。
막 일을 시작했습니다.

ごはんを たべたばかりなので、おなかが いっぱいです。
방금 밥을 먹었기 때문에, 배가 부릅니다.

この アプリを ダウンロードしたばかりで、つかいかたが わかりません。
이 앱을 방금 다운로드해서, 사용법을 모릅니다.
</code></pre></div></code></pre>
<blockquote>
<p>⚠️ <strong>たことがある vs たばかり 비교</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">にほんに いったことがあります。

にほんに いったばかりです。
→ 방금 막 일본에 갔다 온 상태 (아주 최근)
</code></pre></div></code></pre>
</blockquote>

<h2 id="7-응용-표현----한-후에" tabindex="-1" data-src-line="221">7. 응용 표현 ② — ～たあとで (~한 후에) <a class="header-anchor" href="#7-응용-표현----한-후에" aria-hidden="true">#</a></h2>
<p>た형 + <code>あとで</code>는 <strong>~하고 난 후에</strong>라는 순서 표현입니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">동사 た형 + あとで
(~한 후에 / ~하고 나서)
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">しゅくだいを したあとで、あそびます。
숙제를 한 후에, 놉니다.

ごはんを たべたあとで、さんぽします。
밥을 먹은 후에, 산책합니다.

かいぎが おわったあとで、れんらくします。
회의가 끝난 후에, 연락하겠습니다.

にほんに いったあとで、かんがえます。
일본에 간 후에, 생각해 보겠습니다.
</code></pre></div></code></pre>
<blockquote>
<p>💡 <strong>てから vs たあとで</strong><br>
두 표현 모두 &quot;~하고 나서&quot;이지만 뉘앙스 차이가 있습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">～てから: 앞 동작이 끝난 직후 바로 다음 동작 (연속성 강조)
～たあとで: 앞 동작 이후 어느 시점에 다음 동작 (시간적 여유 있음)

ごはんを たべてから、すぐ でかけます。
밥을 먹고 나서, 바로 외출합니다. (연속)

ごはんを たべたあとで、すこし やすみます。
밥을 먹은 후에, 조금 쉽니다. (여유)
</code></pre></div></code></pre>
</blockquote>

<h2 id="8-응용-표현----예시-나열" tabindex="-1" data-src-line="259">8. 응용 표현 ③ — ～たり～たりします (예시 나열) <a class="header-anchor" href="#8-응용-표현----예시-나열" aria-hidden="true">#</a></h2>
<p>た형 + <code>り</code>를 반복하면 <strong>여러 동작을 예시로 나열</strong>하는 표현이 됩니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">동사 た형 + り、동사 た형 + り します
(~하거나 ~하거나 합니다)
</code></pre></div></code></pre>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">しゅうまつは えいがを みたり、ほんを よんだり します。

그녀는 노래하거나, 춤추거나 하는 것을 좋아합니다.

にほんごの べんきょうは たんごを おぼえたり、
かいわを れんしゅうしたり しています。
일본어 공부는 단어를 외우거나, 회화를 연습하거나 하고 있습니다.
</code></pre></div></code></pre>
<blockquote>
<p>💡 <strong>と vs たり</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">と: 완전 나열 (딱 그것만)

(일요일에는 영화를 보거나, 친구와 놀거나 합니다. — 예시)
</code></pre></div></code></pre>
</blockquote>

<h2 id="마무리" tabindex="-1" data-src-line="407">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p><code>～たことがあります</code>는 단순해 보이지만, た형에서 파생되는 다양한 표현들과 함께 익히면 표현력이 크게 넓어집니다.</p>
<p>특히:</p>
<ul>
<li><strong>たことがある</strong> — 경험 유무</li>
<li><strong>たばかり</strong> — 방금 막 한 행동</li>
<li><strong>たあとで</strong> — 순서·전후 관계</li>
<li><strong>たり～たり</strong> — 예시 나열</li>
<li><strong>たほうがいい</strong> — 조언</li>
</ul>
<p>이 다섯 패턴은 일상 회화에서 매우 자주 등장하므로 반복 연습해두면 큰 자산이 됩니다.</p>
<p>다음 강에서는 일본어에서 가장 많은 학습자가 어려워하는 <strong>조건 표현</strong> — <code>～たら·～ば·～と·～なら</code> 네 가지를 한꺼번에 정복합니다.</p>
<hr>
<blockquote>
<p>📚 <strong>시리즈 목차</strong></p>

<ul>
<li>1강 ~ 10강 완료</li>
</ul>
<p><strong>[초급 후반 — N4 레벨]</strong></p>
<ul>
<li>11강: て형 만들기 — 동사 그룹별 활용</li>
<li>12강: ~ている — 진행 · 상태 · 습관 표현</li>
<li>13강: ~てください · ~てもいいです · ~てはいけません</li>
<li>14강: 가능 표현 — 동사 가능형 · ～ことができます</li>
<li><strong>15강</strong>: 경험 표현 — ～たことがあります ← 현재 글</li>
