들어가기 앞서 #

“이것 좀 해주실 수 있어요?”, “여기서 사진 찍어도 되나요?”, “여기서는 음식을 드시면 안 됩니다.”
이 세 가지 상황은 일상에서 매일 마주치는 표현입니다.
이번 강에서는 て형을 이용한 의뢰·허가·금지 표현을 정중도별로 완전히 정리합니다.

이 글을 읽고 나면:

  • ~てください로 부탁 표현을 만들 수 있습니다.
  • ~てもいいです/~てもいいですか로 허가·허락 표현을 쓸 수 있습니다.
  • ~てはいけません으로 금지 표현을 만들 수 있습니다.
  • 각 표현의 정중도별 변형을 상황에 맞게 사용할 수 있습니다.
  • なくてもいいです·なくてはいけません 등 부정형 응용도 익힐 수 있습니다.

1. ~てください — 의뢰·지시 표현 #

기본 구조 #

plain
동사 て형 + ください
(~해 주세요 / ~하세요)

ください는 원래 くれる(주다)의 명령형으로, 상대에게 동작을 해 달라고 부탁하는 표현입니다.

기본 예문 #

plain
ちょっと まってください。
잠깐 기다려 주세요.

ここに なまえを かいてください。
여기에 이름을 써 주세요.

もう いちど いってください。
다시 한번 말씀해 주세요.

この くすりを のんでください。
이 약을 드세요.

しずかに してください。
조용히 해 주세요.

まどを しめてください。
창문을 닫아 주세요.

2. ~てください의 정중도별 변형 #

상황에 따라 정중도를 조절해야 합니다.

정중도 표현 예문
반말 (친구) て형 단독 ちょっと まって
기본 정중 ~てください まってください
더 정중 ~ていただけますか まっていただけますか
가장 정중 ~ていただけないでしょうか まっていただけないでしょうか

예문 비교 #

plain
【반말 — 친한 친구】
ちょっと まって。
잠깐 기다려.

【기본 정중 — 일반적 상황】
ちょっと まってください。
잠깐 기다려 주세요.

【정중 — 윗사람·처음 만난 사람】
ちょっと まっていただけますか。
잠깐 기다려 주시겠습니까?

【매우 정중 — 공식 석상·비즈니스】
おそれいりますが、しょうしょう おまちいただけないでしょうか。
죄송합니다만, 잠시 기다려 주실 수 없겠습니까?

3. ~ないでください — 부정 의뢰 #

"~하지 말아 주세요"는 て형이 아닌 ない형을 사용합니다.

plain
동사 ない형 + でください
(~하지 말아 주세요)

ない형 만들기 (간단 복습) #

그룹 규칙 예시
1그룹 う단 → あ단 + ない かく → かかない / のむ → のまない
2그룹 る 제거 + ない たべる → たべない
3그룹 암기 する → しない / くる → こない

예문 #

plain
ここで たばこを すわないでください。
여기서 담배를 피우지 말아 주세요.

しゃしんを とらないでください。
사진을 찍지 말아 주세요.

おくれないでください。
늦지 말아 주세요.

このことを だれにも いわないでください。
이 일을 아무에게도 말하지 말아 주세요.

むりしないでください。
무리하지 마세요. (걱정할 때 자주 쓰는 표현)

4. ~てもいいです — 허가 표현 #

기본 구조 #

plain
동사 て형 + もいいです
(~해도 됩니다 / ~해도 괜찮습니다)

허가 표현 — 허락해 줄 때 #

plain
ここで しゃしんを とってもいいですよ。
여기서 사진을 찍어도 됩니다.

もう かえってもいいですよ。
이제 돌아가도 됩니다.

このペンを つかってもいいですよ。
이 펜을 사용해도 됩니다.

すきなものを えらんでもいいですよ。
좋아하는 것을 골라도 됩니다.

허락 요청 — 물어볼 때 #

허가를 요청할 때는 ~てもいいですか 로 물어봅니다.

plain
ここに すわってもいいですか。
여기 앉아도 됩니까?

ちょっと みてもいいですか。
잠깐 봐도 됩니까?

トイレに いってもいいですか。
화장실에 가도 됩니까?

この りんごを たべてもいいですか。
이 사과를 먹어도 됩니까?

허가 요청에 대한 대답 #

plain
【허락할 때】
はい、どうぞ。
네, 물론이죠.

ええ、いいですよ。
네, 좋아요.

もちろんです。
물론입니다.

【거절할 때】
すみません、ちょっと…。
죄송합니다만, 좀…. (완곡한 거절)

いいえ、ここでは ちょっと…。
아니요, 여기서는 좀….

5. ~てもいいです의 정중도별 변형 #

정중도 표현 예문
반말 ~ていい？ いってもいい？
기본 정중 ~てもいいですか いってもいいですか
정중 ~てもよろしいですか いってもよろしいですか
매우 정중 ~てもよろしいでしょうか いってもよろしいでしょうか 
plain
【반말】
これ、たべていい？
이거 먹어도 돼?

【기본 정중】
これを たべてもいいですか。
이것을 먹어도 됩니까?

【정중 — 윗사람에게】
こちらを たべてもよろしいですか。
이것을 먹어도 괜찮겠습니까?

【매우 정중 — 비즈니스】
しょうひんを はいけんしてもよろしいでしょうか。
상품을 봐도 괜찮겠습니까?

6. ~なくてもいいです — 면제 표현 #

"~하지 않아도 됩니다"는 しなくてもいいです 패턴입니다.
불필요한 행동이나 의무를 면제해 줄 때 씁니다.

plain
동사 ない형 + くてもいいです
(~하지 않아도 됩니다)

plain
むりして こなくてもいいですよ。
무리해서 오지 않아도 됩니다.

きょうは スーツを きなくてもいいです。
오늘은 정장을 입지 않아도 됩니다.

ぜんぶ たべなくてもいいですよ。
다 먹지 않아도 됩니다.

むずかしければ、やらなくてもいいです。
어려우면, 하지 않아도 됩니다.

しゅくだいは あしたまでに ださなくてもいいです。
숙제는 내일까지 내지 않아도 됩니다.

7. ~てはいけません — 금지 표현 #

기본 구조 #

plain
동사 て형 + はいけません
(~해서는 안 됩니다 / ~하면 안 됩니다)

예문 #

plain
ここで たばこを すってはいけません。
여기서 담배를 피워서는 안 됩니다.

じゅぎょうちゅうに スマホを みてはいけません。
수업 중에 스마트폰을 봐서는 안 됩니다.

うそを ついてはいけません。
거짓말을 해서는 안 됩니다.

きけんなので、はいってはいけません。
위험하므로, 들어가서는 안 됩니다.

ひとの ものを かってに つかってはいけません。
남의 물건을 마음대로 사용해서는 안 됩니다.

8. ~てはいけません의 정중도별 변형 #

정중도 표현 예문
반말 ~てはだめ / ~ちゃだめ いってはだめ / いっちゃだめ
기본 정중 ~てはいけません いってはいけません
정중 ~てはなりません いってはなりません
문어·규정 ~てはならない いってはならない 
plain
【반말 — 친한 친구·아이에게】
そこに はいっちゃだめだよ!
거기 들어가면 안 돼!

【기본 정중】
ここで たばこを すってはいけません。
여기서 담배를 피워서는 안 됩니다.

【격식·공적 문서】
きないじに さんにゅうしてはなりません。
허가 없이 침입해서는 안 됩니다.

9. ~なくてはいけません — 의무 표현 #

“~하지 않으면 안 됩니다” = “반드시 ~해야 합니다”

plain
동사 ない형 + くてはいけません
(~하지 않으면 안 됩니다 / ~해야만 합니다)

축약형 #

회화에서는 길어서 다음과 같이 줄여 씁니다.

형태 표현
정식 ~なくてはいけません
축약 ① ~なくてはいけない
축약 ② ~なくちゃいけない
축약 ③ ~なくちゃ (가장 구어체) 
plain
もっと べんきょうしなくてはいけません。
더 공부하지 않으면 안 됩니다. (더 공부해야 합니다.)

はやく いかなくちゃ。
빨리 가야 해. (구어체)

くすりを のまなくちゃいけない。
약을 먹어야 해.

あしたまでに レポートを ださなくてはいけません。
내일까지 리포트를 내지 않으면 안 됩니다.

10. 의무·필요 표현 비교 #

일본어에는 "~해야 한다"는 의미의 표현이 여러 가지 있습니다.

표현 의미 뉘앙스
~なくてはいけません ~해야 합니다 가장 일반적
~なければなりません ~해야 합니다 더 격식체·문어체
~なくてはなりません ~해야 합니다 격식체
~ないといけません ~해야 합니다 회화체
~なくちゃ ~해야 해 반말·구어체 
plain
【같은 의미, 다른 정중도】

はやく ねなくちゃ。(반말)
빨리 자야 해.

はやく ねないといけません。(회화체 정중)
빨리 자야 합니다.

はやく ねなくてはいけません。(일반 정중)
빨리 자지 않으면 안 됩니다.

はやく ねなければなりません。(격식체)
빨리 자지 않으면 안 됩니다.

11. 표현 전체 비교 정리 #

표현 의미 예문
~てください ~해 주세요 (의뢰) まってください
~ないでください ~하지 말아 주세요 はいらないでください
~てもいいです ~해도 됩니다 (허가) とってもいいです
~てもいいですか ~해도 됩니까? (허가 요청) すわってもいいですか
~なくてもいいです ~하지 않아도 됩니다 (면제) こなくてもいいです
~てはいけません ~해서는 안 됩니다 (금지) すってはいけません
~なくてはいけません ~해야 합니다 (의무) いかなくてはいけません

12. 실전 회화 — 병원 접수 상황 #

plain
【접수 창구에서】

かんごし：こちらの よういしょに なまえと れんらくさきを
         かいてください。
         코치라노 요우이쇼니 나마에토 렌라쿠사키오
         카이테쿠다사이。
         (이 서류에 이름과 연락처를 적어 주세요.)

かんじゃ：ここに かいてもいいですか。
         코코니 카이테모 이이데스카?
         (여기에 써도 됩니까?)

かんごし：はい、そちらで だいじょうぶです。
         하이、소치라데 다이죠우부데스。
         (네, 거기서 괜찮습니다.)

かんじゃ：けいたいでんわを つかってもいいですか。
         케이타이덴와오 츠카테모 이이데스카?
         (휴대폰을 사용해도 됩니까?)

かんごし：まちあいしつでは、おしゃべりや けいたいでんわの
         ご使用は おひかえください。
         마치아이시쯔데와、오샤베리야 케이타이덴와노
         고시요우와 오히카에쿠다사이。
         (대기실에서는 잡담이나 휴대폰 사용은 삼가 주세요.)

かんじゃ：わかりました。あと どのくらい またなくては
         いけませんか。
         와카리마시타。아토 도노쿠라이 마타나쿠테와
         이케마셍카?
         (알겠습니다. 앞으로 얼마나 기다려야 합니까?)

かんごし：じゅうごふんほど おまちいただけますか。
         쥬우고훈호도 오마치이타다케마스카?
         (15분 정도 기다려 주시겠습니까?)

かんじゃ：はい、わかりました。
         하이、와카리마시타。
         (네, 알겠습니다.)

13. 문형 정리 #

문형 의미 정중도
て형 + ください ~해 주세요 ★★★
て형 + いただけますか ~해 주시겠습니까? ★★★★
ない형 + でください ~하지 말아 주세요 ★★★
て형 + もいいです ~해도 됩니다 ★★★
て형 + もよろしいですか ~해도 괜찮겠습니까? ★★★★
ない형 + くてもいいです ~하지 않아도 됩니다 ★★★
て형 + はいけません ~해서는 안 됩니다 ★★★
て형 + はなりません ~해서는 안 됩니다 ★★★★
ない형 + くてはいけません ~해야 합니다 ★★★
ない형 + くちゃ ~해야 해 ★ (반말)

마무리 #

의뢰·허가·금지·의무 표현은 일상에서 가장 자주 쓰이는 패턴 중 하나입니다.
특히 정중도에 따른 변형이 다양하므로, 상황에 맞게 골라 쓰는 연습이 중요합니다.

정리하면:

  • 부탁: ~てください → ~ていただけますか (더 정중)
  • 허가: ~てもいいです → ~てもよろしいですか (더 정중)
  • 금지: ~てはいけません → ~てはなりません (더 격식)
  • 의무: ~なくてはいけません → ~なければなりません (더 격식)
  • 면제: ~なくてもいいです

다음 강에서는 가능 표현 — 동사 가능형과 ～ことができます를 익힙니다.

📚 시리즈 목차

[초급 전반 — N5 레벨] ✅ 완료

  • 1강 ~ 10강 완료

[초급 후반 — N4 레벨]

  • 11강: て형 만들기 — 동사 그룹별 활용
  • 12강: ~ている — 진행 · 상태 · 습관 표현
  • 13강: ~てください · ~てもいいです · ~てはいけません ← 현재 글
