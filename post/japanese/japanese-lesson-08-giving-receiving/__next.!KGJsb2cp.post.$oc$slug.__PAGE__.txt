<p>수수 표현(授受表現)은 일본어 학습자가 <strong>가장 많이 혼동하는 문법</strong> 중 하나입니다.<br>
한국어에서는 “주다” 한 단어로 해결되는 상황이, 일본어에서는 <strong>누가 누구에게 주느냐에 따라</strong> 동사가 달라집니다.<br>
이 강에서는 핵심 개념인 <strong>“시점(視点)”</strong> 을 중심으로 세 동사의 차이를 완전히 정리합니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>あげます·もらいます·くれます의 차이를 명확히 구분할 수 있습니다.</li>
<li>각 동사에 사용하는 조사(に·から)를 정확히 쓸 수 있습니다.</li>
<li>나(화자)를 기준으로 수수 동사를 자연스럽게 선택할 수 있습니다.</li>
<li>수수 표현을 활용한 자연스러운 회화를 만들 수 있습니다.</li>
</ul>
</blockquote>
<hr>
<h2 id="1-수수-표현의-핵심-개념--시점" tabindex="-1" data-src-line="17">1. 수수 표현의 핵심 개념 — 시점(視点) <a class="header-anchor" href="#1-수수-표현의-핵심-개념--시점" aria-hidden="true">#</a></h2>
<p>일본어 수수 표현에서 가장 중요한 것은 <strong>“누구의 시점에서 바라보느냐”</strong> 입니다.</p>

<p>⚠️ <strong>핵심 포인트</strong></p>
<ul>
<li><code>あげます</code>와 <code>くれます</code>는 모두 &quot;주다&quot;이지만, <strong>누가 나에게 주느냐</strong>가 다릅니다.</li>
<li><code>くれます</code>는 <strong>반드시 나(또는 내 가족·내 편)에게</strong> 줄 때만 씁니다.</li>
<li><code>あげます</code>는 나→타인, 또는 타인→타인에게 줄 때 씁니다.</li>
</ul>
</blockquote>

(나는 선생님으로부터 조언을 받았습니다.)

たなかさんは かいしゃから ボーナスを もらいました。
타나카상와 카이샤카라 보나스오 모라이마시타。
(다나카 씨는 회사로부터 보너스를 받았습니다.)
</code></pre></div></code></pre>

<h2 id="4---주다-타인--나내-주변" tabindex="-1" data-src-line="102">4. くれます — 주다 (타인 → 나·내 주변) <a class="header-anchor" href="#4---주다-타인--나내-주변" aria-hidden="true">#</a></h2>
<h3 id="기본-구조-2" tabindex="-1" data-src-line="104">기본 구조 <a class="header-anchor" href="#기본-구조-2" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">[주는 사람] は [나/내 가족] に [물건] を くれます
</code></pre></div></code></pre>
<h3 id="예문-2" tabindex="-1" data-src-line="110">예문 <a class="header-anchor" href="#예문-2" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">ともだちは わたしに プレゼントを くれました。
토모다치와 와타시니 푸레젠토오 쿠레마시타。
(친구가 나에게 선물을 주었습니다.)

せんせいは わたしに ほんを くれました。
센세이와 와타시니 혼오 쿠레마시타。
(선생님이 나에게 책을 주셨습니다.)

하하와 와타시노 이모우토니 오카시오 쿠레마시타。
(어머니가 내 여동생에게 과자를 주셨습니다.) ← 내 가족에게도 くれます 사용 가능
</code></pre></div></code></pre>
<blockquote>
<p>⚠️ <strong>くれます는 타인→나(내 편)일 때만</strong><br>
타인→타인의 상황에는 くれます를 쓸 수 없습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">✅ ともだちが わたしに くれました (친구→나 ✓)

✅ たなかさんが すずきさんに あげました (타인→타인 ✓)
</code></pre></div></code></pre>
</blockquote>

<h2 id="5-세-동사-완전-비교" tabindex="-1" data-src-line="136">5. 세 동사 완전 비교 <a class="header-anchor" href="#5-세-동사-완전-비교" aria-hidden="true">#</a></h2>
<p>같은 상황을 세 가지 시점으로 표현해봅니다.</p>
<p><strong>상황: 친구가 나에게 책을 주었다.</strong></p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">① あげます 시점 (주는 쪽):
  ともだちは わたしに ほんを あげました。
  (친구는 나에게 책을 주었습니다.) ← 어색! 보통 くれます를 씀

② もらいます 시점 (받는 쪽 = 나):
  わたしは ともだちに/から ほんを もらいました。
  (나는 친구에게서 책을 받았습니다.) ✅ 자연스러움

③ くれます 시점 (받는 쪽 = 나, 주는 쪽 강조):
  ともだちは わたしに ほんを くれました。
  (친구가 나에게 책을 주었습니다.) ✅ 자연스러움
</code></pre></div></code></pre>
<blockquote>
<p>💡 <strong>실용 포인트</strong></p>
<ul>
<li>내가 받은 상황 → <code>もらいます</code> 또는 <code>くれます</code> 둘 다 자연스럽습니다.</li>
<li>주는 사람을 주어로 강조하고 싶을 때 → <code>くれます</code></li>
<li>받은 나를 주어로 표현하고 싶을 때 → <code>もらいます</code></li>
</ul>
</blockquote>

<h2 id="8-수수-동사--형--은혜-표현" tabindex="-1" data-src-line="218">8. 수수 동사 + て형 — 은혜 표현 <a class="header-anchor" href="#8-수수-동사--형--은혜-표현" aria-hidden="true">#</a></h2>
<p>수수 동사는 て형과 결합하면 <strong>“~해 줍니다/받습니다”</strong> 는 은혜 표현이 됩니다.<br>

<h3 id="--내가-해줍니다" tabindex="-1" data-src-line="223">～てあげます — 내가 해줍니다 <a class="header-anchor" href="#--내가-해줍니다" aria-hidden="true">#</a></h3>

<h2 id="마무리" tabindex="-1" data-src-line="332">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>수수 표현의 핵심은 <strong>“나를 기준으로 물건이 오는가, 가는가”</strong> 입니다.<br>
처음에는 어색하게 느껴지더라도, 실제 대화에서 여러 번 사용하다 보면 자연스럽게 몸에 배게 됩니다.</p>
<p>특히 <code>くれます</code>와 <code>あげます</code>의 혼동은 일본인이 들었을 때 어색함을 느끼는 대표적인 실수이므로, 이번 강의 내용을 충분히 반복 연습하는 것을 권장합니다.</p>
<p>다음 강에서는 <strong>형용사(い형용사·な형용사)</strong> 를 배우며 문장을 더 풍부하게 표현하는 방법을 익혀봅니다.</p>
<hr>
<blockquote>
<p>📚 <strong>시리즈 목차</strong></p>
<p><strong>[초급 전반 — N5 레벨]</strong></p>
<ul>
<li>1강: 히라가나 · 가타카나 완전 정복</li>
<li>2강: 발음 규칙 — 탁음 · 반탁음 · 요음 · 촉음 · 장음</li>
<li>3강: 자기소개 — ～は～です · じゃありません · ですか</li>
<li>4강: 지시대명사 — これ · それ · あれ · どれ</li>
<li>5강: 숫자와 시간 표현 — ～時 · ～分 · ～円</li>
<li>6강: 동사 기초 — ます형 · 이동 표현 (～へ行きます)</li>
