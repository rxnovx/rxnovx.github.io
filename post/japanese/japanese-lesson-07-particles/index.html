들어가기 앞서 #

일본어에서 조사(助詞)는 단어와 단어 사이의 관계를 나타내는 핵심 요소입니다.
조사를 잘못 쓰면 문장이 어색해지거나 뜻이 완전히 달라지기도 합니다.
이번 강에서는 초급에서 가장 많이 쓰이는 핵심 조사 6가지를 용법별로 깊이 파고듭니다.

이 글을 읽고 나면:

  • を(목적격), で(장소·수단), と(동반·나열), に(도달점·시간·대상), へ(방향), が(주격)의 기본 용법을 구분할 수 있습니다.
  • 조사를 혼동하기 쉬운 케이스(に vs で, は vs が 등)를 구분할 수 있습니다.
  • 각 조사를 활용한 자연스러운 문장을 만들 수 있습니다.

1. 조사 を — 목적어 표시 #

を 는 동사의 목적어(~을/를) 를 나타냅니다.
발음은 お(o) 와 동일하게 읽습니다.

plain
[명사] を [타동사]

기본 용법 #

plain
パンを たべます。
빵을 먹습니다.

みずを のみます。
물을 마십니다.

ほんを よみます。
책을 읽습니다.

おんがくを ききます。
음악을 듣습니다.

にほんごを べんきょうします。
일본어를 공부합니다.

이동 동사와의 결합: 경유·출발점 #

を 는 이동 동사와 결합하면 경유 장소나 출발 장소도 나타냅니다.

plain
こうえんを さんぽします。
코우엔오 산포시마스。
(공원을 산책합니다.) ← 경유

うちを でます。
우치오 데마스。
(집을 나갑니다.) ← 출발점

かどを まがります。
카도오 마가리마스。
(모퉁이를 돕니다.) ← 통과점

2. 조사 で — 장소·수단·재료·이유 #

で 는 용법이 가장 다양한 조사 중 하나입니다.

용법 ①: 동작이 이루어지는 장소 (~에서) #

plain
[장소] で [동작동사]

としょかんで べんきょうします。
도서관에서 공부합니다.

レストランで ひるごはんを たべます。
레스토랑에서 점심을 먹습니다.

こうえんで あそびます。
공원에서 놉니다.

용법 ②: 수단·도구 (~으로/로) #

plain
[수단] で [동사]

えんぴつで かきます。
연필로 씁니다.

にほんごで はなします。
일본어로 말합니다.

でんしゃで いきます。
전철로 갑니다.

スマートフォンで しゃしんを とります。
스마트폰으로 사진을 찍습니다.

용법 ③: 재료 (~으로) #

plain
このケーキは ちょこれーとで つくります。
이 케이크는 초콜릿으로 만듭니다.

きで つくった テーブルです。
나무로 만든 테이블입니다.

용법 ④: 범위·한정 (~에서/~으로) #

plain
クラスで いちばん はやいです。
반에서 가장 빠릅니다.

ふたりで いきます。
둘이서 갑니다.

みんなで たべましょう。
모두 함께 먹읍시다.

3. 조사 と — 동반·나열·인용 #

용법 ①: 동반 (~와/과 함께) #

plain
[사람] と [동사]

ともだちと えいがを みます。
친구와 영화를 봅니다.

かれしと レストランへ いきました。
남자친구와 레스토랑에 갔습니다.

ひとりで いきます。(혼자 갈 때는 と를 쓰지 않음)

용법 ②: 나열 (~와/과, ~랑) #

plain
[명사A] と [명사B]

コーヒーと ケーキを ください。
커피와 케이크를 주세요.

かばんと さいふを かいました。
가방과 지갑을 샀습니다.

💡 と vs や: 나열에서 と는 그것만 있다는 완전 나열, や는 그 외에도 있다는 불완전 나열입니다.

plain
りんごと みかんを かいました。(사과와 귤을 샀습니다. — 딱 두 개)
りんごや みかんを かいました。(사과나 귤 등을 샀습니다. — 그 외에도 있음)

용법 ③: 인용 (~라고) #

plain
「おはよう」と いいます。
"오하요우"라고 말합니다.

かれは「いきます」と いいました。
그는 "갑니다"라고 말했습니다.

4. 조사 に — 도달점·시간·목적·대상·존재 #

に 는 용법이 가장 많은 조사입니다. 하나씩 정리해봅니다.

용법 ①: 이동의 도달점 (~에) #

plain
がっこうに いきます。
학교에 갑니다.

とうきょうに きました。
도쿄에 왔습니다.

용법 ②: 시간 표현 (~에) #

plain
しちじに おきます。
7시에 일어납니다.

どようびに かいものを します。
토요일에 쇼핑을 합니다.

ごがつに にほんへ いきます。
5월에 일본에 갑니다.

⚠️ に를 붙이지 않는 시간 표현
きょう(오늘), あした(내일), まいにち(매일), いつ(언제) 등 상대적·반복적 표현에는 に를 붙이지 않습니다.

plain
✅ しちじに おきます (7시에)
❌ きょうに いきます → ✅ きょう いきます
❌ まいにちに → ✅ まいにち

용법 ③: 존재 장소 (~에) #

plain
つくえの うえに ほんが あります。
책상 위에 책이 있습니다.

えきの まえに ともだちが います。
역 앞에 친구가 있습니다.

용법 ④: 동작의 목적 (~하러) #

plain
[동사ます형] + に + いきます/きます/かえります

かいものに いきます。
쇼핑하러 갑니다.

すしを たべに いきます。
초밥을 먹으러 갑니다.

ともだちに あいに いきました。
친구를 만나러 갔습니다.

용법 ⑤: 동작의 대상 (~에게) #

plain
せんせいに しつもんします。
선생님께 질문합니다.

ははに てがみを かきます。
어머니께 편지를 씁니다.

ともだちに プレゼントを あげます。
친구에게 선물을 줍니다.

5. 조사 へ — 방향 #

へ 는 이동의 방향을 나타냅니다. 발음은 え(e).
に와 거의 같은 의미로 사용되지만 뉘앙스 차이가 있습니다.

plain
にほんへ いきます。
일본으로 갑니다.

うちへ かえります。
집으로 돌아갑니다。

に vs へ 비교 #

조사 강조점 예문
に 도달점 (목적지에 도착하는 것) とうきょうに つきました
へ 방향 (그쪽으로 향하는 동작) とうきょうへ いきます

💡 실제 회화에서는 두 조사를 혼용해도 자연스럽습니다. に쪽이 더 자주 쓰이는 경향이 있습니다.

6. 조사 が — 주격·강조·능력·감정 #

용법 ①: 주격 (~이/가) #

새로운 정보나 특정 대상을 지정할 때 が 를 사용합니다.

plain
あそこに えきが あります。
저기에 역이 있습니다.

だれが きますか。
누가 옵니까?

どれが あなたの かばんですか。
어느 것이 당신의 가방입니까?

용법 ②: 능력·소유 (~이/가) #

plain
にほんごが わかります。
일본어를 알겠습니다. (이해합니다)

じかんが あります。
시간이 있습니다.

くるまが あります。
차가 있습니다.

용법 ③: 감정·기호 (~이/가) #

plain
すしが すきです。
초밥을 좋아합니다.

えいごが とくいです。
영어를 잘합니다.

いぬが こわいです。
개가 무섭습니다.

は vs が — 핵심 차이 #

초급 학습자가 가장 많이 헷갈리는 부분입니다.

조사 역할 뉘앙스
は 주제 이미 알려진 정보, 대비·대조
が 주격 새로운 정보, 특정 지정 
plain
A: だれが やまださんですか。
   누가 야마다 씨입니까?
B: わたしが やまださんです。
   제가 야마다 씨입니다.
   (특정 지정 → が)

A: やまださんは どこですか。
   야마다 씨는 어디 있습니까?
B: やまださんは あそこに います。
   야마다 씨는 저기에 있습니다.
   (이미 아는 주제 → は)

7. 조사 비교 총정리표 #

조사 주요 용법 예문
を 목적어, 경유·출발점 ほんを よむ / こうえんを あるく
で 장소(동작), 수단, 재료, 범위 としょかんで よむ / えんぴつで かく
と 동반, 나열, 인용 ともだちと いく / AとBを かう
に 도달점, 시간, 존재장소, 목적, 대상 がっこうに いく / しちじに おきる
へ 방향 にほんへ いく
が 주격, 능력·소유, 감정 にほんごが わかる / すしが すき

8. 혼동하기 쉬운 조사 비교 #

① で vs に (장소) #

조사 용법 예문
で 동작이 일어나는 장소 としょかんで べんきょうします
に 존재하는 장소, 이동의 도달점 としょかんに います 
plain
✅ がっこうで べんきょうします (학교에서 공부합니다 — 동작의 장소)
✅ がっこうに います (학교에 있습니다 — 존재의 장소)
❌ がっこうに べんきょうします

② と vs に (대상) #

조사 용법 예문
と 함께하는 상대 (쌍방향 동작) ともだちと はなします
に 동작이 향하는 대상 (일방향 동작) ともだちに おしえます 
plain
✅ ともだちと はなします (친구와 이야기합니다 — 서로 대화)
✅ ともだちに おしえます (친구에게 가르칩니다 — 내가 일방적으로 가르침)

③ を vs が (능력·감정 표현) #

plain
✅ にほんごが わかります (일본어를 이해합니다) ← 자연스러운 표현
✅ にほんごを はなします (일본어를 말합니다) ← 의지적 동작

9. 실전 회화 — 하루 일과 #

plain
A: まいにち なんじに おきますか。
   마이니치 난지니 오키마스카?
   (매일 몇 시에 일어나십니까?)

B: ろくじはんに おきます。
   로쿠지한니 오키마스。
   (6시 반에 일어납니다.)
   
   それから、うちで あさごはんを たべます。
   소레카라、우치데 아사고한오 타베마스。
   (그 다음, 집에서 아침을 먹습니다.)

A: かいしゃへは なにで いきますか。
   카이샤에와 나니데 이키마스카?
   (회사에는 무엇으로 갑니까?)

B: でんしゃと バスで いきます。
   덴샤토 바스데 이키마스。
   (전철과 버스로 갑니다.)
   
   かいしゃに くじに つきます。
   카이샤니 쿠지니 츠키마스。
   (회사에 9시에 도착합니다.)

A: ひるごはんは どこで たべますか。
   히루고한와 도코데 타베마스카?
   (점심은 어디에서 드십니까?)

B: かいしゃの ちかくの レストランで ともだちと たべます。
   카이샤노 치카쿠노 레스토란데 토모다치토 타베마스。
   (회사 근처 레스토랑에서 친구와 먹습니다.)

10. 문형 정리 #

문형 의미 예문
～を ～ます ~을/를 ~합니다 ほんを よみます
～で ～ます ~에서 ~합니다 / ~으로 ~합니다 えきで まちます / バスで いきます
～と ～ます ~와/과 ~합니다 ともだちと いきます
～に いきます ~에 갑니다 がっこうに いきます
～に ～ます (시간) ~에 ~합니다 くじに おきます
～に ～が あります ~에 ~이 있습니다 つくえに ほんが あります
～へ いきます ~으로 갑니다 にほんへ いきます
～が すきです ~을/를 좋아합니다 すしが すきです
～が わかります ~을/를 압니다 にほんごが わかります

마무리 #

조사는 한 번에 완벽하게 외우기보다 문장 속에서 반복해서 접하며 감각을 익히는 것이 중요합니다.
특히 で vs に, は vs が 의 구분은 중급 수준이 되어도 계속 신경 써야 할 포인트입니다.

다음 강에서는 일본어의 주고받기 표현, 수수동사(あげます·もらいます·くれます) 를 배웁니다.

📚 시리즈 목차

[초급 전반 — N5 레벨]

  • 1강: 히라가나 · 가타카나 완전 정복
  • 2강: 발음 규칙 — 탁음 · 반탁음 · 요음 · 촉음 · 장음
  • 3강: 자기소개 — ～は～です · じゃありません · ですか
  • 4강: 지시대명사 — これ · それ · あれ · どれ
  • 5강: 숫자와 시간 표현 — ～時 · ～分 · ～円
