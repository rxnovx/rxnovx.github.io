<p>일본어에서 조사(助詞)는 <strong>단어와 단어 사이의 관계</strong>를 나타내는 핵심 요소입니다.<br>
조사를 잘못 쓰면 문장이 어색해지거나 뜻이 완전히 달라지기도 합니다.<br>
이번 강에서는 초급에서 가장 많이 쓰이는 핵심 조사 6가지를 용법별로 깊이 파고듭니다.</p>
<blockquote>
<p>이 글을 읽고 나면:</p>
<ul>
<li>を(목적격), で(장소·수단), と(동반·나열), に(도달점·시간·대상), へ(방향), が(주격)의 기본 용법을 구분할 수 있습니다.</li>
<li>조사를 혼동하기 쉬운 케이스(に vs で, は vs が 등)를 구분할 수 있습니다.</li>
<li>각 조사를 활용한 자연스러운 문장을 만들 수 있습니다.</li>
</ul>
</blockquote>

<h2 id="5-조사---방향" tabindex="-1" data-src-line="249">5. 조사 へ — 방향 <a class="header-anchor" href="#5-조사---방향" aria-hidden="true">#</a></h2>
<p><code>へ</code> 는 이동의 <strong>방향</strong>을 나타냅니다. 발음은 <code>え(e)</code>.<br>
に와 거의 같은 의미로 사용되지만 뉘앙스 차이가 있습니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">にほんへ いきます。
일본으로 갑니다.

うちへ かえります。
집으로 돌아갑니다。
</code></pre></div></code></pre>
<h3 id="-vs--비교" tabindex="-1" data-src-line="262">に vs へ 비교 <a class="header-anchor" href="#-vs--비교" aria-hidden="true">#</a></h3>
<div class="table-scroll" tabindex="0" role="region" aria-label="Scrollable table"><table>

<tr>

<th scope="col">강조점</th>
<th scope="col">예문</th>
</tr>
</thead>
<tbody>
<tr>
<td>に</td>
<td>도달점 (목적지에 도착하는 것)</td>
<td>とうきょうに つきました</td>
</tr>
<tr>
<td>へ</td>
<td>방향 (그쪽으로 향하는 동작)</td>
<td>とうきょうへ いきます</td>
</tr>
</tbody>
</table>

<p>💡 실제 회화에서는 두 조사를 혼용해도 자연스럽습니다. に쪽이 더 자주 쓰이는 경향이 있습니다.</p>
</blockquote>

<h2 id="6-조사---주격강조능력감정" tabindex="-1" data-src-line="273">6. 조사 が — 주격·강조·능력·감정 <a class="header-anchor" href="#6-조사---주격강조능력감정" aria-hidden="true">#</a></h2>
<h3 id="용법--주격-이가" tabindex="-1" data-src-line="275">용법 ①: 주격 (~이/가) <a class="header-anchor" href="#용법--주격-이가" aria-hidden="true">#</a></h3>
<p>새로운 정보나 특정 대상을 지정할 때 <code>が</code> 를 사용합니다.</p>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">あそこに えきが あります。
저기에 역이 있습니다.

だれが きますか。
누가 옵니까?

どれが あなたの かばんですか。
어느 것이 당신의 가방입니까?
</code></pre></div></code></pre>
<h3 id="용법--능력소유-이가" tabindex="-1" data-src-line="290">용법 ②: 능력·소유 (~이/가) <a class="header-anchor" href="#용법--능력소유-이가" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">にほんごが わかります。
일본어를 알겠습니다. (이해합니다)

じかんが あります。
시간이 있습니다.

くるまが あります。
차가 있습니다.
</code></pre></div></code></pre>
<h3 id="용법--감정기호-이가" tabindex="-1" data-src-line="303">용법 ③: 감정·기호 (~이/가) <a class="header-anchor" href="#용법--감정기호-이가" aria-hidden="true">#</a></h3>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">すしが すきです。
초밥을 좋아합니다.

えいごが とくいです。
영어를 잘합니다.

いぬが こわいです。
개가 무섭습니다.
</code></pre></div></code></pre>
<h3 id="-vs---핵심-차이" tabindex="-1" data-src-line="316">は vs が — 핵심 차이 <a class="header-anchor" href="#-vs---핵심-차이" aria-hidden="true">#</a></h3>

   누가 야마다 씨입니까?

<h2 id="9-실전-회화--하루-일과" tabindex="-1" data-src-line="390">9. 실전 회화 — 하루 일과 <a class="header-anchor" href="#9-실전-회화--하루-일과" aria-hidden="true">#</a></h2>
<pre><code><div class="code-block"><div class="code-header"><span class="code-title">plain</span><button type="button" class="copy-button" aria-label="Copy code block">Copy</button></div><pre class="language-plain"><code class="hljs language-plain">A: まいにち なんじに おきますか。
   마이니치 난지니 오키마스카?
   (매일 몇 시에 일어나십니까?)

B: ろくじはんに おきます。
   로쿠지한니 오키마스。
   (6시 반에 일어납니다.)
   
   それから、うちで あさごはんを たべます。
   소레카라、우치데 아사고한오 타베마스。
   (그 다음, 집에서 아침을 먹습니다.)

A: かいしゃへは なにで いきますか。
   카이샤에와 나니데 이키마스카?
   (회사에는 무엇으로 갑니까?)

B: でんしゃと バスで いきます。
   덴샤토 바스데 이키마스。
   (전철과 버스로 갑니다.)
   
   かいしゃに くじに つきます。
   카이샤니 쿠지니 츠키마스。
   (회사에 9시에 도착합니다.)

A: ひるごはんは どこで たべますか。
   히루고한와 도코데 타베마스카?
   (점심은 어디에서 드십니까?)

B: かいしゃの ちかくの レストランで ともだちと たべます。
   카이샤노 치카쿠노 레스토란데 토모다치토 타베마스。
   (회사 근처 레스토랑에서 친구와 먹습니다.)
</code></pre></div></code></pre>

<h2 id="마무리" tabindex="-1" data-src-line="444">마무리 <a class="header-anchor" href="#마무리" aria-hidden="true">#</a></h2>
<p>조사는 한 번에 완벽하게 외우기보다 <strong>문장 속에서 반복해서 접하며</strong> 감각을 익히는 것이 중요합니다.<br>
특히 <code>で vs に</code>, <code>は vs が</code> 의 구분은 중급 수준이 되어도 계속 신경 써야 할 포인트입니다.</p>
<p>다음 강에서는 일본어의 주고받기 표현, <strong>수수동사(あげます·もらいます·くれます)</strong> 를 배웁니다.</p>
<hr>
<blockquote>
<p>📚 <strong>시리즈 목차</strong></p>
<p><strong>[초급 전반 — N5 레벨]</strong></p>
<ul>
<li>1강: 히라가나 · 가타카나 완전 정복</li>
<li>2강: 발음 규칙 — 탁음 · 반탁음 · 요음 · 촉음 · 장음</li>
<li>3강: 자기소개 — ～は～です · じゃありません · ですか</li>
<li>4강: 지시대명사 — これ · それ · あれ · どれ</li>
<li>5강: 숫자와 시간 표현 — ～時 · ～分 · ～円</li>
<li>6강: 동사 기초 — ます형 · 이동 표현 (～へ行きます)</li>
<li><strong>7강</strong>: 조사 — を · で · と · に · へ · が ← 현재 글</li>
<li>8강: 수수 표현 — あげます · もらいます · くれます</li>
<li>9강: 형용사 — い형용사 · な형용사 활용</li>
<li>10강: 존재 표현 — います · あります · 위치 표현</li>
</ul>
<p><strong>[초급 후반 — N4 레벨]</strong></p>
<ul>
<li>11강: て형 만들기 — 동사 그룹별 활용</li>
<li>12강: ~ている — 진행 · 상태 표현</li>
<li>13강: ~てください · ~てもいいです · ~てはいけません</li>
<li>14강: 가능 표현 — 동사 가능형 · ～ことができます</li>
<li>15강: 경험 표현 — ～たことがあります</li>
<li>16강: 조건 표현 — ～たら · ～ば · ～と · ～なら</li>
<li>17강: 수수 표현 심화 — ～てあげる · もらう · くれる</li>
<li>18강: 경어 표현 — 존경어 · 겸양어 · 정중어 완전 정리</li>
</ul>
