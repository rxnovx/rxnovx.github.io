## 들어가기

최근 회사에서 Redhat Linux 9.7 을 사용하게 되어 HPE 교육센터에서 교육을 수강했습니다.
해당 교육을 수강하고나서, 필요할 때마다 꺼내보기 위해 리눅스 배우기 시리즈로 글을 작성합니다.

대학 수업에서도, 이전 회사에서 일을 할 때부터 리눅스를 자주 다뤄왔으며 CentOS, Ubuntu 두 종류의 배포판 리눅스를 사용해 본 경험이 있습니다.
다만, 지금까지 정식적으로 교육은 받아 본 적이 없고 인터넷에 작성된 블로그나 문서를 보면서 배운 리눅스라 사용법은 알지만 구멍이 송송 뚫린 지식이기 때문에
이번 정식 교육을 통해 리눅스 지식에 뚫린 구멍을 메꾸고자 합니다.

---

## Linux 설치를 위한 도구 준비

리눅스를 설치하기 위해선 당연하지만 PC 한대가 추가로 있어야 설치가 가능합니다.
하지만 리눅스를 설치하려고 PC 1대를 사기엔 너무 부담스럽기 때문에 우리는 가상화 툴을 이용하여 리눅스를 설치할 예정입니다.
그리고 로키 리눅스를 설치하기 위해 로키 리눅스 디스크 이미지가 필요합니다.

## VMware 다운로드 및 설치
제가 사용할 가상화 툴은 VMware이고, 운영체제에 따라 두가지 버전으로 나뉩니다.

- VMware Workstation(Window)
- VMware Fusion(MAC)

저는 현재 MAC를 사용중이므로 Fusion을 사용할 예정이며 다운로드 받는 파일이 Fusion일 뿐, 윈도우와 거의 동일합니다.
아래 주소에서 파일을 다운로드 받을 수 있습니다.

- [https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion](https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion)
![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769237947060-image.webp)

### Broadcom 사이트 회원가입

## 1. 본격적인 Rocky Linux 가상머신에 설치하기

이제 VMware를 켜주시고 새로운 머신을 생성하여 해당 머신에 로키 리눅스를 설치하는 과정을 진행하도록 하겠습니다.

### 1. 가상머신 생성

맥북 기준이긴 하지만 윈도우도 메뉴가 비슷하므로, 충분히 따라 하실 수 있을겁니다.

### 1-1. 상단에 File > New... 를 클릭하여 새로운 가상머신을 생성 팝업을 띄웁니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769247543590-image.webp)

### 1-2. Create a custom virtual machine 클릭

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769247634425-image.webp)

### 1-3. Rocky Linux 64-bit Arm 클릭 > Continue

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769247721170-image.webp)

### 1-4. Create a new virtual disk 클릭 (기본값)

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769247767652-image.webp)

### 1-5. Finish (끝)

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769247795763-image.webp)

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769248012524-image.webp)

## 2. 로키 리눅스 이미지를 부팅 이미지로 잡아주기

마지막에 가상머신을 종료한 이유는 추가 설정 및 로키 리눅스 이미지를 부팅 이미지로 설정 후 부팅하기 위함입니다. 

### 2-1. 하드웨어 용량 추가 (옵션)

하드웨어 용량이 20GB로 너무 적습니다.
물론 리눅스 명령어를 익히기 위해서는 충분한 용량이지만 넉넉하게 100GB 정도로 수정을 해줍니다.

수정은 아래 이미지와 같이

Hard Disk (NVMe) > Disk size 100 입력 > Apply

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769248514098-image.webp)

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769248542163-image.webp)

### 2-2. 부팅 이미지를 다운로드한 이미지로 잡아주기

드랍다운 메뉴 클릭 > Choose a disc or disc image... > 다운로드한 이미지 선택 > Connect CD/DVD Drive 체크 > 창 닫기

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769248657091-image.webp)

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769248628880-image.webp)

## 3. 부팅하여 로키 리눅스 설치 진행


### 3-1. 가상머신 부팅

가상머신 우클릭 > Start Up
정상적으로 이미지가 잡히고 부팅이 시작되면 아래와 같이 검은 화면에 메뉴가 뜹니다.

Install Rocky Linux 10.1 을 눌러 진행합니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769248742113-image.webp)

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769248778119-image.webp)


### 3-2. 언어 설정

언어는 영어로 설정해주도록 합니다.
홈디렉토리가 한글로 생성되거나 하면 예상치 못한 오류가 발생하기 때문에 (큰 오류는 아니지만)
미리 영어로 홈디렉토리가 생성되도록 해줍니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769249135915-image.webp)

### 3-3. 설치를 위한 설정

설치를 진행하기 위해 몇가지 설정을 해주어야 합니다.
설정할 항목은 아래와 같습니다.

- Root Account
- User Creation
- Installation Destination

3가지 설정만 하면 나머지는 문제 없으니 설정을 진행해보도록 하겠습니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769249313704-image.webp)

#### 3-3-1. Root Account

루트 어카운트의 로그인을 허용할지 설정하는 단계입니다.

보안을 위해 설정하지 않도록 합니다.
필요하신 분들은 설치 후 passwd 명령어를 통해 root 계정의 암호를 설정하여 로그인 하도록 할 수 있습니다.
우선은 아래 이미지와 같이 Disable root account 로 선택 후 좌측 상단의 Done 버튼을 눌러줍니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769249431738-image.webp)

#### 3-3-2. Create User

로그인 할 유저를 설정하는 단계입니다.
항목에 맞춰 적어주시고 한가지 주의할점은 암호가 단순하면 좌측 상단의 Done 버튼을 두번 눌러야 적용이 가능합니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769249464472-image.webp)

#### 3-3-3. Installation Destination

설치할 디스크를 설정하는 단계입니다.

전문가 또는 특수한 목적으로 디스크 영역을 수동으로 설정할 경우에는
디스크를 선택한 뒤 Storage Configuration 에서 Custom을 선택하여 직접 디스크를 나눠주지만,
학습 단계에서는 필요없습니다. Automatic로 진행 후 좌측 상단의 Done 버튼을 누르도록 합니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769249532984-image.webp)

#### 3-3-4. 설치 진행

다 끝나셨으면 우측 하단의 Begin Installation을 눌러 설치를 진행합니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769249686250-image.webp)

#### 3-3-5. 설치 완료

설치가 완료되면 우측 하단의 Reboot System 버튼을 누릅니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769249835868-image.webp)

#### 3-3-6. 부팅 이미지 언마운트

그대로 부팅을 하게 되면 다시 설치 이미지로 부팅이 되기 때문에 아래의 설정으로 돌아가
[Connect CD/DVD Drive] 를 체크 해제 해줍니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769249999356-image.webp)

## 4. 로키 리눅스 실행

정상적으로 부팅이 되면 아래와 같이 로그인이 뜹니다.

User Create 단계에서 입력했던 유저 정보를 입력하여 로그인 하면 설치 완료입니다.

![image.png](/images/_posts/linux/rocky-linux-series-1-install/1769250086643-image.webp)

## 5. 마치면서

로키 리눅스를 가상머신 환경에 설치하기 위한 설치 과정을 정리해보았습니다.
