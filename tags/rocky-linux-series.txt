## 로그인 세션에 대한 정보를 얻기

### 로그인 사용자를 확인하는 방법

리눅스에서 현재 로그인한 사용자가 누구인지,
어떤 터미널을 통해 접속했는지는 기본적으로 확인해야 할 정보입니다.
문제 상황을 추적하거나 접근 권한을 확인할 때 자주 사용됩니다.

* **UID** : user id
* **GID** : group id
* **terminal** : tty, pts 등 접속 터미널 정보

---

### 커맨드로 확인하는 방법

가장 기본적으로 사용하는 명령어는 `id` 입니다.
현재 사용자 기준으로 UID, GID, 소속 그룹 정보를 한 번에 출력합니다.

```bash
id
```

필요한 정보만 확인하고 싶을 경우에는 다음과 같이 나누어 사용할 수 있습니다.

```bash
id -un      # 사용자 이름
whoami     # 현재 사용자 이름
id -Gn     # 소속 그룹 목록
tty        # 현재 터미널
```

> [!NOTE] 노트
> 공식 문서는 대부분 여기에서 확인할 수 있습니다.
> [https://docs.redhat.com/ko](https://docs.redhat.com/ko)
> 문제가 생겼을 때 가장 먼저 참고할 만한 자료입니다.

---

## 명령어 문서에서 도움말 확인하기

대부분의 리눅스 명령어는 자체적인 도움말을 포함하고 있습니다.
짧고 빠르게 옵션이나 사용법을 확인할 때 유용합니다.

```bash
command --help
```

출력 내용은 간단하지만,
자주 사용하는 옵션을 확인하기에는 충분한 정보가 제공됩니다.

---

## man 과 info 명령어로 메뉴얼을 확인하기

보다 자세한 설명이 필요할 경우에는 `man` 명령어를 사용합니다.
각 명령어에 대한 공식 매뉴얼을 텍스트 환경에서 확인할 수 있습니다.

```bash
man [section] name
```

매뉴얼 화면에서 사용할 수 있는 기본 조작은 다음과 같습니다.

* `Enter` : 한 줄씩 이동
* `Space` : 한 페이지씩 이동
* `b` : 이전 페이지로 이동
* `/` : 검색 모드 진입 (`n`으로 다음 결과 이동)

매뉴얼은 섹션별로 구성되어 있으며,
명령어, 설정 파일, 시스템 호출 등 용도에 따라 구분되어 있습니다.

키워드 기반으로 매뉴얼을 검색하고 싶을 경우에는 다음 명령어를 사용합니다.

```bash
man -k 키워드
```

이는 내부적으로 매뉴얼 인덱스를 검색하는 방식이며,
환경에 따라 인덱스가 최신 상태가 아닐 수도 있습니다.

이럴 경우에는 `mandb` 명령어를 사용하여
수동으로 매뉴얼 인덱스 데이터베이스를 생성할 수 있습니다.

```bash
mandb
```

## man 페이지의 기호를 예제로 이해하기

`man` 페이지에서 사용하는 기호들은
처음 보면 의미를 파악하기 어렵습니다.
아래에서는 실제 메뉴얼에 등장하는 예시를 기준으로
각 기호가 어떤 의미를 가지는지 정리합니다.

---

### 대괄호 `[]` : 생략 가능한 옵션 또는 인수

대괄호로 묶인 항목은 반드시 입력할 필요가 없는 선택 사항입니다.

```text
ls [-a] [-l] [file ...]
```

위 예시는 다음과 같이 해석할 수 있습니다.

* `-a`, `-l` 옵션은 필요할 때만 사용합니다.
* `file` 인수는 생략할 수 있습니다.
* 인수를 생략하면 현재 디렉토리를 기준으로 동작합니다.

---

### 꺾쇠 괄호 `<>` : 반드시 필요한 값

꺾쇠 괄호로 표시된 항목은 반드시 값을 입력해야 합니다.
실제 메뉴얼에서는 문자열, 숫자, 경로 등이 들어갑니다.

```text
useradd -u <UID> <username>
```

위 예시는 다음을 의미합니다.

* `<UID>`에는 숫자 값이 반드시 들어가야 합니다.
* `<username>`은 생성할 사용자 이름입니다.
* 두 값 모두 생략할 수 없습니다.

---

### 세로 막대 `|` : 여러 항목 중 하나 선택

세로 막대는 여러 선택지 중 하나를 선택해야 함을 의미합니다.
동시에 사용할 수는 없습니다.

```text
shutdown [-h | -r | -c] [time]
```

위 예시는 다음과 같이 해석됩니다.

* `-h`, `-r`, `-c` 중 하나만 사용할 수 있습니다.
* 시스템 종료, 재부팅, 예약 취소 중 하나를 선택합니다.

---

### 말줄임표 `...` : 반복 가능

말줄임표는 동일한 형태의 인수를 여러 개 사용할 수 있음을 의미합니다.

```text
chmod [OPTION]... MODE[,MODE]... FILE...
```

위 예시는 다음을 의미합니다.

* `OPTION`은 여러 개 지정할 수 있습니다.
* `FILE` 인수는 하나 이상 지정할 수 있습니다.
* 여러 파일에 동일한 권한 설정을 적용할 수 있습니다.

---

### 기호를 읽는 순서

처음 `man` 페이지를 볼 때는 다음 순서로 읽는 것이 좋습니다.

1. 대괄호(`[]`)로 선택 사항을 구분합니다.
2. 꺾쇠 괄호(`<>`)로 반드시 필요한 값을 확인합니다.
3. 세로 막대(`|`)로 동시에 사용할 수 없는 옵션을 확인합니다.
4. 말줄임표(`...`)로 반복 가능한 인수를 파악합니다.

기호의 의미를 알고 나면,
긴 메뉴얼에서도 필요한 사용법만 빠르게 골라볼 수 있습니다.


`man` 외에도 `info` 명령어를 통해 문서를 확인할 수 있습니다.
일부 GNU 계열 명령어는 `info` 문서에 더 자세한 설명이 포함되어 있습니다.

```bash
info 명령어
```

---

현재 로그인한 사용자나 시스템 접속 이력을 확인하기 위한 명령어도 자주 사용됩니다.

```bash
who     # 현재 로그인한 사용자
last    # 로그인 이력
```

## 여러 가지 시스템 정보 확인 방법

## 파일시스템이란?

파일시스템은 데이터를 저장하고 관리하기 위한 구조를 말합니다.
윈도우, 유닉스, 리눅스 등 대부분의 운영체제에서 공통으로 사용되는 개념입니다.

파일의 크기가 크고 개수가 적은지,
파일의 크기가 작고 개수가 많은지에 따라
적합한 파일시스템이 달라집니다.

대표적으로 윈도우에서는 NTFS를 사용합니다.
과거에는 FAT32도 많이 사용되었습니다.

리눅스에서는 ext4와 같은 전용 파일시스템을 주로 사용하며,
필요에 따라 FAT32와 같은 파일시스템도 지원합니다.

---

## 유닉스/리눅스에서의 파일 구조 특징

유닉스/리눅스에서의 파일 구조 특징은 아래와 같습니다.

* singly rooted (최상단 디렉토리)
  : 하나의 루트(/) 디렉토리를 기준으로 모든 디렉토리가 구성됨

* cAsE SensiTiviTY
  : 파일 이름에서 대소문자를 명확하게 구분함

* long file names
  : 긴 파일 이름을 지원함

* supports links
  : 링크 기능을 지원함 (하드 링크, 심볼릭 링크)

* timestamps various file operations
  : 파일에 대해 여러 종류의 시간 정보(생성, 수정, 접근 등)를 관리함

---

## 파일시스템을 탐색하는 방법

리눅스는 윈도우와 마찬가지로 트리 구조의 파일 구조를 가지고 있습니다.
이러한 트리 구조에서는 경로가 중요합니다.

경로에는 두 가지 종류가 있으며,
절대경로와 상대경로로 나뉩니다.

또한 원하는 디렉토리로 이동하기 위한 명령어도 필요합니다.
아래에서 각각 살펴보겠습니다.

---

### 절대경로

절대경로는 최상위 경로(/)부터 시작하여 특정 위치를 가리키는 경로를 말합니다.

```bash
# 현재 위치한 곳은 홈 디렉토리
# package.json 파일을 열고자 할 때
vi /home/user/workspace/project1/package.json
```

---

### 상대경로

상대경로는 현재 내가 위치한 디렉토리를 기준으로 경로를 지정하는 방식입니다.

```bash
# 현재 위치한 곳은 홈 디렉토리
# package.json 파일을 열고자 할 때
vi workspace/project1/package.json
```

---

### 트리 구조 안에서 원하는 디렉토리로 이동하는 명령어 cd

cd(change directory) 명령어는 트리 구조 안에서 원하는 디렉토리로 이동하는 명령어입니다.
인수로 경로를 입력받습니다.

현재 위치한 경로를 확인하기 위해서는 pwd 명령어를 사용합니다.

```bash
cd ~    # ~ (tilde)는 home directory를 의미함
pwd
/home/user
```
### 디렉토리 내부 파일 목록을 출력해주는 명령어 ls

현재 위치한 디렉토리 또는 특정 디렉토리 내부에 어떤 파일과 디렉토리가 있는지 확인하는 명령어입니다.

ls 명령어는 리눅스에서 가장 자주 사용하는 기본 명령어 중 하나입니다.
옵션 없이 실행하면 현재 디렉토리의 파일과 디렉토리 이름만 출력합니다.

```bash
ls
```

특정 디렉토리의 내용을 확인하고 싶다면 경로를 인수로 전달합니다.

```bash
ls /etc
```

옵션을 사용하면 출력 형태를 변경할 수 있습니다.

```bash
ls [옵션] [디렉토리]
```

자주 사용하는 옵션은 다음과 같습니다.

* -l : 파일의 상세 정보를 함께 출력
* -a : 숨김 파일을 포함하여 출력

```bash
# 상세 정보 출력
ls -l

# 숨김 파일 포함
ls -a

# 상세 정보 + 숨김 파일
ls -la
```

ls -l 옵션을 사용하면 파일의 권한, 소유자, 크기, 수정 시간 등을 함께 확인할 수 있습니다.
이 출력 결과는 파일 권한과 소유권을 이해하는 데 자주 활용됩니다.

ls 명령어는 단독으로도 많이 사용되지만,
cd, pwd와 함께 디렉토리 이동과 탐색 과정에서 자연스럽게 사용됩니다.

추가로 ls는 리눅스를 사용하면서 가장 많이 사용되는 명령어 입니다.

---

## 디렉토리 조작 관련 명령어

디렉토리를 조작하기 위한 명령어를 알아보겠습니다.
디렉토리를 생성하거나 삭제하는 명령어입니다.

* **mkdir** : 디렉토리 생성

  * `-m` : 생성 시 퍼미션 지정
  * `-p` : 상위 디렉토리까지 함께 생성

* **rmdir** : 빈 디렉토리 삭제

  * `-p` : 상위 디렉토리까지 함께 삭제 (비어 있을 경우)

---

## 파일 조작 관련 명령어

파일을 조작하는 명령어에 대해 알아보겠습니다.
파일을 복사하거나 이동하는 명령어입니다.

* **cp** : 파일/디렉토리 복사

  * 여러 파일 복사 가능: `cp a b c .`
  * `-i` : 덮어쓰기 전 확인 (alias 권장)
  * `-r`, `-R` : 디렉토리 전체 복사

* **mv** : 파일/디렉토리 이동 및 이름 변경

  * `-i` : 덮어쓰기 전 확인 (alias 권장)
  * 디렉토리는 옵션 없이 이동 가능

---


## 삭제 및 파일 생성 명령어

* **rm** : 파일/디렉토리 삭제

  * `-i` : 삭제 전 확인
  * `-f` : 강제 삭제
  * `-r`, `-R` : 디렉토리 재귀 삭제

* **touch** : 빈 파일 생성 / 타임스탬프 변경

  * 파일 존재 여부로 동작을 제어할 때 활용
  * 예: `/etc/nologin` → 일반 사용자 로그인 차단

---

> [!TIP] TIP : Alias
> 자주 쓰는 옵션을 기본 동작으로 설정하는 기능으로
> cp나 rm, mv 명령어를 쓸 때 파일을 덮어쓸 경우 -i 옵션을 주지 않아도 항상 주도록
> Alias를 설정해두면 파일이 덮어써지거나 삭제되는 것을 방지할 수 있음.
> ``` bash
> 예: `alias cp='cp -i'`, `alias mv='mv -i'`
> ```
> `.bashrc`에 정의하면 로그인 후에도 유지됨

  
---

## 바로가기 만들기 : 파일 링크 생성

* **ln** : 링크 생성

  * 하드링크 : 같은 파일에 이름만 하나 더 추가

    * 다른 디스크(파일시스템) 간 생성 불가
  * 소프트링크(`-s`) : 경로를 가리키는 링크

    * 디스크가 달라도 생성 가능
